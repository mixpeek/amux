A Developer's Guide to Unattended Coding

Set it up right, and you only check in once a day.

Prerequisites for unattended operation

  1. YOLO mode: Auto-approve tool-use prompts
  2. Recovery: Keep going through usage limits and reboots, and surface stalled work
  3. Task board: Agents know what to work on
  4. Git isolation: Agents don't conflict with each other

amux provides all four. Register sessions with --yolo, which launches Claude Code with --dangerously-skip-permissions. amux holds delivery through usage limits and resumes at the provider's reset, brings every worker back in its own conversation after a macOS reboot, and flags stalled board work with an alert.

Get started with amux

Run an AI engineering team of Claude Code, Codex and Gemini CLI agents from one dashboard or your phone. One Rust binary, MIT + Commons Clause, free to self-host on macOS or Linux.

curl -fsSL https://amux.io/install.sh | bash
# then open https://localhost:8824
