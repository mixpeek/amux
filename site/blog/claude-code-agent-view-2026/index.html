Claude Code Agent View: What It Does and Where It Stops

Agent view (claude agents) is Claude Code's built-in screen for background sessions. What it covers, and when a fleet needs more.

Published September 11, 2026 · Updated October 30, 2026

Correction, October 30, 2026: an earlier version of this post described agent view as a pane that shows the subagents of one session. That was wrong. Agent view lists independent background sessions across every project on your machine, and Anthropic's docs say subagents are not listed as separate rows. The full, current comparison is amux vs Claude Code agent view.

What is Claude Code agent view?

Agent view is one terminal screen for all your background Claude Code sessions: what is running, what needs your input, and what is done. You type a prompt to dispatch a new session, press Space to peek at one and reply, or attach to the full conversation. A supervisor process keeps the sessions running without a terminal, each session moves into its own git worktree before it edits files, and each row shows a one-line summary and the status of any pull request it opened. It is in research preview.

Where does agent view stop?

  • Claude Code only. Codex and Gemini CLI agents are not listed.
  • Your machine only. Sessions survive sleep but stop if the machine shuts down, and make no progress while it sleeps.
  • The terminal. Agent view has no phone app; Anthropic's phone paths are Remote Control and Projects (a cloud beta on Pro and Max).
  • You coordinate. Each prompt starts an independent session; there is no shared task board for agents to claim work from.

Frequently Asked Questions

What is Claude Code agent view?

Agent view, opened with claude agents, is a built-in Claude Code screen that lists every background Claude Code session you started on your machine, across all projects, grouped by state. You can dispatch new sessions, peek at one and reply, or attach to the full conversation. It is in research preview.

Does agent view show subagents?

No. Anthropic's docs say subagents and teammates a session spawns are not listed as separate rows. Each row is an independent background session.

Do agent view sessions keep running when my laptop is closed?

They survive sleep and resume on wake, but they run on your machine and stop if it shuts down. To keep agents working with the lid closed you need a machine that stays on, such as amux Cloud or Anthropic's cloud sessions.
