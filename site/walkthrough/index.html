Short cuts

Transcript

Your first agent

This is amux, an open-source control plane for coding agents. Claude Code, Codex and Gemini work as one team that you watch, steer, and reach from anywhere. It runs free on your own machine. Here's a fresh install.

Skip the tour. Click plus, then New worker. Give it a name, point it at a repo, and tell it what to do. Here that's a failing discount test in a small store API.

Create. That card is a real Claude Code session in its own terminal, and amux tracks its status and its task.

Open it and you're in the live terminal. It reads the code, sees the discount was applied after tax, fixes it, and runs the tests.

Run a team

The real gain is a team. Here are five workers, each in its own git worktree so they never collide: API, frontend, docs, tests and ops.

Groups set the rules for a lane. Backend has binding rules, its own environment and board gates, and its workers can only message workers in a shared group.

Coordinate

Workers coordinate with each other. qa found a bug the frontend should handle. Mention @web, and qa gets a two-hour pass to message a worker outside its group.

Every message between workers and people lands in Messages: channels per group, direct threads, and mentions.

Only what needs you

Routine questions get answered for you. What truly needs you, like spending money, touching production data, or anything sent outside, comes here. api wants to migrate production.

You decide in one place. Not today: ship prices in US dollars only. api gets the answer and keeps going.

Talk to a worker

Chat sits beside the terminal. Ask what a worker is doing and get a straight answer, while the worker keeps going undisturbed.

Or just talk. Converse is a voice call with your worker, and it never touches the terminal either.

The board

The board is the team's shared list of work. Agents create cards, claim them atomically so two never grab the same one, and move them through the columns.

Each column can have a gate. Moving a card to Done asks you to confirm it was merged and the tests pass. Gates can come from the card's type, its worker or its group, and the board records who confirmed each one.

Turn on drain, and an idle worker refills its To Do from the backlog and starts the next card by itself. Work flows from backlog to done with every gate checked on the way.

Shared intelligence

MDAI files are markdown that computes itself. This one reads the server code and the test suite and keeps an endpoint coverage table current. The release check builds on top of it.

Draw is a shared whiteboard. Maya opens the same plan from her browser, and you watch her add a cache in real time. When it's ready, send the sketch to a worker.

Beyond the repo

Workers can drive a real browser with saved profiles, so they can sign in where you already are and you can watch them live.

Connectors give every worker your Google, Slack and other accounts through one grant.

And the vault holds secrets and payment methods. Workers get keys as environment variables, never see the values, and any payment above your limit waits for you.

Own the record

Every message, log, task, board card and the commits behind them land in one database on your machine. That record is yours, and it's what lets you build your own software factory.

It keeps working offline. Lose the network, keep sending, and the dashboard queues it and syncs the moment you're back.

Anywhere, together

All of it works on your phone, and you can invite teammates with scoped access to run the same fleet together.
