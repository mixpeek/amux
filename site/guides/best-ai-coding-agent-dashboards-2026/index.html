What does an AI coding agent dashboard do?

A coding agent such as Claude Code or Codex CLI runs one conversation in one terminal. Once you run three or more at the same time, you need somewhere to see all of them. A dashboard gives you that screen. The useful ones answer four questions without opening a terminal:

  • Which agents are working, waiting or stuck? A permission prompt or a usage limit stops an agent silently.
  • What did each one change? Diffs, branches and pull requests per task.
  • Who works on what? A task list or board so two agents do not edit the same files.
  • Can I reach it away from my desk? A phone view, and a machine that stays on when the laptop closes.

The tools below split into three shapes: desktop apps you review work in, web dashboards you host on your own machine, and control planes that run the agents for you and report back.

1. amux: best for running a team of agents

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors parallel Claude Code, Codex and Gemini CLI sessions, restarts them after a crash, resumes them after a usage limit, and gives them a shared kanban board to claim work from. One Rust binary plus SQLite, source-available under MIT + Commons Clause.

  • Board the agents work from. Agents claim tasks atomically, so two never take the same card. Each card moves from todo to done with the agent's evidence attached.
  • Agents talk to each other. One agent can send another a message or read its output, and every message lands in a Messages log you can search.
  • Phone first. A native iPhone app and a web app to answer prompts, send a task or check a run from anywhere.
  • Runs unattended. A scheduler for recurring jobs, usage-limit resume, and recovery after a crash or reboot.
  • More than code. A file viewer, notes, CRM, email and browser automation in the same dashboard.

Where it runs: install on macOS or Linux with curl -fsSL https://amux.io/install.sh | bash, or let us run it on amux Cloud: your own server at yourname.amux.io from $39/mo, so agents keep going with the laptop closed. Agencies and freelancers juggling several client repos usually want Team at $69/mo for the extra CPU and memory. Your data stays exportable either way (how).

Trade-offs: no Windows build, and the diff review is lighter than in the desktop review apps below.

2. Claude Code agent view: best built-in option

Claude Code's agent view (claude agents) is a full-screen terminal screen for background Claude Code sessions on your machine. Each session moves into its own git worktree before editing, and each row shows its pull request and check status. A supervisor process restarts a session that exits unexpectedly. It is a research preview, included with Claude Code, and each session draws on your Claude plan.

Best for: a Claude Code user who wants to watch several tasks from one terminal and nothing more. It runs only Claude Code, only while your machine is awake, with no phone view and no shared board. amux vs Claude Code agent view →

3. Conductor: best Mac app

Conductor is a polished Mac app that runs Claude Code, Codex and Cursor agents in isolated git worktrees, with diff review and merge at its center and a mobile app on Pro. On November 4, 2026 it said it was joining Meta and stopped new sign-ups; on November 12 it reversed course and said it will keep developing the app. It has not published new dates for Conductor Cloud, so check its site before you rely on the hosted part.

Best for: a Mac developer who reviews each agent's diff before merging. amux vs Conductor →

4. Emdash: best for review and merge

Emdash is a free Apache-2.0 desktop app for macOS, Windows and Linux. Each task gets its own git worktree, terminal and conversation; it pulls issues from Linear, GitHub, Jira and others, and shows diffs, pull requests and CI checks in the same window. Its docs list 35 agent CLIs. Cron automations run an agent prompt on a schedule. Web and mobile are promised for Emdash 2.0, currently a waitlist.

Best for: working through a queue of issues at a desktop and merging each one yourself. amux vs Emdash →

5. Orca: best desktop IDE for any CLI agent

Orca is a free MIT desktop app for Mac, Windows and Linux that puts each agent in its own git worktree, with a diff viewer that sends line notes back to the agent, a built-in browser and split panes. A lead agent can split a task and start worker agents. A companion phone app is in beta, and agents can run on SSH hosts or a Remote Orca Server you run. Orca does not sell managed hosting.

Best for: a desktop IDE that works with almost any CLI agent. amux vs Orca →

6. Nimbalyst: best visual workspace

Nimbalyst (formerly Crystal) is a free MIT desktop workspace where you and your agents edit the same files visually: markdown, mockups, Mermaid and Excalidraw diagrams and code, with red and green diffs to accept or reject. Sessions run in their own git worktrees and sit on a session kanban. An iOS companion lets you reply by text or voice and review diffs. Agents run inside the desktop app, so they stop when your computer does.

Best for: reviewing agents' work on docs and designs as well as code. amux vs Nimbalyst →

7. Agent of Empires: best free web dashboard on tmux

Agent of Empires (aoe) is a free MIT session manager on tmux with a keyboard-driven TUI and a web dashboard (aoe serve) you can install as a phone PWA through Tailscale Funnel or Cloudflare Tunnel. It runs Claude Code, Codex, OpenCode, Gemini CLI and more, with git worktrees and Docker, Podman or Apple Containers sandboxes. Sessions survive closing aoe or losing SSH.

Best for: a terminal user who wants a phone view of their own machine for free. amux vs Agent of Empires →

8. CloudCLI: best web UI for one session at a time

CloudCLI (Claude Code UI) is an AGPL-3.0 web UI for Claude Code, Cursor CLI and Codex: chat, a file explorer and editor, Git and a shell in any browser, phone included. CloudCLI Cloud hosts persistent containers with 2 CPU cores and 4 GB RAM from 7 EUR a month, with Growth at 20 EUR and a five-member Team plan at 39 EUR.

Best for: working inside one agent session from a browser on cheap hosting. Managing many agents at once relies on community plugins. amux vs CloudCLI →

9. Vibe Kanban: best issue-per-agent board

Vibe Kanban is an Apache-2.0 kanban UI where you create an issue, start an agent on it in its own workspace and branch, and send inline diff comments back. It supports 10+ agents. Its company, bloop, shut down in April 2026; the project is now community maintained and local only, and its hosted cloud is gone.

Best for: planning issues and reviewing one agent's diff per issue on your own machine. amux vs Vibe Kanban →

FAQ

What is an AI coding agent dashboard?

An AI coding agent dashboard is one screen that shows every coding agent you have running, such as Claude Code, Codex or Gemini CLI sessions, with each one's status, recent output and changes. Most also let you send an agent a message, answer its prompts and start new tasks without opening a terminal.

Which AI coding agent dashboard works on a phone?

amux has a native iPhone app and a web app. Nimbalyst and Orca have companion apps (Orca's is in beta), Conductor has a mobile app on Pro, and Agent of Empires and CloudCLI serve web dashboards you can open in a phone browser. Claude Code agent view is terminal only.

Can a dashboard keep agents running when my laptop is closed?

Only if the agents run on another machine. amux Cloud gives you an always-on server from $39/mo, CloudCLI Cloud hosts containers, and Orca and Emdash can drive agents on machines you provide over SSH. Desktop apps and Claude Code agent view stop when your computer sleeps or shuts down.

Is there a free AI coding agent dashboard?

Yes. amux is free to self-host, and Emdash, Orca, Nimbalyst, Agent of Empires, CloudCLI and Vibe Kanban are free as well. You still pay for the agents themselves through your Claude, ChatGPT or Gemini plan or API key.

What is the difference between amux and a desktop app like Conductor or Emdash?

Conductor and Emdash put you in front of each agent's diff at a desktop. amux runs the agents as a team on a server: they claim work from a shared board, message each other, resume after usage limits and run on schedules, and you steer them from a browser or your phone.
