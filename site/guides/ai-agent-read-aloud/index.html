AI Agent Read Aloud

Listen to what your coding agents did — no screen, no API key, no cloud.

amux includes a built-in read-aloud (TTS) button on every session card and in the Trends view. Tap the speaker icon to hear AI agent output spoken aloud using Piper TTS — a free, open-source, offline neural text-to-speech engine that runs entirely on your machine. No API key required. No per-character cost. Works on the iOS app and mobile PWA so you can listen to your morning briefing while getting ready for the day, on your commute, or with your phone in your pocket.

New in August 2026 — read-aloud (Piper TTS) is a new feature shipped in amux. See the changelog for details.

Why read-aloud matters for AI agent teams

When you run 10–50 AI coding agents overnight, the morning review is a bottleneck. You wake up, open the dashboard, and face a wall of terminal output, board cards, and status updates from sessions that ran for eight hours while you slept. Reading everything takes 20-30 minutes. Skimming misses blockers. Scrolling through raw terminal output on a phone screen is painful.

Read-aloud changes this. Instead of reading, you listen. The Trends view groups all fleet activity by theme and synthesizes a spoken summary — 60-90 seconds to hear what your team of agents accomplished overnight, which themes had the most progress, and what's blocked. You can do this with your phone on the nightstand while still in bed, or with earphones while walking to the kitchen. By the time you've made coffee, you already know what needs your attention today.

How to set up Piper TTS with amux

Step 1 — Install Piper

# macOS (Homebrew)
brew install piper

# Python (any platform)
pip install piper-tts

Piper is an open-source neural TTS engine from the Nabu Casa / Home Assistant team, MIT licensed. It runs locally with no internet connection after the initial model download. Installation takes under two minutes.

Step 2 — Enable read-aloud in amux

In the amux dashboard, go to Settings → Audio and enable Read-aloud (Piper TTS). amux will automatically detect your Piper installation. Select your preferred voice from the dropdown — amux ships with a default high-quality English voice (en_US-lessac-high).

Step 3 — Use the speaker button

A speaker icon now appears on:

  • Session cards — reads the session's most recent output (last N lines)
  • Trends theme cards — reads the synthesized theme summary (recommended for morning reviews)
  • Board cards — reads the card's description and current status

On mobile (iOS app or PWA), the audio streams from your amux server to your device's speaker or connected earphones. No Piper installation is needed on the phone itself.

Morning briefing workflow

The fastest morning review pattern with read-aloud:

  1. Open amux iOS app — tap the Trends tab
  2. Tap "Read all themes" — hear a 60-90 second spoken summary of the entire night's fleet activity
  3. Check blockers — the Trends view surfaces blockers first; tap any to expand and see which session and which task is stuck
  4. Dictate instructions — if something needs your input, use voice dictation (Whisper) to send a message to the stuck session
  5. Review PRs — the board shows completed tasks; open GitHub to review and merge pull requests

Total time: 5-10 minutes, most of it hands-free. The entire workflow is usable from an iPhone without typing anything.

Piper TTS vs. cloud TTS for AI agent briefings

ComparisonPiper TTS (amux default)Cloud TTS (ElevenLabs, AWS Polly, etc.)
Cost Free (MIT licensed, self-hosted) Per-character billing; agent output can be long
Privacy Entirely local — agent output never leaves your machine Agent output (code, secrets, business logic) sent to third-party servers
API key required No Yes — plus account and billing setup
Internet required No — works offline, on a plane, in a dead zone Yes — requires reliable connection for every read-aloud request
Voice quality Good — neural TTS, natural prosody; not identical to top cloud voices Excellent — large-scale trained models with expressive voices
Latency <1s on M-series Mac; 1-3s on older hardware 100ms-1s depending on API and network
Setup time <2 minutes (brew install piper) 10-30 minutes (account + API key + integration)
Voice options 100+ Piper voice models (16 languages) Hundreds of voices, many languages

For AI agent briefings, Piper wins on the factors that matter most: no cost at scale (agent output can be thousands of characters per session), no privacy risk (code and business logic stay local), and no dependency on internet connectivity. The voice quality difference is noticeable but not meaningful for developer use cases — you're listening for information, not entertainment.

Piper voice models

Piper ships with dozens of voice models. amux defaults to en_US-lessac-high, a high-quality American English female voice. To change or add voices:

Voice output vs. voice input: the full hands-free loop

amux supports both sides of voice interaction with your agent fleet:

  • Voice output (this guide) — Piper TTS reads agent output and summaries aloud
  • Voice input — Whisper dictation transcribes your spoken instructions and sends them to agent sessions

Used together, these enable a fully hands-free interaction loop. In the morning review: listen to what agents did (Piper), speak your next instruction to the session that needs redirection (Whisper), hear confirmation that it was sent (Piper). No typing required. This workflow is especially powerful on a phone or tablet where typing is slow.

Frequently asked questions

Can AI coding agents read their output aloud?

Yes — amux includes a built-in read-aloud button on every session card and in the Trends view, using Piper TTS. It's free, local, and requires no API key. Tap the speaker icon on any session card to hear the agent's recent output spoken aloud, or tap "Read all themes" in the Trends tab for a spoken summary of everything your fleet accomplished overnight.

What TTS engine does amux use?

amux uses Piper TTS — an open-source, offline neural text-to-speech engine originally developed at Nabu Casa for Home Assistant. Piper runs locally with no internet connection, no API key, and no per-character cost. It produces natural-sounding speech at fast inference speeds (typically under 1 second for a paragraph on modern hardware). Download from github.com/rhasspy/piper or install with brew install piper.

Does read-aloud work on the amux iOS app?

Yes. The iOS app and mobile PWA both support read-aloud. When you tap the speaker icon on your phone, amux streams the synthesized audio from the server (where Piper runs) to your device's speaker or earphones. No Piper installation is needed on the phone — only the server running amux needs Piper installed.

What's the difference between read-aloud and voice dictation?

Read-aloud is output — amux speaks AI agent output to you. Voice dictation is input — you speak instructions and amux transcribes them to send to an agent session. amux supports both: read-aloud uses Piper TTS (text-to-speech), voice dictation uses Whisper (speech-to-text), both free and local. Together they enable a fully hands-free interaction loop: listen to what agents did, speak your next instruction, done. See the voice dictation guide for input setup.

Is Piper really free? No catch?

Piper TTS is MIT licensed and free with no usage limits, no account, and no API key. The only requirement is running it on your own hardware — it does not use a cloud API. Inference is fast on any modern CPU; an M-series Mac synthesizes speech faster than real-time. Voice quality is good but not identical to large commercial cloud TTS — for developer tool briefings and agent output, the quality is more than sufficient, and the privacy and cost advantages are significant.

What gets read aloud — raw terminal output or a summary?

Both. On individual session cards, amux reads the last N lines of terminal output — useful for a quick status check on a specific session. In the Trends view, amux reads a synthesized theme summary — what the fleet worked on, how many tasks were completed per theme, and what's blocked. The Trends read-aloud is the better option for morning briefings because it gives you the high-level picture in 60-90 seconds rather than reading raw terminal output from each session.

Can I use a different voice or TTS engine?

Yes. amux supports any Piper voice model — download additional voices from the Piper GitHub repository and select them in Settings → Audio. amux can also route read-aloud through the system TTS on macOS (say command) or any TTS API you configure. Piper is the default because it works with no setup beyond installation and keeps agent output private on your machine.
