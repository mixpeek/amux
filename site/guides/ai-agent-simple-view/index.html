AI Agent Simple View
Plain-English Status at a Glance (2026)

The amux Simple tab answers the one question you actually want answered when you check on your agents: what are they doing right now? It synthesizes each worker's last message, recent activity, and timestamped history into one plain-English paragraph -- no terminal output parsing, no scrollback hunting. On iOS, the summary reads itself aloud.

Last updated: August 2026 -- Simple tab shipped August 2026 (AMUX-3056)

What is the Simple tab?

Every worker in amux has four tabs in its detail pane: Terminal (raw output), Messages (the conversation history), Files (project browser), and Simple. The Simple tab is the newest of the four and the most useful when you need a fast status check.

When you open the Simple tab for a worker, amux synthesizes a plain-English summary from three sources:

  • The last message sent to the agent -- the task or prompt it is currently working on
  • Recent context -- the most relevant recent tool calls and outputs, distilled without the noise
  • Timestamped history -- a lightweight log of what the agent accomplished over its current session, so the summary covers more than just the last 30 seconds

The result reads like a human status update: "Refactoring the auth middleware to split token validation from session lookup. Just finished reading the existing tests. Currently editing src/auth/middleware.rs."

Why you need plain-English agent status

The terminal tab is built for debugging. It shows every tool call, every file read, every shell command -- all the detail you need when something goes wrong. But scanning raw terminal output to answer "what is this agent doing?" is slow, especially when you have 10 agents running in parallel or you are checking in from your phone.

Common scenarios where the Simple tab saves real time:

Overnight and headless agents

You kicked off 8 agents on a large refactor before going to sleep. In the morning, opening 8 terminal tabs and reading through hours of output to understand where each agent got to is 20+ minutes of work. Opening 8 Simple tabs takes under a minute and tells you the same thing in plain English.

Checking in from your phone

The amux iOS app and mobile PWA show the full dashboard including the Simple tab. When you are away from your desk -- commuting, in a meeting, at lunch -- you can open any worker's Simple tab and see a readable summary without squinting at terminal scrollback on a small screen.

Briefing a teammate on agent progress

When you need to hand off an agent mid-task or explain what a running agent has done so far, the Simple tab gives you copyable prose rather than a wall of terminal output. The summary is written to be shared.

Monitoring a fleet after a deploy

After kicking off a fleet-wide task (a migration, a sweep, a bulk refactor), the Simple tab for each worker gives you the same granularity as a human team's Slack status updates -- one sentence per person, no digging into logs.

How to use the Simple tab

  1. Open a worker in the amux dashboard. Click on any session in the sessions list. The worker pane opens on the right (or full-screen on mobile) showing the terminal output by default.
  2. Click the Simple tab. In the tab row at the top of the worker pane -- alongside Terminal, Messages, and Files -- click Simple. amux fetches the synthesis immediately. On first load this takes about one second; subsequent views are cached until the agent's context changes meaningfully.
  3. Read the summary. The summary is one to three paragraphs of plain English. If the agent is actively working, the summary focuses on its current file or subtask. If the agent has recently finished a major step, the summary describes what it completed and what it is about to do next.
  4. Set a standing prompt (optional). Click the config gear icon in the Simple tab header to open the configuration dropdown. Enter a standing prompt to shape every future summary for this worker -- for example, "always mention any blockers first" or "write for a non-engineer reader". The prompt persists until you change or clear it.
  5. Enable read-aloud on iOS. On the iOS app, tap the speaker icon in the Simple tab. The summary plays through the shared audio player at the bottom of the screen. Adjust the font size and playback speed in the config dropdown.

Simple tab configuration options

The config dropdown (the gear icon in the Simple tab header) exposes three settings per worker:

SettingWhat it doesExample value
Standing prompt A persistent instruction that shapes every summary. The model appends this to its synthesis instructions on every render. "Summarize in one sentence", "Focus on blockers", "Explain as if I am not an engineer"
Font size Controls the text size in the Simple tab pane. Defaults to the dashboard body size. Increase for phone reading. 14px (default), 16px, 18px
Detail level Controls how much context the synthesis draws on. Brief uses only the last message; Detailed draws on the full timestamped history. Brief, Standard (default), Detailed

Configuration is per-worker and persists in the amux database. You only set it once per worker.

Reading agent status aloud on iOS

The Simple tab integrates with the shared fixed-bottom audio player in the amux iOS app -- the same player used by the TTS (text-to-speech) feature for reading messages aloud.

To listen to your agent's status:

  1. Open the amux iOS app and navigate to any worker.
  2. Tap the Simple tab.
  3. Tap the speaker icon in the tab header.
  4. The summary reads through the bottom audio player. You can lock your screen -- playback continues.

This is designed for use while your agents are running overnight on your Mac. In the morning, you can hear a summary of what each agent accomplished without unlocking your phone or opening the app past the lock screen controls.

You can also queue multiple workers: tap the speaker icon for several workers in succession and they queue in the audio player. amux reads each summary in turn, naming the worker before its status ("backend-1: just finished the migration, currently verifying the index rebuild...").

Frequently asked questions

What does the amux Simple tab show?

The Simple tab shows a plain-English summary of what a specific AI agent is currently working on. It synthesizes the worker's last received message, recent context, and timestamped activity history into one readable paragraph -- no terminal output parsing required. You configure a standing prompt to control the tone and focus of the summary.

How is the Simple tab different from reading the terminal?

The terminal shows raw tool calls, file diffs, and model output -- useful for debugging, not for a quick status check. The Simple tab distills all of that into one coherent sentence or short paragraph in plain English. The difference: "Bash: git diff HEAD~3, Read: src/api/auth.rs lines 1-200, Edit: src/api/auth.rs" vs. "Tightening the auth token expiry logic, reviewing the refresh flow for edge cases."

Can I listen to the agent status on my phone?

Yes. The Simple tab integrates with the shared read-aloud player in the amux iOS app. Tap the speaker icon in the Simple tab and the current summary plays through the fixed-bottom audio player. This is designed for checking in on your agent fleet during commutes or away from your desk -- the agents keep running on your dev machine and you hear their status on your phone.

What is a standing prompt in the Simple tab?

A standing prompt is a persistent instruction you set once that shapes every summary the Simple tab generates for that worker. Examples: "Summarize in one sentence", "List any blockers first", "Explain this as if I am not an engineer". The standing prompt is per-worker and persists across sessions.

Does the Simple tab work for headless agents?

Yes -- headless Claude Code agents are exactly the scenario Simple tab was built for. When an agent is running overnight on a task with no human watching the terminal, the Simple tab lets you check in from any device and understand what the agent accomplished without needing to read raw JSONL transcripts or parse tmux scrollback.
