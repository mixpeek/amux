Claude Code Web Dashboard

Monitor status, manage tasks, review output, and control agents from any browser or phone. Claude Code is a terminal tool; amux adds the web layer.

What the Dashboard Shows

Claude Code itself has no web interface. It runs in your terminal and that is where its output lives. When you run multiple Claude Code sessions (which most serious users do), keeping track of them means switching between terminal tabs, running tmux commands, or losing track of what ran where.

amux solves this by running a local web server alongside your Claude Code sessions. Open http://localhost:8824 in any browser and you see:

  • Fleet status row: Every registered Claude Code session on one screen. Running, idle, stopped, or waiting for input, all at a glance.
  • Task board: A shared kanban for all sessions. Assign tasks to specific agents, watch them claim and complete work, and review results without touching a terminal.
  • Terminal view: Click any session to see its live output. Output streams incrementally: new lines arrive as they're produced, not on a polling interval.
  • Token spend: Per-session and total token usage, updated live.
  • Agent messages: Send a prompt to any agent directly from the browser. No terminal tab switching needed.

How to Set It Up (5 Minutes)

amux is a single binary. No Docker, no Python environment, no Node.js runtime required.

Step 1: Install amux

brew install mixpeek/amux/amux

On Linux or if you prefer manual install:

curl -fsSL https://amux.io/install.sh | bash

Step 2: Register your Claude Code project

# Register a session for your project
amux register myproject --dir ~/Dev/myproject --yolo

# --yolo means Claude Code auto-accepts tool use (expected for agent runs)
# Add more sessions for additional projects or parallel work
amux register frontend --dir ~/Dev/myproject-frontend --yolo
amux register infra --dir ~/Dev/myproject --yolo

Step 3: Start the dashboard server

amux serve

The server starts on port 8824 and stays running. Open http://localhost:8824 in your browser.

Step 4: Launch Claude Code agents

# Start an agent for a registered session
amux start myproject

# Agents appear in the dashboard immediately
# Send them work via the task board or direct message

Step 5 (optional): Add a task to the board

# From the terminal
amux board add "Migrate user schema to UUID primary keys" --session myproject

# From the dashboard: click + New Task, fill in title and session

Task Board: Assigning Work Across Agents

The kanban board is shared across all sessions. Every Claude Code agent can see the same board and claim tasks atomically. Two agents will never pick up the same item.

Tasks have four states:

  • backlog: Queued but not yet dispatched
  • todo: Ready for an agent to claim
  • doing: Actively being worked on by a specific agent
  • done: Completed, with evidence recorded by the agent

From the browser you can drag tasks between columns, filter by session, and read the full description and evidence for any completed card. Agents can also post notes to cards mid-task, which gives you a readable trail for morning review after overnight runs.

Terminal View: Reading Agent Output

Click any session row in the dashboard to expand its terminal view. Output streams to the browser as the agent produces it. You can scroll back through the full session history, not just the last screenful.

The terminal view on desktop and mobile renders output incrementally. You do not wait for a polling interval to see new lines. Since September 2026, mobile rendering also handles incremental diffs, so scrolling through a busy agent's output on your phone works the same as on desktop.

If an agent is waiting for input (a tool-approval prompt, a clarifying question), the dashboard shows a visual indicator on that session's row. You can respond directly from the browser without switching to a terminal.

Mobile Access: iPhone and Android

The amux dashboard is a Progressive Web App. Open it on your phone's browser and install it to your home screen for a full-screen, app-like experience.

On mobile you can:

  • Check agent status across your entire fleet in one view
  • Read terminal output with incremental streaming (new lines arrive as they're produced)
  • Send a message to any agent with the keyboard
  • Move tasks between board columns
  • Review token spend and cost per session

There is also a native iOS app in the App Store (amux: Agent Multiplexer) for users who prefer a native experience over the PWA.

Owner Alerts: When Agents Need You

Checking the dashboard is pull. Owner alerts are push. When an agent hits a blocker it cannot resolve, or finishes its queue and wants more work, it can send you a push notification and email directly from its CLAUDE.md instructions:

# In CLAUDE.md (configure this for any session you run unattended)
If you encounter a blocker that will stall progress for more than 30 minutes:
  amux alert "Blocked on auth schema -- need your decision" "30+ min blocker"

If you finish all tasks early:
  amux alert "Queue empty, ready for more tasks" "queue finished"

Configure the alert destination in ~/.amux/server.env:

AMUX_OWNER_EMAIL=you@example.com

The health invariant alert.channel_can_deliver verifies the alert channel is working before your next overnight run. Check it at /api/health/invariants.

Remote Access from Outside Your Network

By default the dashboard is only accessible on your local machine. For access from another device or a remote location, use Tailscale:

# Install Tailscale, then amux auto-provisions a TLS cert for your Tailscale hostname
# Your dashboard becomes accessible at https://your-machine.tail1234.ts.net:8824
# from any device on your Tailscale network

Important: the dashboard URL on your Tailscale network is reachable by anyone on that network. The URL is not publicly accessible on the internet. Do not share the URL with people who should not have access to your agent fleet.

FAQ

Does Claude Code have a built-in web dashboard?

No. Claude Code is a terminal tool. The web dashboard is provided by amux, which runs a local server alongside your Claude Code sessions and connects to them via tmux or the herdr terminal backend.

Can I monitor Claude Code from my phone?

Yes. Open the amux dashboard URL on your phone and install it as a PWA. You get a full mobile interface for monitoring agents, reading output, and sending commands. A native iOS app is also available in the App Store.

What happens if I close the browser tab?

Agents keep running. The browser tab connects to the local server for display; closing it has no effect on the Claude Code sessions. Reopen the dashboard at any time and your agents will still be there, with their full output history.

Does this work with multiple Claude Code agents at the same time?

Yes. Running multiple agents is the primary use case. Each Claude Code session appears as its own row. You can manage 2 agents or 50 from the same dashboard view.

Can I use the dashboard to run Claude Code on a remote server?

Yes. Install amux on the remote server, start the agents there, and access the dashboard from your local browser via Tailscale or a VPN. All compute stays on the server; the browser just shows you what's happening.

How is this different from community Claude Code web UIs on GitHub?

Community repos (claude-code-webui and similar) provide read-only terminal mirroring for a single session. amux is a full control plane: task board, multi-session management, agent messaging, owner alerts, cost tracking, and a native iOS app, all actively maintained.
