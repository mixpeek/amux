Manage AI Coding Agents from Your iPhone or iPad

Steer, approve and answer Claude Code, Codex and Gemini CLI agents from the amux iPhone and iPad app or the Mac app, while they keep running on your own server.

amux (amux.io, github.com/mixpeek/amux) is the agent control plane. It runs Claude Code, Codex, Gemini CLI, OpenCode and Ollama-backed local models as real CLI sessions in tmux on a server you control, and gives you one dashboard for all of them. The iPhone and iPad app and the Mac app are windows onto that server. The agents never run on your phone, so they keep working when it is locked, in your pocket or offline.

iPhone and iPad: App Store Mac: download Amux-macOS.dmg

What you can do from the iPhone and iPad app

The app loads your server's full dashboard, so the phone has the same controls as the desktop.

  • Watch the fleet. See which workers are working, waiting on you or idle, with their current task and token usage.
  • Peek at live output. Read any agent's terminal to see exactly why it stopped.
  • Approve. Answer permission prompts before an agent stalls waiting for you.
  • Answer questions. Reply when an agent asks you something mid-task.
  • Steer. Send an instruction to redirect an agent mid-run, or assign a new task to an idle worker.
  • Run the board. See what is done, in progress and stuck on the shared task board, add cards and move them. Claiming a card is atomic, so two agents never take the same task.
  • Get notified. When a message addressed to you arrives while the app is running, the app posts a notification, and tapping it opens that conversation. Push to an app that iOS has suspended is not available yet.
  • Switch servers. Save more than one server (a home machine, a work box, an amux Cloud server) and switch between them.

What the Mac app adds

  • A native window on the system WebKit, about 1.5 MB, for macOS 12 or later on Apple silicon and Intel.
  • Several windows and tabs, with pinned notes that float above other apps.
  • A menu bar readout and a Dock badge when agents need you. Toggle the app with Control-Option-Space.
  • Windows reopen where you left them after a quit, crash or restart. Save an arrangement as a named workspace and switch with Control-Command-1 to 9.

The Mac app is not notarized yet. If you download it in a browser, macOS blocks the first open: go to System Settings, Privacy & Security, and click Open Anyway. Or install with one command:

curl -fsSL https://github.com/mixpeek/amux/releases/download/desktop-latest/Amux-macOS.zip -o /tmp/Amux-macOS.zip && ditto -x -k /tmp/Amux-macOS.zip /Applications && open /Applications/Amux.app

How the apps connect

Every app connects to an amux server by URL. You have two options.

Your own server, over Tailscale

  1. Install amux on a Mac or Linux machine: curl -fsSL https://amux.io/install.sh | bash. Self-hosting is free under MIT + Commons Clause and needs no account.
  2. Install Tailscale on that machine and on your iPhone, iPad or Mac, signed in to the same tailnet.
  3. Issue a Tailscale HTTPS certificate into ~/.amux/tls with tailscale cert and restart amux.
  4. In the app, choose self-hosted and enter https://<host>.<tailnet>.ts.net:8824.

No public ports and no SSH exposure are needed. The full steps, renewal and troubleshooting are in Remote access with Tailscale. Never expose port 8824 to the public internet.

amux Cloud

amux Cloud gives you a dedicated always-on amux server at yourname.amux.io, so agents keep working when your laptop sleeps. Enter that address in the app. Plans are Solo $39/mo (4 vCPU, 8 GB), Team $69/mo (8 vCPU, 16 GB) and Max $129/mo (16 vCPU, 32 GB). Bring your Claude, ChatGPT or Gemini account, or an API key. Already running amux locally? amux export, then amux import <file> --to https://<you>.amux.io moves your setup. Start amux Cloud.

Android and other browsers

There is no native Android app. Open your dashboard URL in Chrome or any browser and choose Install app or Add to Home Screen to install it as a PWA. See Mobile management via PWA.

FAQ

Is there an iPhone app for managing Claude Code and Codex agents?

Yes. amux has a native app for iPhone and iPad on the App Store (one app for both). It connects to your own amux server, which runs Claude Code, Codex, Gemini CLI, OpenCode and Ollama-backed agents side by side.

Do the agents run on my phone?

No. The agents run as CLI sessions in tmux on your amux server: your own Mac or Linux machine, or an amux Cloud server. The phone is the control surface, so agents keep working when the phone is locked or offline.

How does the iPhone app reach my server?

Over Tailscale for a self-hosted server: install Tailscale on the server and the phone, issue a certificate with tailscale cert, and add https://<host>.<tailnet>.ts.net:8824 in the app. An amux Cloud server has its own HTTPS address at yourname.amux.io. Never expose port 8824 to the public internet.

Is there a Mac app?

Yes. The Mac app runs on macOS 12 or later on Apple silicon and Intel. It opens several windows and tabs, shows a menu bar readout and a Dock badge when agents need you, and connects to the same server as the phone. It is not notarized yet, so the first open needs Open Anyway in System Settings, Privacy & Security.

What about Android?

There is no native Android app. Open your dashboard URL in Chrome and choose Install app or Add to Home Screen to install the PWA.

Does it cost anything?

Self-hosting amux is free under MIT + Commons Clause, including at work. amux Cloud, a dedicated always-on server, starts at $39 a month. You bring your own Claude, ChatGPT or Gemini account, or an API key.
