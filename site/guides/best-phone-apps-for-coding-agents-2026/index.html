Why steer coding agents from your phone?

Coding agents now work for an hour or more without help, but they still stop to ask questions and request permission. If nobody answers, the agent sits idle. A phone client turns that idle time into progress: you approve a command from the train, answer a question at lunch, and queue the next task before bed.

Every tool below falls into one of two designs. Most make your phone a window into agents on your own computer: simple and free, but the work pauses when the computer sleeps or goes offline. The other design runs the agents on an always-on machine (a desktop that never sleeps, a VPS, or a managed server) so the phone is only for steering. That difference matters more than any feature list.

1. amux: best for running a team of agents from your phone

amux is an open-source control plane for running an AI engineering team from a single dashboard or your phone. It launches, monitors and self-heals dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, open source under MIT + Commons Clause.

On the phone you get the amux app for iPhone and iPad, or the web app installed to the home screen on Android or any browser. From there you see every agent at once, read its live terminal, answer questions, approve permission prompts, send instructions, restart a stuck session and move cards on the shared board.

  • Self-host free: curl -fsSL https://amux.io/install.sh | bash on a Mac or Linux machine, then reach it from your phone over your network or Tailscale.
  • amux Cloud: your own dedicated server at yourname.amux.io, ready in about three minutes, so agents keep running when your laptop sleeps. Solo $39/mo (4 vCPU, 8 GB), Team $69/mo (8 vCPU, 16 GB), Max $129/mo (16 vCPU, 32 GB). You sign in with your own Claude, ChatGPT or Gemini account or an API key.
  • Self-healing: amux compacts context, restarts crashed sessions and replays the last message, so a fleet can run unattended overnight.
  • Limitations: no native Android app yet (the web app covers it); a smaller community than Happy or Paseo.

Pick amux if you run more than one or two agents, want them on a shared task board, or want the work to continue while your laptop is closed. Freelancers and agencies juggling several client repos usually pick Cloud Team. More: amux iOS app, mobile guide.

2. Claude Code Remote Control: best built-in option for Claude Code

Remote Control connects the Claude app for iOS and Android, or claude.ai/code, to a Claude Code session running on your machine. Run claude remote-control in a project (or /remote-control inside a session), scan the QR code, and the conversation stays in sync between terminal, browser and phone. Server mode can host several sessions, up to 32 by default, each optionally in its own git worktree.

  • Requirements: a Claude Pro, Max, Team or Enterprise plan; API keys are not supported. Team and Enterprise owners must enable it first.
  • Limitations: Claude Code only. Your computer has to stay on and the claude process has to keep running; it reconnects after a sleep, but nothing happens while it sleeps.

Pick it if you use only Claude Code and your computer is on whenever you want the agent working.

3. Codex in the ChatGPT app: best built-in option for Codex

OpenAI’s remote connections pair the ChatGPT app on iOS or Android with the ChatGPT desktop app on a Mac or Windows PC. You continue Codex chats, read output and approve actions from the phone. Setup starts in the desktop app under Settings, then a QR code; it cannot be set up from the Codex CLI or IDE extension.

  • Limitations: Codex only, and the host must stay awake, online and signed in. A “Keep this Mac awake” option helps while plugged in. Workspace admins may need to enable it.

Pick it if you live in the ChatGPT desktop app and use only Codex.

4. Happy: best polished open-source phone client

Happy is an MIT-licensed harness for Claude, Codex and Grok with a desktop app (macOS, Windows, Linux) and native iOS and Android apps. The desktop app runs a background runtime, Happy Agent, whose sessions survive restarts, and an end-to-end encrypted relay syncs them to your phone. It is free and uses the subscriptions you already have. The original CLI (happy claude, happy codex) still works but is in maintenance mode.

  • Limitations: agents run on hardware you provide, so a sleeping laptop pauses them unless you install Happy Agent on a server you run; no kanban board across agents. Full comparison: amux vs Happy.

Pick it if you want the most popular open-source mobile client for one or two agents.

5. Paseo: best open-source client for many agent CLIs

Paseo is an Apache-2.0 agent environment with a desktop app, native iOS and Android apps, a web app and a CLI. A local daemon manages agents (Claude Code, Codex, GitHub Copilot, OpenCode, Pi and others) and clients connect directly, over Tailscale, or through an optional end-to-end encrypted relay. The project says it has no telemetry.

  • Limitations: the daemon has to run on a machine that stays on if you want work to continue; you set that machine up yourself.

Pick it if you switch between many agent CLIs and want one open-source app for all of them.

6. HAPI: best local-first, self-hosted option

HAPI describes itself as a local-first alternative to Happy. It supports a long list of agents, including Claude Code, Codex, Cursor Agent, OpenCode and Copilot, with native iOS and Android apps, a web PWA and a Telegram Mini App. You run your own hub, with an encrypted relay or your own Cloudflare Tunnel or Tailscale setup.

  • Limitations: AGPL-3.0, which matters if you plan to modify and offer it to others; you operate the hub yourself.

Pick it if you want everything on your own hardware, or you like steering agents from Telegram.

7. SSH + Tailscale + tmux: the do-it-yourself route

Run your agents inside tmux on a desktop or VPS, join it and your phone to a Tailscale network, and attach from an SSH app such as Termius or Blink Shell. It works with any terminal agent and costs nothing.

  • Limitations: a terminal on a phone screen is hard to read and type in; no notifications, no overview of several agents, and no crash recovery unless you script it. See remote access with Tailscale.

Pick it if you are comfortable in a terminal and only check in occasionally.

Which one should you use?

  • One Claude Code session, computer always on: Claude Code Remote Control.
  • Codex only, from the ChatGPT desktop app: the ChatGPT app’s remote connections.
  • An open-source phone app for one or two agents: Happy, or Paseo if you use many agent CLIs.
  • Everything self-hosted, Telegram included: HAPI.
  • A team of agents with a task board that keeps working overnight: amux Cloud, or self-host amux on a machine that never sleeps.

FAQ

What is the best app to control Claude Code from my phone?

For a single session on a machine you keep on, Claude Code Remote Control is the simplest: run claude remote-control and open the session in the Claude app. For several agents at once, a task board and agents that keep running after your laptop sleeps, amux gives you an iPhone app and a web app over your own server, or an always-on amux Cloud server from $39 a month.

Can I control Codex from my phone?

Yes. The ChatGPT app for iOS and Android can control Codex running in the ChatGPT desktop app on a Mac or Windows PC. Setup starts in the desktop app, not the Codex CLI, and the host has to stay awake and online. amux, Happy, Paseo and HAPI also run the Codex CLI and let you steer it from a phone.

Do my coding agents keep running when my laptop sleeps?

Only if they run on a machine that stays awake. Claude Code Remote Control, Codex remote connections, Happy, Paseo and HAPI make your phone a window into agents on your own computer, so a sleeping laptop pauses the work. To keep agents running overnight, put them on an always-on machine: a desktop, a VPS, or an amux Cloud server at yourname.amux.io.

Is there a free way to manage coding agents from my phone?

Yes. Claude Code Remote Control comes with Claude Pro, Max, Team and Enterprise plans. Happy (MIT), Paseo (Apache 2.0), HAPI (AGPL-3.0) and amux (MIT + Commons Clause) are open source and free to self-host. SSH with Tailscale and tmux is free too. You still pay for the agent itself through your Claude, ChatGPT or Gemini plan or API key.

What can I do with coding agents from a phone?

Check what each agent is doing, answer its questions, approve or deny permission prompts, send the next instruction and review the result. With amux you can also start and restart agents, move cards on the shared task board and see the whole fleet at once.

Which phone app works with Claude Code, Codex and Gemini CLI together?

amux runs Claude Code, Codex and Gemini CLI side by side. Paseo and HAPI also support several agent CLIs, and Happy supports Claude Code and Codex. The official apps from Anthropic and OpenAI each control only their own agent.
