What's new for business owners (October 2026)

The October 2026 updates make amux more capable for unattended overnight business automation:

  • Standing approvals — pre-approve recurring agent actions (send this weekly email, file this type of PR) so agents run through the night without stalling at a permission prompt. You set the rule once; amux remembers it.
  • Vault secrets — encrypted API keys injected at agent launch, scoped per-workflow. Agents can call your CRM, payment provider, or analytics API without credentials ever appearing in agent context or git history.
  • Companion chat — ask any running agent what it's doing in plain English from the iOS app. "What did you finish tonight?" returns a plain-language summary of completed tasks.
  • Goal keeper — set a goal string for each agent run. amux checks every N turns and redirects the agent if it drifts, preventing the overnight-run-that-went-sideways failure mode.
  • Full Google Calendar sync — every Google calendar you own now syncs with the amux calendar tab. Board deadlines, scheduled agent runs, and your personal meetings appear in one view on any device.

What business owners use amux for

amux is the control plane that turns AI agents into a business operations layer. Business owners use it for four categories of work:

💻

Software development

Claude Code agents build features, fix bugs, write tests, and generate documentation — all in parallel, overnight, without developer supervision. Your backlog shrinks while you sleep.

🤖

Browser automations

AI agents drive your real Chrome browser — with your saved logins — to pull reports, fill forms, reconcile dashboards, and monitor competitors. Intent-resolved every run, not brittle coordinate replay.

📞

CRM and email

Built-in CRM with contacts, company, interaction logs, and follow-up tracking. Gmail API integration for drafting and sending email. Agents log conversations, update records, and draft outreach without leaving amux.

📅

Scheduled routines

Cron-style scheduler runs agent tasks on a repeating schedule: daily Stripe payout pull, weekly competitive report, monthly invoice generation, nightly customer data sync. Set it once, runs automatically.

Browser automations: beyond Zapier

Business owners who already use Zapier or Make hit the same wall: pre-built automations break when a UI changes, cannot handle 2FA prompts, and cannot reason about what they see on screen.

amux browser automation is different. You write a plain-English SOP — "Go to the Stripe dashboard, filter to yesterday, read the payout total, post it to the board" — and an AI agent executes it against your real Chrome session with your saved login. The agent reads the current screen and decides actions each run. It handles layout changes, loading states, and minor UI updates without you rewriting the automation.

Example automations business owners run

  • Daily payout pull: Stripe, PayPal, or Shopify → read yesterday's total → post to board or email yourself
  • Competitor price monitoring: check 5 competitor pricing pages weekly → summarize changes → post to notes
  • Customer portal reconciliation: compare your internal records with the customer-facing portal → flag discrepancies
  • Invoice generation: pull data from your accounting SaaS → generate invoice draft → email to client
  • Status page monitoring: check a vendor's status page daily → alert if anything degraded

Managing from your phone

The amux positioning is "run your business entirely from your phone." This is not marketing language. Business owners use the iOS app to:

  • Monitor the fleet: see all running agents, their status (working / needs you / stalled / done), and current task at a glance
  • Manage the board: add tasks, review completed work, approve items that need a decision
  • Steer agents: send a message to a running agent mid-task to redirect, add context, or answer a question
  • Read the morning digest: push notification at 8am (configurable) with everything that needs your attention from the overnight run
  • Review cost: check how much the night's run cost before the morning standup

Install the iOS app from the App Store or add the dashboard to your iPhone home screen as a PWA.

FAQ

Can non-technical business owners use amux?

Yes — through the web dashboard and iOS app, which require no command-line knowledge. The amux Concierge service handles the initial setup for business owners who want the system configured for them. After setup, the daily workflow is managing the board, reading the morning digest, and approving decisions — all in the mobile app.

What kinds of business tasks can AI agents automate?

AI coding agents (Claude Code, Codex): software features, bug fixes, test writing, documentation, code reviews. Browser automation agents: recurring reports from SaaS dashboards, form submissions, data reconciliation, competitor monitoring, status checks. CRM agents: contact logging, email drafting, follow-up tracking. Scheduler: any of the above on a recurring cron schedule.

How do I monitor agents when I'm away?

The iOS app gives you a full fleet dashboard on your phone. Push notifications alert you when an agent needs your input. The owner digest (configurable schedule) summarizes the overnight work and pending decisions each morning.

Can AI agents handle my email and CRM?

Yes. amux includes a built-in CRM and Gmail API integration. Agents can draft email responses with your company context, log customer interactions, update contact records, and trigger follow-up sequences. Connected Gmail accounts have real Gmail API access — emails send from your real inbox with your signature.

What does amux cost?

amux is free and open source. You pay for AI model usage — typically $10-200/month depending on agent count and hours. Claude Code Max plan ($100-200/month) eliminates per-token billing for a team of agents. The Concierge service is available for business owners who want managed setup and ongoing support.

Can agents run overnight without supervision?

Yes. Self-healing watchdog monitors agents, auto-recovers from crashes and stalls, handles the Claude Code resume dialog automatically, and alerts you only when human judgment is genuinely needed. Most overnight runs complete with zero manual intervention. The morning digest tells you what was done and what (if anything) needs your decision.

What is the amux Concierge?

The amux Concierge is a done-for-you service: the amux team sets up your fleet, maps your workflows, configures browser automations and scheduled tasks, integrates your tools, and provides ongoing management. Designed for business owners who want AI agent leverage without becoming a developer.

How is amux different from Zapier?

Zapier connects apps via pre-built triggers and fixed actions. amux uses AI agents that follow plain-English instructions and adapt to what they find — handling UI changes, edge cases, and multi-step judgment calls that rigid automations cannot. amux also builds software. They can be used together: Zapier for simple linear app-to-app workflows, amux for complex judgment-intensive tasks and software development.
