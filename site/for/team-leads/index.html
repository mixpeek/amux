amux for Engineering Team Leads

Visibility into your AI engineering team without reading every terminal. Organize agents by group, check plain-English status from your phone, and run a weekly review in under 60 seconds. Updated October 2026.

The team lead's problem with AI coding agents

You are responsible for what the team ships, but your team's AI agents live in a dozen separate terminal windows across several machines. Each developer knows what their own agents are doing. You do not. Getting a status update means interrupting someone or reading raw terminal scrollback, which is not a real option when you have eight sessions to check before a sync call. What you need is a layer above the terminals that shows you the team at a glance.

Organize your fleet by team with Groups

amux lets you assign sessions to named groups: frontend, backend, infra, or any label that maps to your team structure. The groups view shows each panel separately, with a live active/idle/waiting count and the board card totals for each group.

One tap on a group opens all of its sessions together. One tap on a session opens its live output and board context. The hierarchy lets you start at the team level and drill in only when something needs your attention.

See what every agent is doing — in plain English

Raw terminal output is not a status update. The amux Simple tab reads the live state of any agent session and produces a plain-English summary: what the agent is working on right now, what it recently completed, and where it is in the current task. No scrollback parsing, no ANSI noise.

From the Simple tab you can also configure a standing prompt that shapes how the agent summarizes its own work, and enable read-aloud so you can hear the status hands-free. For remote check-ins from your phone, this is the fastest path from "what is that session doing?" to an actual answer.

The Simple tab is available on every session from the desktop dashboard and from the iOS app. Open it, read the summary, close it. Under 10 seconds per session.

The team board: shared task tracking across agents

The amux board is a shared kanban with four columns: todo, doing, done, and verified. Every agent session writes its active task to the board and moves cards as work progresses. As team lead, you see all cards across all sessions in one view.

Cards carry the session that owns them, the task description the agent wrote when it picked up the work, and a timestamp. When something needs your input, the agent moves the card to needs-you and the board highlights it. You can respond with a steering message directly from the card without navigating to the individual session.

Unlike a separate project management tool, the board is updated by the agents themselves as they work. The status you see is the current reality, not what someone last remembered to update.

Weekly review without the meeting

The amux Review tab gives you a rolling 7-day synthesis across every session: total messages processed, token spend, cards completed by group, and a blockers section. It is the answer to "what did the AI team ship this week?" without asking anyone or reading any terminals.

The Unblock everything view surfaces every card that is waiting on a human decision into a single list. Each entry shows what the agent was doing when it stalled and what it needs. Work through the list from your phone before standup. Most blockers take 30 seconds to resolve.

For a thematic breakdown, the Trends view groups activity by what was worked on rather than by session. It answers "how much work went into authentication vs. API changes vs. bug fixes?" without any manual tagging.

Save and share your team's AI setup

amux's EnvSpec feature exports your entire AI team configuration as a YAML file: which sessions exist, their assigned groups, their standing prompts, their environment variables, and their board gates. When you onboard a new developer or set up a second machine, you restore the spec and the full team configuration appears in under a minute.

The export command:

curl -sk https://localhost:8824/api/envspec/export > team-config.yaml

And to restore it on a new machine:

curl -sk -X POST -d @team-config.yaml https://localhost:8824/api/envspec/apply

For teams that rotate agents across projects or spin up environments for specific sprints, this replaces the "here is how we set it up" doc with a runnable artifact. Check the YAML into your project repository alongside your CLAUDE.md so any team member can reproduce the full setup.

What's New — October 2026

Three features shipped in the past two months that directly affect team lead workflows:

Workspace isolation per worker

Set AMUX_WORKSPACE_ISOLATION=1 on any worker via the Scope tab and it gets its own git worktree. Parallel workers no longer share a single index — one agent's uncommitted files are invisible to every other agent. For teams running multiple agents on the same codebase simultaneously, this eliminates a significant class of false failures and cross-contamination. Each isolated worker's status card shows an "isolated" badge so you can see at a glance which sessions are running clean.

Open groups for team broadcast

Group messaging now supports open groups: any worker can post to a named group channel and all members receive the message. This is useful for cross-group notifications — a backend agent announcing a schema change that frontend agents need to know about, or an infra agent broadcasting that a shared service restarted. Configure which groups are open in the Group settings panel.

FTS5 full-text search across session history

The dashboard now indexes all session messages, logs, and transcripts with FTS5 full-text search. As team lead, you can search across your entire fleet's history — find every session that mentioned a specific file, error, or decision without opening each session's peek panel. The search panel opens with Cmd+K and works from the iOS app too. Particularly useful for post-incident review: search the error message to immediately surface which session, when, and what context surrounded it.

Voice orchestration: dispatch commands hands-free

The amux orchestrate panel accepts voice input from a mobile browser or the iOS app. Speak a command and it routes to the right session or group: "summarize what the backend group has done today," or "send the frontend session a message to pause and wait for review." The voice orchestrator handles routing, you handle the decision.

This is useful during standup when you want to pull a quick status without typing, or when you are away from your desk and need to redirect an agent that is heading in the wrong direction.

Frequently Asked Questions

Do I need to be technical to use amux as a team lead?

You need to be comfortable enough in a terminal to run an install script. Beyond that, the dashboard is a web UI accessible from any browser or the iOS app. The board, groups view, Simple tab, and Review dashboard are all point-and-click. Team leads who are comfortable reading code but not writing it every day use amux without issues.

How many agents can I manage with amux?

A single amux instance handles 10-30 concurrent sessions on a standard developer machine. For larger fleets, move amux to a dedicated VM. The dashboard and groups view scale to show all sessions simultaneously. amux is open source (MIT + Commons Clause) and free — there is no per-session charge.

Can I see what all agents are working on at once?

Yes. The board shows every session's current card in real time. The groups view collapses the fleet by team so you see frontend, backend, and infra as separate panels with live counts. For individual sessions, the Simple tab gives a plain-English summary of exactly what that agent is doing right now.

How does amux differ from GitHub Copilot for teams?

GitHub Copilot assists one developer writing code in one file at a time. amux runs full autonomous agents: sessions that read the codebase, write files, run tests, and iterate with no human in the loop per step. You use Copilot at the keyboard; you use amux to run a fleet of agents in parallel while you handle other work.

Is amux free for teams?

amux is open source (MIT + Commons Clause) and free to self-host. No per-seat fee, no SaaS subscription. Your only cost is AI API tokens billed directly by Anthropic, OpenAI, or Google. For a team running 5-10 agents during business hours, expect $100-400/month in API costs total.
