amux vs Polyscope: Which Should Run Your Coding Agents?

Polyscope and amux both run Claude Code and Codex agents in parallel and both reach your phone. Compared on interface, running many agents, phone access, where agents run, team use and price. Updated November 2026.

amux Cloud: your agents keep running when your laptop sleeps, and you steer them from any browser or your phone. You get your own server at yourname.amux.io, from $39/mo, with no per-token markup.

Start amux Cloud Self-host free on GitHub

Freelancer, agency or small team? Cloud Team is $69/mo with 8 vCPU and 16 GB RAM, one shared server your agents and teammates reach from any device, at a flat price per server instead of per seat.

Short answer: pick Polyscope if you work at a Mac or Windows desktop and want each agent in an instant copy-on-write clone of your repo, with diff review, a review agent, a built-in browser for visual edits and close Laravel tooling. Pick amux if you want to run an AI engineering team from a browser or phone: agents on a shared kanban board that resume after usage limits on their own, a scheduler, CRM, email and browser automation, and an always-on server we can run for you at one flat price.

What are amux and Polyscope?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Polyscope is a desktop app for macOS and Windows from Beyond Code, the team behind Herd, Tinkerwell and Expose. Each task gets its own workspace: a clone of your repository on a fresh branch, made instantly with copy-on-write on macOS. It runs Claude Code, OpenAI Codex and the Cursor CLI on your own subscriptions or API keys. Around the agent it adds a diff view with inline comments, a review agent, "Opinions" that has Claude and Codex debate the same question, an integrated browser where you point at an element and ask for a change, workspaces linked across repositories, and Autopilot, which breaks a goal into user stories and works through them. It also runs headless on Linux as polyscope-server.

How do you drive each one?

Polyscope is chat-first. You add a repository, press a key to create a workspace, and type a prompt; the activity feed shows the agent's messages and tool calls as it works. When it finishes you open the diff, leave inline comments for the agent, then open a pull request or merge. Its browser pane sits beside the agent so front-end changes land while you watch.

amux starts in the browser. Each agent is a worker card on the dashboard with its live terminal, and the same view works on a phone, in the iPhone and iPad app, or in the Mac app. Nothing needs to be installed on the device you steer from.

Which is better for running many agents at once?

Polyscope makes a new workspace almost free, so one person can keep many features going and throw each workspace away after merging. Autopilot takes a larger goal, splits it into user stories and works through them with crash recovery, and linked workspaces let one prompt start agents in several repositories.

amux organises the fleet around shared work. Tasks live on a kanban board that agents claim from, agents message each other and share memory, usage limits pause delivery until the provider resets, and stall alerts fire when a worker stops making progress. That suits leaving work running overnight and reading the board from your phone in the morning.

Which is better from a phone?

Polyscope's remote access is part of Pro. Your desktop app or Linux server registers with an end-to-end encrypted relay, you sign in with the same GitHub account on your phone, and you can send prompts, approve plans, answer questions, review diffs and start workspaces. On the free plan Polyscope stays on the machine it runs on.

amux has a native iPhone and iPad app and an installable web app that show every worker on your server, on every plan. On amux Cloud the phone talks to a server that is always on.

Where do the agents run?

Polyscope runs agents on your desktop by default. For a machine that stays on, install polyscope-server on a Linux VPS or dev box and keep it running with systemd; the server is free to run, and the account that connects to it needs Pro. Polyscope does not host one for you.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash. amux Cloud provisions a dedicated server at yourname.amux.io in about three minutes: 4 vCPU and 8 GB on Solo, 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running.

How much do amux and Polyscope cost?

Polyscope's Personal plan is free with unlimited projects and parallel agents, Autopilot and visual editing. Pro is $99 a year and adds phone and browser access, the headless Linux server and email support. Team is $299 a year and covers 10 seats. Model usage is billed by your provider.

amux is free to self-host with every feature. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max. The price covers the server itself, models are billed by your own provider plan, and the cost does not grow with the number of agents or teammates on the box.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel on one board every teammate can open, with no machine of your own to keep online.

When should you choose amux or Polyscope?

Choose Polyscope if

  • You work at a Mac or Windows desktop and want a polished chat-first app around Claude Code, Codex or Cursor.
  • You review every diff yourself and want inline comments and a review agent in the app.
  • You build Laravel apps and want its PHP SDK and Expose preview tunnels.
  • You want visual edits in a browser pane for front-end work.

Choose amux if

  • You want agents on one board, claiming tasks and resuming after usage limits on their own.
  • You want to steer every agent from any browser or a full phone app on the free plan too.
  • You want a scheduler, CRM, email and browser automation beside your agents.
  • You want a dedicated always-on server your team shares at one flat price: amux Cloud from $39/mo.

FAQ

Is amux a Polyscope alternative?

For running coding agents, yes. Polyscope is a desktop app that gives each agent an instant copy-on-write clone of your repo, with diff review, a review agent and a built-in browser. amux is a self-hosted server you steer from any browser, its iPhone app or its Mac app, with a shared task board, usage-limit recovery and a scheduler, and amux Cloud runs it on a dedicated always-on server.

Is Polyscope free?

The Personal plan is free, with unlimited projects and parallel agents. Pro is $99 a year and adds phone and browser access and the headless Linux server. Team is $299 a year for 10 seats. amux is free to self-host with every feature, and amux Cloud starts at $39 a month per server.

Can I use Polyscope from my phone?

Yes, on Pro. Polyscope opens in any browser through an end-to-end encrypted relay, and from a phone you can send prompts, approve plans, answer questions and review diffs. amux has a native iPhone and iPad app and a web app with every worker on your server, on every plan including the free self-hosted one.

Can Polyscope keep agents running when my laptop is closed?

Yes, if you run polyscope-server on a Linux machine you keep on and connect from a Pro account. Polyscope does not host it for you. amux self-hosted also needs a machine that stays on, and amux Cloud runs one for you from $39 a month, or $69 for the Team plan with 8 vCPU and 16 GB.

Which agents does Polyscope support?

Claude Code, OpenAI Codex and the Cursor CLI, with Kimi support listed as coming soon. amux runs Claude Code, Codex, Gemini CLI and OpenCode as workers on a shared board.
