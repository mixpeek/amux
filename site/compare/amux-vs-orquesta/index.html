What are amux and Orquesta?

amux (amux.io, github.com/mixpeek/amux) is the agent control plane from Mixpeek. It runs dozens of Claude Code, Codex, Gemini CLI, OpenCode and Ollama-backed agent sessions in parallel, gives them a shared task board with atomic claiming and agent-to-agent messages, and resumes them after usage limits and, on macOS, after a reboot. You reach it from a web dashboard or PWA, a native iPhone and iPad app or a native Mac app. It is one Rust binary with SQLite that you self-host for free on a Mac or Linux machine, or rent as an always-on amux Cloud server. The license is MIT + Commons Clause.

Orquesta calls itself "the PromptOps collaboration layer for teams that build with AI." It has a hosted product, Orquesta Cloud, and a self-hosted edition, Orquesta OSS. On the OSS page, the team submits prompts in a dashboard, agents on your machines connect to a Socket.io server with a token, run the prompt through Claude CLI and stream the logs back, and "nothing leaves your network." The OSS README describes it as the self-hosted backend that the Orquesta Terminal app connects to, with projects, multi-user auth, agent tokens and prompt history. Orquesta OSS is MIT licensed. On October 29, 2026 the repository had 2 stars; it was created on March 3, 2026 and last pushed on July 22, 2026.

Self-hosted edition versus Cloud

Orquesta splits into two products. Orquesta OSS is the self-hosted server: a dashboard, team roles, agent tokens and prompt history, with agents running Claude CLI on your machines and your own Anthropic key. Orquesta Cloud adds, per its OSS page, the embed SDK, the Batuta AI agent, quality gates, Slack and Telegram, and cloud VM provisioning, with plans from free to $12 per user per month and a custom Enterprise plan that can be self-hosted or run in your VPC.

amux Cloud is your own amux server, run for you as a dedicated always-on machine at yourname.amux.io, and amux export followed by amux import <file> --to https://<you>.amux.io moves a local setup there.

Phone, Mac and browser

Orquesta's site shows iOS and Android apps that sign in to an existing Orquesta organization, a desktop terminal app for Windows, macOS and Linux, a CLI and a Chrome extension. Whether the mobile apps connect to a self-hosted OSS server is not stated on its site. amux publishes one native app for iPhone and iPad on the App Store and a native Mac app as a DMG (macOS 12+, not notarized yet), and both connect to your own self-hosted server or your amux Cloud address. The web dashboard installs as a PWA.

Tailscale and remote machines

Orquesta OSS recommends Tailscale for agents on remote machines, with Cloudflare Tunnel, a direct IP or a VPS as alternatives, and says the agent detects on its own whether it is talking to OSS or Cloud. amux documents Tailscale for reaching the server: run tailscale cert for its ts.net name, restart amux, and open https://<host>.<tailnet>.ts.net:8824 from any tailnet device or the iOS and Mac apps. Optional switches let your own devices or invited tailnet members sign in by Tailscale identity, and amux Cloud servers can join your tailnet.

When should you choose amux or Orquesta?

Choose Orquesta if

  • Your team thinks in prompts and wants roles, prompt history and live logs in one place.
  • You want hosted plans priced per user from $5 per month, or an Enterprise plan with SAML SSO, SCIM and VPC hosting.
  • You use Cursor, Kiro or Kimi through Orquesta Cloud, or want Slack and Telegram on Cloud.
  • You want a small MIT server that runs Claude CLI on your machines.

Choose amux if

  • You want the iPhone, iPad and Mac apps to connect to the server you host yourself.
  • You run Codex, Gemini CLI, OpenCode or Ollama-backed local models next to Claude Code.
  • You want many agents claiming work from one shared board, with messages, schedules and automatic resume after usage limits.
  • You want a flat-priced always-on server: amux Cloud from $39/mo.

FAQ

Is amux an Orquesta alternative?

Yes, for running agents on machines you control. Orquesta OSS is a self-hosted prompt orchestration server whose agents run Claude CLI, and Orquesta Cloud is a paid hosted product with more agents and integrations. amux is one self-hosted server for Claude Code, Codex, Gemini CLI, OpenCode and Ollama agents on a shared task board, with native iPhone, iPad and Mac apps and an optional amux Cloud server.

Does Orquesta have an iPhone app?

Yes. Orquesta's site shows iOS and Android apps that sign in to an existing Orquesta organization. Whether they work with a self-hosted Orquesta OSS server is not stated on its site. amux's iPhone and iPad app connects to your own amux server or your amux Cloud address.

Do Orquesta and amux work over Tailscale?

Yes. Orquesta OSS recommends Tailscale for agents on remote machines. amux serves a browser-trusted certificate from tailscale cert at https://host.tailnet.ts.net:8824 and can optionally sign in your own devices or tailnet members by Tailscale identity.

Which agents does Orquesta support?

Orquesta OSS runs prompts through Claude CLI with your own Anthropic key. Orquesta's main site lists Claude Code, Cursor, Kiro, Kimi and the Orquesta CLI and says it works with any agent. amux runs Claude Code, Codex, Gemini CLI, OpenCode and Ollama-backed local models.

How much does Orquesta cost?

Orquesta OSS is free under MIT. Orquesta Cloud has a Free plan, Pro at $5 per user per month, Max at $12 per user per month and a custom Enterprise plan. amux is free to self-host, and amux Cloud is $39, $69 or $129 per month for Solo, Team or Max.

What license is amux under?

MIT + Commons Clause. You can use, modify and self-host amux for free, including at work and for commercial work you build with it. The Commons Clause forbids selling amux itself, meaning offering to others for a fee a product or service whose value comes entirely or substantially from amux. By the OSI definition, that makes amux source-available software. Orquesta OSS uses the MIT license, which has no such restriction.
