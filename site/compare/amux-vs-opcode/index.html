What are amux and Opcode?

amux is an open-source control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, open source under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Opcode calls itself "a powerful GUI app and Toolkit for Claude Code". It is a desktop app built with Tauri 2 (Rust and TypeScript) that reads your ~/.claude/projects folder and adds a visual layer on top: a project and session browser, custom agents, a usage dashboard, an MCP server manager, checkpoints and a CLAUDE.md editor. It was first released as Claudia by Asterisk; the old getAsterisk/claudia and getAsterisk/opcode repositories now redirect to winfunc/opcode. It is AGPL-3.0 licensed with about 22,400 GitHub stars. The latest release is v0.2.0 from August 31, 2025, and the last code change landed in October 2025.

Where do the agents run?

With Opcode, everything runs on your computer. The app reads Claude Code's own project folder, starts sessions and background agents as local processes, and keeps all data on your machine. That is good for privacy, and it means the agents stop when the computer sleeps or the app closes. Opcode has no hosted option.

With amux, you can self-host on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash, or let amux Cloud provision a dedicated server at yourname.amux.io in about three minutes. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we run the box. Agents keep working after you close the laptop, and you check in from the phone.

Which is better for running many agents at once?

Opcode is built for one developer working closely with Claude Code. You pick a project, resume or start a session, and keep a library of purpose-built agents you can launch in the background. Its standout features are the visual timeline, where you can checkpoint a session, fork it and diff any two points, and the usage dashboard that breaks cost down by model and project. It has no shared task list, so coordinating several agents on one codebase is up to you.

amux is built around the team. Each agent is a worker on the dashboard, work lives on a shared kanban board that agents claim tasks from, agents can message each other, and agents resume on their own after a provider usage limit resets, and on macOS every worker comes back in its own conversation after a reboot. That makes amux a good fit for leaving a software project, or a small business, running overnight and checking it from your phone in the morning.

Can you run them from your phone?

Opcode is a desktop app with no phone app. amux has a native iPhone and iPad app and a web app you can install on Android or any browser. The phone shows every agent with its live terminal, the task board, and controls to answer, approve, restart or reassign.

How much do amux and Opcode cost?

Opcode is free and open source under AGPL-3.0, and it uses the Claude Code you already pay for. amux is free to self-host; amux Cloud costs $39/mo for Solo (4 vCPU, 8 GB), $69/mo for Team (8 vCPU, 16 GB) and $129/mo for Max (16 vCPU, 32 GB), with the server included.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel without a machine on your desk.

When should you choose amux or Opcode?

Choose Opcode if

  • You use only Claude Code and want a desktop GUI for browsing, resuming and searching your sessions.
  • You want checkpoints you can fork and diff, and a cost dashboard by model and project.
  • You want custom agents with their own file and network permissions running in the background on your machine.
  • You prefer everything local with no telemetry, and an AGPL-3.0 license is fine for you.

Choose amux if

  • You run more than a few agents and want them on one board, claiming tasks and resuming on their own after usage limits.
  • You manage the work from your phone more than at a desk.
  • You want agents that keep working with your laptop closed: amux Cloud from $39/mo, or any always-on machine.
  • You use Codex or Gemini CLI alongside Claude Code.
  • You want CRM, email, browser automation and a scheduler in the same place as your agents.

FAQ

Is amux an Opcode alternative?

Yes, for running Claude Code agents. Opcode is a desktop GUI for one developer's Claude Code sessions, with custom background agents, checkpoints and a cost dashboard. amux runs a team of Claude Code, Codex and Gemini CLI agents on a shared task board, resuming after usage limits, with phone apps, and offers an always-on amux Cloud server.

Is Opcode the same as Claudia?

Yes. Claudia, the Claude Code desktop GUI from Asterisk, is now Opcode. The getAsterisk/claudia repository redirects to winfunc/opcode on GitHub.

Does Opcode have a phone app?

No. Opcode is a desktop app for macOS and Linux, and Windows from source. amux has a native iPhone and iPad app and an installable web app for Android and any browser.

Can Opcode keep agents running when my laptop is closed?

No. Opcode runs sessions and background agents as processes on your computer and has no hosted option. amux Cloud gives you a dedicated always-on server at yourname.amux.io from $39/mo, so agents keep working while your laptop sleeps.

Is Opcode free and open source?
