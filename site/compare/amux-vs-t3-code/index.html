amux vs T3 Code: Which Should Run Your Coding Agents?

T3 Code and amux both run Claude Code, Codex and other coding agents on your own machines and let you steer them from a phone. Compared on interface, running many agents, where agents run, phone access, license and price. Updated November 2026.

amux Cloud: your agents keep running when your laptop sleeps, and you steer them from any browser or your phone. You get your own server at yourname.amux.io, from $39/mo, with no per-token markup.

Freelancer, agency or small team? Cloud Team is $69/mo with 8 vCPU and 16 GB RAM, one shared server your agents and teammates reach from any device, at a flat price per server instead of per seat.

Short answer: pick T3 Code if you want a fast, free, MIT-licensed interface for one developer driving many agent threads: twelve or more agent CLIs, a worktree and a one-button pull request per thread, desktop apps for Mac, Windows and Linux, and phone apps for iOS and Android. Pick amux if you want to run an AI engineering team: agents that claim work from one shared task board and message each other, CRM, email and browser automation beside them, and an always-on server we run for you at one flat price, so nothing depends on a computer you keep awake.

What are amux and T3 Code?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

T3 Code, from the team behind T3 Chat, calls itself "the open-source control plane for coding agents". It drives the agents you are already signed in to (Claude Code, Codex, Cursor, OpenCode, Grok Build, Antigravity, Kiro, Pi, Muse Code, fx and any ACP agent) through one interface: a desktop app for macOS, Windows and Linux, a t3 server with a web client, and iOS and Android apps. Each conversation is a thread that can work in its own git worktree, switch models midway, or hand a task to another agent. It is MIT licensed, had about 63,600 GitHub stars on November 17, 2026, and shipped v0.1.10 that day.

How do you drive each one?

T3 Code is built around the conversation. You open a thread, pick an agent and a model, and talk to it; the same threads appear on the desktop app, the web client and the phone apps, all served by one t3 server. Its team treats speed as a feature and says a dropped frame is a bug. Threads that are waiting on subagents, pull request checks or background commands move to a Working section until they need you.

amux is built around the team. Each agent is a named worker card on the dashboard with its live terminal, and work arrives as cards on a shared kanban board. The same view works on a phone, in the iPhone and iPad app, or in the Mac app, and nothing needs to be installed on the device you steer from.

Which is better for running many agents at once?

T3 Code gives one person many fast threads. Each can run in its own worktree, switch between Claude and Codex, hand work to another agent, or start subagents, and scheduled tasks can start a thread at a set time or when a webhook fires, such as a failed CI job. Agents outside T3 Code can read and start threads through its MCP server.

amux adds the layer a team needs on top of that: one board the agents claim tasks from atomically, so two never grab the same work; messages and @mentions between workers for handoffs and reviews; and held delivery through a provider's usage limit, so a worker picks up again when the limit resets. That suits leaving a team running overnight and reading the board from your phone in the morning.

Which is better from a phone?

Both are good here. T3 Code has native iOS and Android apps with voice input, and its docs describe the phone as a remote: the computer running the server does the work and has to stay on. T3 Connect reaches that computer through a Cloudflare tunnel without router setup.

amux has a native iPhone and iPad app and an installable web app that show every worker on your server, and you can start, steer and read any agent from them. On amux Cloud the phone talks to a server that is always on, so the agents keep working while your laptop is closed.

Where do the agents run?

T3 Code runs agents wherever you run its server. Its own FAQ suggests a desktop, a server or a VPS, and its author says under 5% of his prompts run on his laptop. You provide and maintain that machine. T3 Code sends basic product usage events by default (provider, model, token totals, no prompts or code), which T3CODE_TELEMETRY_ENABLED=false turns off.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash. amux Cloud provisions a dedicated server at yourname.amux.io in about three minutes: 4 vCPU and 8 GB on Solo, 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running. You can export everything at any time (how).

How much do amux and T3 Code cost?

T3 Code is free, and its FAQ says there is no way to pay for it. You pay your model providers. T3 Connect is free for up to 3 machines; a T3 Chat Pro or Premier plan raises that to 10 or 100. The machine your agents run on is yours to pay for.

amux is free to self-host with every feature, and the code is on GitHub. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max. The price covers the server itself, models are billed by your own provider plan, and the cost does not grow with the number of agents or teammates on the box.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel on one board every teammate can open, without a VPS to set up and patch.

When should you choose amux or T3 Code?

Choose T3 Code if

  • You want an MIT license with no conditions.
  • You use an agent amux does not run, such as Cursor, Grok Build, Antigravity, Kiro or any ACP agent.
  • You want desktop apps on Windows and Linux, or a native Android app.
  • You want a worktree per thread and a one-button commit, push and pull request.
  • You already run a machine that stays on, and you work mostly in one-to-one threads with your agents.

Choose amux if

  • You want agents that claim work from one shared board, message each other and hold through usage limits.
  • You want a scheduler, CRM, email and browser automation beside your agents.
  • You want to steer every agent from any browser or a native iPhone app, with nothing installed on that device.
  • You run Gemini CLI or local models through Ollama.
  • You want a dedicated always-on server your team shares at one flat price, with no machine of your own to keep awake: amux Cloud from $39/mo, or $69 for Team.

FAQ

Is amux a T3 Code alternative?

For running coding agents, yes. T3 Code is a free MIT app that drives Claude Code, Codex and other agent CLIs as threads from a desktop, web or phone client. amux is a self-hosted server that runs a team of agents on a shared task board, with CRM, email and browser automation, and amux Cloud runs it on a dedicated always-on server.

Is T3 Code free?

Yes. T3 Code is MIT licensed and its FAQ says there is no way to pay for it; you pay your model providers. Its T3 Connect remote service is free for up to 3 machines, and a paid T3 Chat plan raises that to 10 or 100. amux is free to self-host, and amux Cloud costs $39 a month per server, or $69 for Team.

Is T3 Code open source?

Yes, under the MIT license, with about 63,600 GitHub stars in November 2026. amux is source-available under MIT + Commons Clause: free to use, modify and self-host, but you may not sell amux itself.

Can T3 Code keep agents running when my laptop is closed?

Only on a machine you keep running. T3 Code runs agents wherever its server runs, and its docs say the phone is a remote and the computer needs to stay on; you can install it as a background service on a desktop, server or VPS you manage. amux Cloud gives you a dedicated always-on server from $39 a month that we run for you.

Does T3 Code have a phone app?

Yes. T3 Code has iOS and Android apps and a web client at app.t3.codes, connected to your computer over T3 Connect, the local network or Tailscale. amux has a native iPhone and iPad app and an installable web app that start, steer and read every worker on your server.
