What are amux and Agent Deck?

amux is an open-source control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, open source under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Agent Deck calls itself mission control for your AI coding agents: a terminal session manager written in Go that shows every agent session in one TUI, running, waiting or idle. It runs each agent in its own tmux session, works with more than a dozen terminal agents, and adds forking, git worktrees, Docker sandboxes, MCP and skills managers, a cost dashboard, and a web mode. It is MIT licensed, has about 1.2k GitHub stars, and ships often (v1.16.34 came out on October 25, 2026).

Terminal or dashboard?

Agent Deck is built for people who already live in tmux. You press n for a new session, Enter to attach, Ctrl+Q to detach, and waiting sessions show up in your tmux status bar so you can jump to them with a number key. It has a web mode too: agent-deck web serves a browser terminal, a fleet view and the cost dashboard on port 8420, protected by a token when you bind it to the network.

amux starts from the browser. Each agent is a worker card on the dashboard with its live terminal, and the same view works on a phone, in the iPhone and iPad app, or in the Mac app. You can still attach to any agent from a terminal, but nothing requires one.

Which is better for running many agents at once?

Agent Deck's answer to scale is the conductor: a persistent agent session that watches your other sessions, answers routine questions when it is confident, and escalates the rest to you, optionally through a Telegram or Slack bot. Watchers can wake it on webhooks, GitHub events or phone pushes. Groups, fuzzy search and status filters keep a long session list manageable.

amux organises the fleet around shared work. Tasks live on a kanban board that agents claim from, agents message each other and share memory, usage limits pause delivery until the provider resets, and stall alerts fire when a worker stops making progress. A scheduler starts recurring work on its own. That suits leaving a software project, or a small business, running overnight and reviewing the board from your phone in the morning.

Where do the agents run?

Agent Deck runs where you install it: your Mac, a Linux box, or Windows through WSL. Its remote mode registers SSH servers, installs agent-deck on them and lists their sessions in your local TUI, so you can spread agents across machines you already run. There is no hosted plan.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash. amux Cloud provisions a whole dedicated server at yourname.amux.io in about three minutes: 4 vCPU and 8 GB on Solo, 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running.

How much do amux and Agent Deck cost?

Agent Deck is free. amux is free to self-host too, and both use your own model subscriptions. If you would rather not keep a machine awake for your agents, amux Cloud costs $39/mo for Solo (4 vCPU, 8 GB), $69/mo for Team (8 vCPU, 16 GB) and $129/mo for Max (16 vCPU, 32 GB). The price is per server, so it does not grow with the number of agents or projects on it.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel on one board.

When should you choose amux or Agent Deck?

Choose Agent Deck if

  • You work in tmux and want a keyboard-driven TUI over every agent session.
  • You use many different terminal agents, such as Copilot CLI, Cursor CLI, Crush or pi, beside Claude Code.
  • You want Docker sandboxes, per-session MCP servers and skills, or a token cost dashboard.
  • You already run your own servers and want one TUI across them over SSH, for free.

Choose amux if

  • You want to manage agents from a browser or a native iPhone app rather than a terminal.
  • You want agents on one board, claiming tasks and resuming after usage limits on their own.
  • You want a scheduler, CRM, email and browser automation beside your agents, to run business tasks as well as code.
  • You want a dedicated always-on server sized for a whole fleet: amux Cloud from $39/mo.

FAQ

Is amux an Agent Deck alternative?

Yes. Both manage many Claude Code, Codex, Gemini CLI and other coding agent sessions in one place. Agent Deck is a terminal TUI on top of tmux, with a web mode, Docker sandboxes, an MCP manager, a cost dashboard and a conductor session you can reach over Telegram or Slack. amux is a web and phone dashboard that runs a team of agents on a shared task board with usage-limit and reboot recovery, a scheduler and business tools, and amux Cloud gives you a dedicated always-on server.

Is Agent Deck free?

Yes. Agent Deck is MIT licensed and free, installs with one curl command or Homebrew, and runs on macOS, Linux and Windows through WSL. It has no hosted plan, so you run it on your own machine or on servers you reach over SSH. amux is also free to self-host, and amux Cloud starts at $39 a month if you want the server run for you.

Can I control Agent Deck from my phone?

Indirectly. Agent Deck's web mode serves a browser UI with push notifications, and its conductor session can answer and escalate through a Telegram or Slack bot. It has no native phone app. amux has a native iPhone and iPad app plus an installable web app that shows every agent's live terminal and the task board.

Do both keep agents running when my laptop is closed?

Only if they run on a machine that stays on. Agent Deck runs on the machine you install it on, and its remote mode manages agent-deck instances on SSH servers you provide. amux self-hosted is the same, and amux Cloud runs an always-on server for you at yourname.amux.io.

Which is better for a freelancer or small agency?

If you live in the terminal and run agents on your own boxes, Agent Deck is a strong free choice. If you want agents for several client projects on one board that you check from your phone, with nobody keeping a machine awake, amux Cloud Team is $69 a month for 8 vCPU and 16 GB RAM.
