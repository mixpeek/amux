What are amux and Mission Control?

amux (amux.io, github.com/mixpeek/amux) is the agent control plane from Mixpeek. It runs dozens of Claude Code, Codex, Gemini CLI, OpenCode and Ollama-backed agent sessions in parallel, gives them a shared task board with atomic claiming and agent-to-agent messages, and restarts them after crashes and usage limits. You reach it from a web dashboard or PWA, a native iPhone and iPad app or a native Mac app. It is one Rust binary with SQLite that you self-host for free on a Mac or Linux machine, or rent as an always-on amux Cloud server. The license is MIT + Commons Clause.

Mission Control is a self-hosted control plane for operating AI agents, from Builderz Labs and maintained by nyk. Its site headline is "Run every AI agent from one control plane." The README says it lets you dispatch tasks, inspect runs, review failures, track spend and coordinate agent runtimes from one local dashboard backed by SQLite, and that it sits above runtimes without replacing their reasoning or tool loops. It is MIT licensed and labeled alpha software whose APIs and schemas may change. On October 29, 2026 the repository had 6,410 stars; it was created on February 13, 2026, last pushed on October 28, 2026, and its latest tagged release was v2.3.0 on July 25, 2026.

Different layers of the stack

Mission Control sits above agent runtimes. You register agents, give them tasks over a REST API, and the control plane records what ran, which result passed review, and where tokens and money went. Its README says a gateway is optional for task, project, scheduler and cost work, while live session messaging needs a connected runtime gateway. It is a good match for teams already running OpenClaw, CrewAI, LangGraph or AutoGen who need governance: roles, API keys, approvals, audits and evals.

amux runs the coding agents itself. Each worker is a real Claude Code, Codex, Gemini CLI, OpenCode or Ollama-backed CLI session in tmux, and amux starts it, watches it, restarts it after crashes or usage limits, and lets you switch its model or provider while it runs. Work lives on a shared board where agents claim tasks atomically and message each other.

Phone, Mac and browser

Mission Control's interfaces are its web UI, CLI, MCP server and REST API. Native iOS, Android or Mac apps are not stated on its site. amux publishes one native app for iPhone and iPad on the App Store, a native Mac app as a DMG (macOS 12+, not notarized yet), and a web dashboard you can install as a PWA.

Self-hosting and Tailscale

Both are free to self-host. Mission Control runs from an install script, from source with Node.js 22 and pnpm, or from Docker, and its security checklist asks for a TLS reverse proxy such as Caddy, nginx or Tailscale before you expose it to a network. amux installs with curl -fsSL https://amux.io/install.sh | bash on macOS or Linux. Its Tailscale setup is documented step by step: run tailscale cert for the server's ts.net name, restart amux, and open https://<host>.<tailnet>.ts.net:8824 from any tailnet device or add it in the iOS or Mac app. amux also offers amux Cloud, a dedicated always-on server, which Mission Control does not.

When should you choose amux or Mission Control?

Choose Mission Control if

  • You operate OpenClaw, CrewAI, LangGraph, AutoGen or Claude SDK workflows and want one governance layer over them.
  • You need spend tracking, RBAC, audit history, evals and an approval gate before a task counts as done.
  • You want a REST API, MCP server and CLI as the main interfaces, or Windows and Docker installs.
  • You need a plain MIT license and can accept alpha API and schema changes.

Choose amux if

  • You run CLI coding agents such as Claude Code, Codex, Gemini CLI, OpenCode or Ollama models and want them started, watched and restarted for you.
  • You want native iPhone, iPad and Mac apps that connect to your own server.
  • You want a documented Tailscale HTTPS setup with optional sign-in by Tailscale identity.
  • You want an always-on server without running one: amux Cloud from $39/mo.

FAQ

Is amux a Mission Control alternative?

For coding agents, yes. Mission Control is a governance layer over agent runtimes such as OpenClaw, CrewAI, LangGraph, AutoGen, Claude Code and Codex, with task review, spend tracking, RBAC and audits. amux runs the coding agent CLIs itself on a shared task board, with native iPhone, iPad and Mac apps and an optional amux Cloud server.

Does Mission Control have an iPhone or Mac app?

Native iOS, Android or Mac apps are not stated on its site. Its interfaces are a web UI, CLI, MCP server and REST API. amux has a native iPhone and iPad app on the App Store and a native Mac app.

Do Mission Control and amux work over Tailscale?

Mission Control's security checklist lists Tailscale as one way to put the dashboard behind TLS. amux documents a full Tailscale setup that serves a browser-trusted certificate at https://host.tailnet.ts.net:8824, with optional sign-in by Tailscale identity.

Is Mission Control production ready?

Its README calls it alpha software and says APIs, schemas and configuration may change between releases.

Is Mission Control free?

Yes. It is MIT licensed and free to self-host with no account. The maintainer separately offers a paid setup service. amux is free to self-host, and amux Cloud starts at $39/mo.

What license is amux under?

MIT + Commons Clause. You can use, modify and self-host amux for free, including at work and for commercial work you build with it. The Commons Clause forbids selling amux itself, meaning offering to others for a fee a product or service whose value comes entirely or substantially from amux. By the OSI definition, that makes amux source-available software. Mission Control uses the MIT license, which has no such restriction.
