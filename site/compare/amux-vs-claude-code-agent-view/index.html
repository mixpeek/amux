What are amux and Claude Code agent view?

amux is an open-source control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, open source under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Claude Code agent view is a screen built into Claude Code, opened with claude agents. Anthropic's docs describe it as one screen for all your background sessions: what is running, what needs your input, and what is done. You type a prompt to dispatch a new background session, press Space to peek at one and reply, or attach to the full conversation. A supervisor process runs the sessions without a terminal, so they keep going after you close the view. It lists sessions from every project on the machine, and it is in research preview.

Where do the agents run?

Agent view runs every session on your own machine. Anthropic's docs list this as a limitation: sessions are preserved across sleep but stop if the machine shuts down. A laptop that is asleep is not working, so an agent view fleet makes progress only while your computer is awake. For work that should continue with the lid closed, Anthropic points to Projects, a public beta on Pro and Max plans that runs parallel cloud sessions.

amux runs wherever you install it. Self-hosted on a Mac or Linux machine that stays on, it keeps a fleet going overnight. amux Cloud provisions a whole dedicated server at yourname.amux.io in about three minutes: 4 vCPU and 8 GB on Solo, 8 vCPU and 16 GB on Team. Every agent runs on that one server, on one board, signed in with your own Claude, ChatGPT or Gemini account or an API key.

Which is better for managing many agents?

Agent view is a dispatcher and monitor. Every prompt you type starts its own independent session, and the list groups them by state so you can see which ones need you. It does a lot well for a built-in tool: each session moves into its own git worktree before it edits files, rows show a one-line summary and the status of any pull request the session opened, and a notification fires when a session needs input or finishes. The coordinating is still yours: you decide what each session works on.

amux is organised around the team. Each agent is a worker on the dashboard, work lives on a shared kanban board that agents claim tasks from, agents message each other, and usage limits pause delivery until the provider's reset, with stall alerts when a session stops. A scheduler starts recurring work on its own. It also mixes runtimes: a Codex or Gemini CLI agent sits on the same board as your Claude Code agents, which agent view does not cover.

Which is better from your phone?

Agent view is a terminal screen, so on a phone you would need an SSH app. Anthropic's other phone paths are Remote Control, which continues a local Claude Code session in the Claude app or a browser, and Projects for cloud threads.

amux has a native iPhone and iPad app and a web app you can install on Android or any browser. The phone shows every agent at once with its live terminal, the task board, and controls to answer, approve, restart or reassign.

How much do they cost?

Agent view comes with Claude Code, so it adds no cost of its own, but each background session uses your Claude plan's usage: Anthropic's docs note that ten agents in parallel use quota roughly ten times as fast as one. amux is free to self-host and uses the same model subscriptions. amux Cloud costs $39/mo for Solo (4 vCPU, 8 GB), $69/mo for Team (8 vCPU, 16 GB) and $129/mo for Max (16 vCPU, 32 GB), for a whole server that runs every agent and project you put on it.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel on one board, and you can invite teammates to the same server.

When should you choose amux or agent view?

Choose Claude Code agent view if

  • You use only Claude Code and want parallel sessions with nothing extra to install.
  • You work at your computer and want to check on background tasks from the terminal.
  • You want each parallel session isolated in its own git worktree and PR status on every row.

Choose amux if

  • You run Codex or Gemini CLI alongside Claude Code and want them on one dashboard.
  • You want agents on a shared task board, claiming work and resuming after usage limits, with a scheduler for recurring runs.
  • You want to manage the fleet from a native iPhone app.
  • You want the agents to keep working with your laptop closed: amux Cloud gives you a dedicated always-on server from $39/mo.
  • You want CRM, email and browser automation next to your agents, to run business tasks as well as code.

FAQ

What is Claude Code agent view?

Agent view is a built-in Claude Code screen, opened with claude agents, that lists every background Claude Code session you started on your machine across all projects, grouped by state: working, needs input, completed and so on. You can dispatch new sessions from it, peek at one and reply, or attach to the full conversation. A supervisor process keeps the sessions running without a terminal. It is in research preview.

Is amux an alternative to Claude Code agent view?

For some jobs. Agent view is the simplest way to run several Claude Code sessions in parallel on one machine from a terminal, and it costs nothing beyond your Claude plan. amux is for running a team: Claude Code, Codex and Gemini CLI agents on one shared kanban board, a scheduler, CRM, email and browser automation, a native iPhone app, and an optional always-on server with amux Cloud. Many people use both.

Do agent view sessions keep running when my laptop is closed?

They survive sleep and resume on wake, but they run on your machine, so they stop if it shuts down, and they make no progress while it sleeps. To keep agents working with the lid closed you need a machine that stays on, such as a server you self-host amux on, amux Cloud, or Anthropic's cloud sessions.

Can I use agent view from my phone?

Agent view itself is a terminal screen. From a phone, Anthropic offers Remote Control to continue a local session in the Claude app, and Projects, a public beta on Pro and Max that runs parallel cloud sessions you can steer from your phone. amux has a native iPhone and iPad app that shows every agent, its live terminal and the task board.

Does agent view work with Codex or Gemini CLI?

No. Agent view lists Claude Code background sessions only. amux runs Claude Code, Codex, Gemini CLI, OpenCode and Ollama agents side by side on one dashboard.
