What are amux and Paseo?

amux is an open-source control plane for running an AI engineering team from a single dashboard or your phone. It launches, monitors and self-heals dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, open source under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Paseo calls itself an open-source agentic development environment for desktop, mobile, web and CLI. A local server called the daemon manages your coding agents, and the desktop app, phone apps, web app and paseo CLI connect to it. Each task can get its own git worktree, and agents can start other agents and message them across providers. It is Apache-2.0 licensed, has about 21.9k GitHub stars, and ships often (v0.13.0 came out on October 24, 2026).

Where do the agents run?

Both tools keep agents working while your laptop is closed only if they run on a machine that stays on.

With Paseo, agents always run on hardware you provide. The desktop app starts the daemon on your computer, and for a server you install the CLI with npm install -g @getpaseo/cli or run its Docker image. Its security docs list a laptop, a Mac Mini, a VPS or a Docker container as places to run it. Paseo Hub, the optional managed service, starts agents from GitHub, Slack and Discord, but the Hub FAQ says a run fails, and nothing is queued, if your daemon is offline.

With amux, you can self-host the same way (install it on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash), or let amux Cloud provision a dedicated server at yourname.amux.io in about three minutes. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we run the box.

Which is better for running many agents at once?

Paseo is built around the workspace. You open a new workspace per task, each with its own worktree and branch, then read each agent's diff, run the app and check it in the built-in browser. Agents can create worktrees, start other agents and talk to them, and its skills hand a plan from one agent to another or ask a second agent for an opinion. It is strong when you are at the desk reviewing code as it lands.

amux is built around the team. Each agent is a worker on the dashboard, work lives on a shared kanban board that agents claim tasks from, and a watchdog restarts any session that crashes or runs out of context and replays its last message. You can open the board on your phone, see which agent is stuck, answer it and move on, which makes amux a good fit for leaving a software project, or a small business, running overnight.

Which is better from your phone?

Paseo's phone app is the full app, native on iOS and Android, with voice dictation. Phones reach the daemon through an opt-in relay that is end-to-end encrypted, or directly over Tailscale or another VPN.

amux has a native iPhone and iPad app and a web app you can install on Android or any browser. The phone shows every agent at once with its live terminal, the task board, and controls to answer, approve, restart or reassign. Traffic goes over HTTPS straight to your own server rather than through a relay.

How much do amux and Paseo cost?

Both are free to self-host and both use your existing model subscriptions. Paseo itself is free; hosted Paseo Hub is free for one seat and 50 agent runs a month, and Pro costs $15 per seat per month. Any always-on machine for the daemon is your own cost and upkeep. amux is free to self-host; amux Cloud costs $39/mo for Solo (4 vCPU, 8 GB), $69/mo for Team (8 vCPU, 16 GB) and $129/mo for Max (16 vCPU, 32 GB), with the server included.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel without a machine on your desk.

When should you choose amux or Paseo?

Choose Paseo if

  • You want an editor, terminals, diffs, pull requests and a browser around your agents in one desktop app.
  • You use Copilot, Pi, Amp, Cline or another agent beyond the big three.
  • You want native apps on Windows, Linux or Android.
  • You want GitHub, Slack or Discord mentions to start agents, or a TypeScript SDK to build on.
  • You prefer the Apache-2.0 license and are happy to run your own always-on machine.

Choose amux if

  • You run more than a few agents and want them on one board, claiming tasks and recovering from crashes on their own.
  • You want CRM, email, browser automation and a scheduler in the same place as your agents, to run business tasks as well as code.
  • You manage the work from your phone more than you review code at a desk.
  • You want an always-on server without maintaining one: amux Cloud from $39/mo.

FAQ

Is amux a Paseo alternative?

Yes. Both run Claude Code, Codex and other coding agents in parallel and let you steer them from your phone. Paseo is an agentic development environment with an editor, terminals, diffs and a browser in one window, running on machines you provide. amux runs a team of agents on a shared task board with self-healing and business tools, and offers an always-on amux Cloud server.

Do Paseo and amux keep agents running when my laptop is closed?

Only if the agents run on a machine that stays on. Paseo's daemon can run on a server, a VM or in Docker that you operate. amux can be self-hosted the same way, or you can use amux Cloud, a dedicated always-on server at yourname.amux.io from $39/mo.

Does Paseo host my agents?

No. Paseo's docs say agents run on your own machines. Paseo Hub, its optional managed service, adds GitHub, Slack and Discord triggers, and if your daemon is offline the run fails rather than queueing. amux Cloud runs the server for you.

Is Paseo free?

Yes. Paseo is Apache-2.0 licensed and free, and agents use your own Claude, Codex and other subscriptions. Hosted Paseo Hub has a free plan with 50 agent runs a month and a Pro plan at $15 per seat per month. amux is free to self-host; amux Cloud starts at $39/mo.

Which supports more coding agents?

Paseo. It supports Claude Code, Codex, Copilot, OpenCode, Pi, Antigravity and Muse Code natively, plus dozens more, including Gemini CLI, through its Agent Client Protocol catalog. amux runs Claude Code, Codex, Gemini CLI, OpenCode and Ollama.
