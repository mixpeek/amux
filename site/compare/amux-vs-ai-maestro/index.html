What are amux and AI Maestro?

amux (amux.io, github.com/mixpeek/amux) is the agent control plane from Mixpeek. It runs dozens of Claude Code, Codex, Gemini CLI, OpenCode and Ollama-backed agent sessions in parallel, gives them a shared task board with atomic claiming and agent-to-agent messages, and restarts them after crashes and usage limits. You reach it from a web dashboard or PWA, a native iPhone and iPad app or a native Mac app. It is one Rust binary with SQLite that you self-host for free on a Mac or Linux machine, or rent as an always-on amux Cloud server. The license is MIT + Commons Clause.

AI Maestro is an agent orchestration dashboard from FluidMind, made in partnership with 23Blocks. Its tagline is "Stop juggling terminals. Conduct your agents." The README describes a peer mesh of machines with no central server, agent-to-agent messaging over its Agent Messaging Protocol (AMP), persistent agent memory, a code graph, teams with a Kanban board, per-agent schedules, and gateways to Slack, Discord, email and WhatsApp. It is MIT licensed. On October 29, 2026 the repository had 839 stars; it was created on October 10, 2025, last pushed on October 29, 2026, and its latest release was v0.106.10 on October 28, 2026.

Which has an iPhone app and a Mac app?

AI Maestro is reached through its web dashboard. The site describes it as fully mobile-optimized with touch controls, the installer adds a Mac launcher app that opens the dashboard, and Chrome and Edge can install it as an app. A native iOS or Android app is not stated on its site.

amux publishes one native app for iPhone and iPad on the App Store and a native Mac app as a DMG (macOS 12+, Apple silicon and Intel, not notarized yet). The web dashboard installs as a PWA on Android and any browser. From the phone you can steer agents, approve actions and answer their questions.

Several machines, Tailscale and hosting

This is where AI Maestro is strongest. Every machine joins a peer mesh as an equal, remote agents appear next to local ones in one dashboard, worker machines can run headless in about 100 MB of RAM, and agents can move between hosts with their repositories. The site names Tailscale for encrypted links between machines and for steering agents from anywhere. It can also deploy agents to Docker, AWS EC2 or ECS Fargate from the dashboard. There is no hosted version yet.

amux runs as one server per machine that you self-host on macOS or Linux, or rent as an amux Cloud server at yourname.amux.io. For remote access it documents a Tailscale setup: tailscale cert for the ts.net name, after which amux serves a browser-trusted certificate at https://<host>.<tailnet>.ts.net:8824. Optional switches let your own devices or invited tailnet members sign in by Tailscale identity, and amux Cloud servers can join your tailnet. No public ports or SSH exposure are needed.

Coordinating the team

Both treat agents as a standing team. AI Maestro gives each agent long-term memory built from its own conversations, a code graph of the codebase, signed messages over AMP, a shared Kanban board and per-agent boards, and schedules that travel with the agent. amux gives agents a shared task board with atomic claiming so two agents never take the same task, agent-to-agent messages, schedules and loops, automatic recovery from crashes and usage limits, owner approval for outbound email, and browser automation with saved sign-in profiles.

When should you choose amux or AI Maestro?

Choose AI Maestro if

  • Your agents run on several machines and you want them in one peer mesh with no central server.
  • You want persistent agent memory, a code graph, or gateways to Discord or WhatsApp.
  • You want to deploy agents to Docker, AWS EC2 or ECS Fargate from the dashboard.
  • You work on Windows through WSL2, run Grok Build, or need a plain MIT license.

Choose amux if

  • You want native iPhone, iPad and Mac apps that connect to your own server.
  • You run Gemini CLI, OpenCode or Ollama-backed local models next to Claude Code and Codex.
  • You want atomic task claiming on one shared board and self-healing restarts.
  • You want an always-on server without running one: amux Cloud from $39/mo.

FAQ

Is amux an AI Maestro alternative?

Yes. Both run many coding agents as a coordinated team from one dashboard, with a Kanban board and agent-to-agent messages. AI Maestro centers on a peer mesh across several machines with agent memory and a code graph. amux centers on a shared board with atomic claiming, native iPhone, iPad and Mac apps, and an optional always-on amux Cloud server.

Does AI Maestro have an iPhone app?

A native iOS app is not stated on its site. Its site describes a mobile-optimized web dashboard with touch controls. amux has a native iPhone and iPad app on the App Store.

Do AI Maestro and amux work over Tailscale?

Yes. AI Maestro's site lists Tailscale for encrypted links between machines and for steering agents from anywhere. amux serves a browser-trusted certificate from tailscale cert at https://host.tailnet.ts.net:8824 and can optionally sign in your own devices or tailnet members by Tailscale identity.

Which agents does AI Maestro support?

Claude Code, Codex and Grok Build get launch, chat, status and approval cards. Pi, OpenClaw, GitHub Copilot CLI and any other terminal agent run in a terminal tab. amux runs Claude Code, Codex, Gemini CLI, OpenCode and Ollama-backed local models.

Is AI Maestro free?

Yes. It is MIT licensed with no seats, usage fees or paid tier, and there is no hosted version yet. amux is free to self-host, and amux Cloud starts at $39/mo.

What license is amux under?

MIT + Commons Clause. You can use, modify and self-host amux for free, including at work and for commercial work you build with it. The Commons Clause forbids selling amux itself, meaning offering to others for a fee a product or service whose value comes entirely or substantially from amux. By the OSI definition, that makes amux source-available software. AI Maestro uses the MIT license, which has no such restriction.
