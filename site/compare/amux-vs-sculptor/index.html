What are amux and Sculptor?

amux is an open-source control plane for running an AI engineering team from a single dashboard or your phone. It launches, monitors and self-heals dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, open source under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Sculptor, from the AI lab Imbue, is a desktop app for running coding agents in parallel. You connect a repo, create a workspace (by default a git worktree on its own branch), prompt an agent, review its changes and open a pull request. It integrates deeply with Claude Code and the Pi harness and can run any other terminal agent. It is MIT licensed, has about 240 GitHub stars, and ships often (v0.49.0 came out on October 21, 2026). Its README calls it an experimental research preview.

Where do the agents run?

With Sculptor, the desktop app starts its own backend on your computer, and agents work in workspaces next to your repo. An experimental setting lets the app spawn a custom backend command instead, and Imbue ships a Docker recipe for it; the docs say the same approach works in a VM or on a remote server over SSH. The app still has to be open on your desktop to drive it, and there is no hosted option.

With amux, you can self-host on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash, or let amux Cloud provision a dedicated server at yourname.amux.io in about three minutes. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we run the box. Agents keep working after you close the laptop, and you check in from the phone.

Which is better for running many agents at once?

Sculptor is built around the workspace. Each task gets an isolated copy of the repo on its own branch, and inside a workspace you can open several agents that share one working copy, for example one building a feature while another writes tests. Its docs are candid that agents editing the same file at once can conflict, so you divide the work by area. Bundled skills cover writing a spec, building mocks and a fix-bug flow that writes failing tests first, and the CI Babysitter can ask an agent to fix a red pull request while you step away.

amux is built around the team. Each agent is a worker on the dashboard, work lives on a shared kanban board that agents claim tasks from, agents can message each other, and a watchdog restarts any session that crashes or runs out of context and replays its last message. That makes amux a good fit for leaving a software project, or a small business, running overnight and checking it from your phone in the morning.

Can you run them from your phone?

Sculptor's docs describe a desktop app only, for Apple Silicon Macs and Linux, with no iOS, Android or web client. amux has a native iPhone and iPad app and a web app you can install on Android or any browser. The phone shows every agent with its live terminal, the task board, and controls to answer, approve, restart or reassign.

When should you choose amux or Sculptor?

Choose Sculptor if

  • You review code at your desk and want chat, live diffs, commits and pull requests around your agents in one desktop app.
  • You want an isolated worktree or clone per task created for you.
  • You want ready-made skills for specs, mocks and test-first bug fixes, or an agent that fixes red CI on its own.
  • You use the Pi harness, or prefer a plain MIT license.

Choose amux if

  • You run more than a few agents and want them on one board, claiming tasks and recovering from crashes on their own.
  • You manage the work from your phone more than you review code at a desk.
  • You use Codex or Gemini CLI alongside Claude Code.
  • You want CRM, email, browser automation and a scheduler in the same place as your agents, to run business tasks as well as code.
  • You want an always-on server without maintaining one: amux Cloud from $39/mo.

FAQ

Is amux a Sculptor alternative?

Yes. Both run Claude Code and other coding agents in parallel, each with its own working copy. Sculptor is a desktop app for hands-on coding with live diffs, skills and pull requests. amux runs a team of agents on a shared task board with self-healing, phone apps and business tools, and offers an always-on amux Cloud server.

Does Sculptor have a phone app?

Not in its docs. Sculptor ships desktop builds for Apple Silicon Macs and Linux. amux has a native iPhone and iPad app and an installable web app for Android and any browser.

Can Sculptor keep agents running when my laptop is closed?

Only with setup of your own. By default the backend runs on the machine with the app. An experimental custom backend command can run it in Docker, a VM or on a remote server over SSH. amux Cloud gives you a dedicated always-on server at yourname.amux.io from $39/mo.

Is Sculptor free and open source?

Yes. Sculptor is MIT licensed and a free download, built by Imbue, and agents use your own Claude or Pi provider accounts. Its README calls it an experimental research preview. amux is free to self-host under MIT + Commons Clause; amux Cloud starts at $39/mo.

Which coding agents does Sculptor support?

Sculptor integrates deeply with Claude Code and the Pi harness, and you can run any other terminal agent in its built-in terminal. amux runs Claude Code, Codex, Gemini CLI, OpenCode and Ollama.
