amux vs Claude Code Remote Control: Which Should You Use to Run Agents from Your Phone?

What are amux and Claude Code Remote Control?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Remote Control is part of Anthropic's Claude Code. It connects a Claude Code session on your machine to claude.ai/code, the Claude app for iOS and Android, the Claude desktop app or VS Code. You start it three ways: claude remote-control (or claude rc) waits in a terminal for sessions started from your other devices; claude --remote-control opens a normal local session that you can also drive remotely; and /remote-control (or /rc) hands an existing session over with its history. You connect by URL or QR code. The code, files and tools stay on your machine.

How do you start each one?

Remote Control needs nothing beyond Claude Code and a claude.ai sign-in. Run claude remote-control in a project folder, press the spacebar for a QR code, scan it with your phone, and start or continue sessions from the Claude app. Inside a session already running, /remote-control does the same for that conversation. On Team and Enterprise plans an Owner has to turn on the Remote Control toggle in the admin settings first, and organizations with Zero Data Retention or HIPAA settings cannot turn it on.

amux installs on a Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash, or you start an amux Cloud server and skip the machine. Either way you open one dashboard, in a browser, the iPhone and iPad app or the Mac app, and every agent appears as a named worker card with its live terminal.

Which is better for running many agents at once?

Remote Control's server mode can hold many sessions: up to 32 by default (--capacity changes it), and --spawn worktree gives each new session its own git worktree so parallel sessions do not edit the same files. Each session is its own conversation that you open and answer one at a time.

amux adds the layer that keeps a team of agents working without you: one board that agents claim tasks from atomically, so two never grab the same work; messages and @mentions between workers for handoffs and reviews; a scheduler for overnight and recurring runs; held delivery through a provider's usage limit, so a worker picks up again when the limit resets; and stall alerts when a worker stops making progress. It also runs Codex and Gemini CLI workers beside Claude Code, and keeps a CRM, email with owner approval for outside sends, and browser automation next to them.

What happens when your laptop sleeps?

With Remote Control, Claude keeps running on your machine the entire time, so that machine has to stay on with the claude process running. If the laptop sleeps or the network drops, the session reconnects when the machine comes back online, and the work waits until then. Your session makes outbound HTTPS requests only and opens no inbound ports, and the transcript of messages, responses and tool activity is stored on Anthropic's servers while connected.

amux self-hosted keeps running when you close the browser tab, on whatever machine you installed it on. amux Cloud removes the machine from the problem: it provisions a dedicated server at yourname.amux.io in about three minutes, 4 vCPU and 8 GB on Solo or 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running and patched, so agents keep working overnight and your phone reaches them from anywhere. You can export everything at any time (how).

How much do amux and Remote Control cost?

Remote Control is included in Claude Pro, Max, Ultra, Team and Enterprise plans, with nothing extra to pay. Usage counts against your Claude plan as any Claude Code session does, and you supply the computer that stays on.

amux is free to self-host with every feature, and the code is on GitHub. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max. The price covers the server itself, models are billed by your own provider plan, and the cost does not grow with the number of agents or teammates on the box.

For freelancers and agencies running agents across several client repos, Cloud Team is one always-on server every teammate can open, at $69 a month, with no Mac to leave awake and no VPS to set up and secure.

When should you choose amux or Remote Control?

Choose Claude Code Remote Control if

  • You only use Claude Code and already have an eligible Claude plan.
  • You work on a computer that stays on, such as a desktop or a server you already run.
  • You want to continue a session from the Claude app with nothing else to install.
  • You want a handful of parallel sessions, each in its own worktree, and you answer them yourself.

Choose amux if

  • You want agents that keep working while your laptop sleeps, without leaving a Mac awake.
  • You want agents that claim work from one shared board, message each other and hold through usage limits.
  • You run Codex or Gemini CLI as well as Claude Code, or sign in with an API key.
  • You want a scheduler, CRM, email and browser automation beside your agents.
  • You want an always-on server without running one: amux Cloud from $39/mo, or $69 for a team.

FAQ

What is Claude Code Remote Control?

A Claude Code feature that lets you continue a session running on your own machine from claude.ai/code, the Claude app for iOS and Android, the Claude desktop app or VS Code. You start it with claude remote-control (server mode), claude --remote-control, or /remote-control inside a session, and connect by URL or QR code. Claude keeps running locally the whole time.

Is amux a Claude Code Remote Control alternative?

For steering coding agents from your phone, yes, and the two can also be used together. Remote Control connects the Claude apps to Claude Code sessions on a machine you keep on. amux runs a team of Claude Code, Codex and Gemini CLI workers on a shared task board with a scheduler, CRM, email and browser automation, and amux Cloud runs it on a dedicated server that stays on without your laptop.

Does Claude Code Remote Control work when my laptop is closed?

No. Anthropic's docs say your computer must stay on and the claude process must keep running. If the laptop sleeps or the network drops, the session reconnects when the machine comes back online. To keep agents working while you sleep, run them on a machine that stays on, such as a self-hosted amux server or an amux Cloud server from $39 a month.

Which plans include Claude Code Remote Control?

Anthropic lists Pro, Max, Ultra, Team and Enterprise plans, and API keys are not supported. On Team and Enterprise an Owner must turn on the Remote Control toggle first, and it is not available through Bedrock, Google Cloud, Microsoft Foundry or a custom base URL. amux works with your own Claude, ChatGPT or Gemini sign-in or an API key.

Can Remote Control run several sessions at once?

Yes, in server mode. claude remote-control accepts up to 32 concurrent sessions by default (set with --capacity), and --spawn worktree gives each new session its own git worktree. An interactive session started with --remote-control or /remote-control carries one remote session. All of them are Claude Code sessions.
