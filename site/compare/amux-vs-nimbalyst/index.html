What are amux and Nimbalyst?

amux is an open-source control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, open source under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Nimbalyst is an open-source visual workspace for building with Codex, Claude Code, OpenCode and other coding agents. It started as Crystal, a desktop app for running Claude Code and Codex sessions in parallel git worktrees, which is now Nimbalyst. It is an Electron desktop app for macOS, Windows and Linux with an iOS companion app, MIT licensed, free for individuals, with about 2,000 GitHub stars (Crystal has about 3,100) and frequent releases (v0.81.7 came out on October 16, 2026).

Where do the agents run?

With Nimbalyst, agents run inside the desktop app on your Mac, Windows or Linux computer, each session in its own git worktree, using your own Claude Code or Codex subscription or API key. The iOS companion reaches those sessions, but the agents run on that computer, so it has to stay on for them to keep working. Nimbalyst's paid plan hosts a shared team wiki, not your agents.

With amux, you can self-host on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash, or let amux Cloud provision a dedicated server at yourname.amux.io in about three minutes. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we run the box. Agents keep working after you close the laptop, and you check in from the phone.

Which is better for running many agents at once?

Nimbalyst is built around the documents your agents produce. You run several sessions at once, each in a worktree, track them on a session kanban, and link sessions to the files they touched. Its strength is review: you open a plan, a mockup or a diagram in a visual editor, see the agent's proposed edits as red and green changes, and accept or reject each one. Task trackers for plans, bugs and features are files your agents read and update alongside you.

amux is built around the team. Each agent is a worker on the dashboard, work lives on a shared kanban board that agents claim tasks from, agents can message each other, and agents resume on their own after a provider usage limit resets, and on macOS every worker comes back in its own conversation after a reboot. That makes amux a good fit for leaving a software project, or a small business, running overnight and checking it from your phone in the morning.

Can you run them from your phone?

Both have an iPhone app. Nimbalyst's iOS companion shows which agents need you and which are still working, lets you reply by text or voice, swipe through diffs, queue the next task, and sends a push when an agent is waiting. amux has a native iPhone and iPad app and a web app you can install on Android or any browser; the phone shows every agent with its live terminal, the task board, and controls to answer, approve, restart or reassign. The difference is what the phone connects to: a desktop that must stay on, or an amux server that can run in the cloud.

When should you choose amux or Nimbalyst?

Choose Nimbalyst if

  • You want to edit specs, mockups, diagrams and code visually alongside your agents and approve their changes as red and green diffs.
  • You work at your desk on Mac, Windows or Linux and want git, a terminal and worktrees in the same app.
  • You want to build your own editors with an extension SDK, or keep a wiki your agents write for you.
  • You used Crystal and want its successor, or prefer a plain MIT license.

Choose amux if

  • You run more than a few agents and want them on one board, claiming tasks and resuming on their own after usage limits.
  • You manage the work from your phone more than you review it at a desk.
  • You want agents that keep working with your laptop closed: amux Cloud from $39/mo, or any always-on machine.
  • You want CRM, email, browser automation and a scheduler in the same place as your agents, to run business tasks as well as code.
  • You use Gemini CLI or Ollama alongside Claude Code and Codex.

FAQ

Is amux a Nimbalyst alternative?

Yes. Both run Claude Code, Codex and other coding agents in parallel, each in its own working copy, and both track sessions on a kanban board. Nimbalyst is a desktop workspace for editing the agents' work visually: markdown, mockups, diagrams and code with red and green diffs. amux runs a team of agents that resume after usage limits, with phone apps and business tools, and offers an always-on amux Cloud server.

Is Nimbalyst the same as Crystal?

Yes. Crystal, the desktop app for running Claude Code and Codex sessions in parallel git worktrees, is now Nimbalyst. The Crystal repository says so in its description and points to nimbalyst.com.

Does Nimbalyst have a phone app?

Yes. Nimbalyst has an iOS companion app that shows which agents need you, lets you reply by text or voice, swipe through diffs and queue the next task, and sends a push when an agent is waiting. The agents themselves run in the desktop app. amux has a native iPhone and iPad app and an installable web app for Android and any browser.

Can Nimbalyst keep agents running when my laptop is closed?

Nimbalyst is a desktop app for macOS, Windows and Linux, and it does not offer hosting for your agents. amux Cloud gives you a dedicated always-on server at yourname.amux.io from $39/mo, so agents keep working while your laptop sleeps.

Is Nimbalyst free and open source?

Yes. The Nimbalyst app is MIT licensed and free for individuals, with no feature limits, and you bring your own Claude Code or Codex subscription or API key. Wiki Teams, a shared wiki for a team, is a paid plan at $20 per user per month, free during its beta. amux is free to self-host under MIT + Commons Clause; amux Cloud starts at $39/mo.
