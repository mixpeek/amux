amux vs Vibe Kanban

What changed after the shutdown, and how to pick a replacement. Updated October 2026.

Quick answer: bloop, the company behind Vibe Kanban, shut down in April 2026. Vibe Kanban lives on as a community-maintained, local-only open-source project, and its cloud boards, comments and team features are gone. If you used it to plan an issue, run one agent on it and review the diff, the community edition still covers that. If you want a board your agents work from on their own, with messages between agents, schedules, usage-limit resume and your phone, amux does that on macOS or Linux, free to self-host.

What happened to Vibe Kanban

On April 10, 2026, bloop announced it was shutting down because it could not find a business model for a product whose users were mostly on the free plan. The announcement made four practical changes:

  • The project continues as open source and community maintained, with a community roadmap promised.
  • The latest version added a data export.
  • Remote services (kanban issues, comments, projects and organisations) stayed up for 30 days, then Vibe Kanban moved to a fully local architecture.
  • Local workspaces keep working, and paid subscriptions were ended and recent invoices refunded.

So the single-developer, local loop survives. Shared team boards hosted by bloop do not.

What Vibe Kanban does well

Vibe Kanban was built around the idea that engineers now spend most of their time planning and reviewing agent work. You write an issue, start a workspace where an agent gets its own branch, terminal and dev server, then review the diff with inline comments that go straight back to the agent. A built-in browser previews the running app, and it opens the pull request for you. It supports more agent CLIs than almost anything else, and npx vibe-kanban gets you started in one command.

If that review loop is what you liked, keep using the community edition locally. Nothing about the shutdown stops it from working on your machine.

What amux does differently

In amux the board belongs to the agents as much as to you. A worker claims a card atomically, does the work, attaches evidence and moves it on, so ten agents can drain a backlog without two of them taking the same task. Agents message each other to hand off or unblock, schedules start work at set times, and agents resume on their own after a usage limit resets, with stall alerts when one stops, so runs survive the night.

It is open source and self-hosts on macOS or Linux as one Rust binary with SQLite. You supervise from the web dashboard, the free iOS app or the PWA. For a team board that stays up when laptops close, amux Cloud runs your own amux server at yourname.amux.io from $39 a month.

Which should you choose?

  • Stay on Vibe Kanban (community edition) if you work alone, start each agent yourself, and value inline diff review and live preview most.
  • Choose amux if you want agents working through a backlog on their own, coordinating with each other, running on a schedule or overnight, or supervised from your phone, or if you lost Vibe Kanban's shared team boards.
  • Use both if you like Vibe Kanban for hands-on review of a single feature and want amux running the standing fleet.

Moving open issues to amux

There is no one-click importer. Export your data from the latest Vibe Kanban, install amux, and recreate the open issues as board cards from the CLI (amux board add "title") or with a short script against the board REST API. Then start a worker and it will pick up cards from todo.

curl -fsSL https://amux.io/install.sh | bash
# then open https://localhost:8824

The installer asks before installing Rust or tmux. You need at least one agent CLI. See the getting started guide or how to run an AI engineering team.

FAQ

Is Vibe Kanban shut down?

bloop, the company behind Vibe Kanban, shut down on April 10, 2026. The project continues as open source and community maintained. Its remote services (cloud kanban issues, comments, projects and organisations) were removed after 30 days, and Vibe Kanban moved to a fully local architecture. Local workspaces keep working.

What is the best Vibe Kanban alternative?

It depends on what you used it for. If you mostly ran one agent per task and reviewed its diff, the community edition of Vibe Kanban still does that locally, and Conductor is a Mac app with a similar flow. If you want a board your agents work from on their own, with atomic task claiming, agent-to-agent messages, schedules, usage-limit resume and phone access, amux is built for that, on macOS or Linux, self-hosted for free or on amux Cloud.

What is the difference between amux and Vibe Kanban?

Vibe Kanban is a planning and review interface: you create kanban issues, start a coding agent in a workspace for each one, review the diff with inline comments, preview the app and open a pull request. amux is a control plane for an AI engineering team: agents claim cards from a shared board themselves, message each other, run on schedules, resume after usage limits, and you supervise from a web dashboard or your phone.

Does amux import Vibe Kanban data?

No. amux does not have a Vibe Kanban importer. Vibe Kanban's latest version includes a data export, and amux board cards can be created from the CLI or the REST API, so a short script can recreate open issues as cards.

Is amux free?

Yes. amux is open source (MIT plus the Commons Clause) and free to self-host with every feature: curl -fsSL https://amux.io/install.sh | bash. amux Cloud, your own always-on amux server at yourname.amux.io, starts at $39 per month for teams that want agents running when laptops are closed.
