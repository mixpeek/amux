What are amux and CodeAgentSwarm?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

CodeAgentSwarm is a desktop app for macOS 12+, Windows 10/11 and Linux that runs several coding CLIs as independent terminals in one workspace. It supports twelve: Claude Code, Codex CLI, Antigravity CLI, OpenCode, Kimi Code, Grok Build, Cursor Agent, Muse Code, Pi, Devin CLI, GitHub Copilot CLI and Cline. It adds desktop notifications, live diffs per terminal, a git worktree per session, a Turbo mode that auto-approves routine operations, a kanban board agents update over MCP, and one searchable conversation history across every agent. Version 2.4.0 added coordinator agents that split a goal into worker sessions and a daily budget per provider; 2.5.0 added scheduled conversations. It is closed source and in open beta.

How do you drive each one?

CodeAgentSwarm is a window you keep open. Each terminal runs one agent on one project, its title says what the agent is doing, and live diffs show each change as it lands. Notifications tell you when an agent finishes or stops for a permission, and Turbo mode approves routine operations while blocking pushes to protected branches and destructive deletes. Its pitch is supervision: every agent, every diff and every notification in one view.

amux starts in the browser. Each agent is a worker card on the dashboard with its live terminal, and the same view works on a phone, in the iPhone and iPad app, or in the Mac app. Nothing needs to be installed on the device you steer from.

Which is better for running many agents at once?

The two have converged. Both have a kanban board the agents read and update, both can let one agent plan work for others, and both schedule runs. CodeAgentSwarm's coordinators open worker sessions in the background and report back in chat, and its Auto lane starts as many queued tasks at once as you allow. Its daily budget spreads your provider quota across the week so the agents do not burn it by lunch.

The difference is where the work lives. CodeAgentSwarm runs on your computer while the app is open, and its own docs say a schedule missed while the app was closed runs once when it reopens. amux runs as a server: agents claim tasks from the board, resume when a usage limit resets, restart after a crash or reboot, and stall alerts fire when a worker stops making progress. That suits leaving a team running overnight and reading the board from your phone in the morning.

Which is better from a phone?

CodeAgentSwarm's Mobile Connect is in alpha. A web beta is open to every account, native iOS and Android access is by request, and the desktop app has to stay open for it to work. You can also manage schedules from your phone.

amux has a native iPhone and iPad app and an installable web app that show every worker on your server, and you can start, steer and read any agent from them. On amux Cloud the phone talks to a server that is always on, so the agents keep working while your laptop is closed.

Where do the agents run?

CodeAgentSwarm runs every agent on your own computer, on the provider subscriptions you already pay for. It has no cloud execution of its own.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash. amux Cloud provisions a dedicated server at yourname.amux.io in about three minutes: 4 vCPU and 8 GB on Solo, 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running. You can export everything at any time (how).

How much do amux and CodeAgentSwarm cost?

CodeAgentSwarm is free during its open beta, with the Pro features unlocked when you sign up. Its pages do not say what Pro will cost after the beta. You pay your model providers directly.

amux is free to self-host with every feature, and the code is on GitHub. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max. The price covers the server itself, models are billed by your own provider plan, and the cost does not grow with the number of agents or teammates on the box.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel on one board every teammate can open, with no desktop app that has to stay open.

When should you choose amux or CodeAgentSwarm?

Choose CodeAgentSwarm if

  • You want a desktop app on Windows as well as Mac and Linux.
  • You use an agent amux does not run, such as Cursor Agent, Devin CLI, Copilot CLI, Cline or Kimi Code.
  • You want to watch every diff live and get a notification the moment any agent needs you.
  • You want one searchable history across every agent, and a daily quota budget per provider.
  • Your agents only need to run while you are at your computer, and closed-source beta software is acceptable.

Choose amux if

  • You want agents that keep working, resume after usage limits and restart after a crash, with no app left open.
  • You want a scheduler, CRM, email and browser automation beside your agents.
  • You want to read and self-host the source.
  • You want to steer every agent from any browser or a native iPhone app, with nothing installed on that device.
  • You want a dedicated always-on server your team shares at one flat price: amux Cloud from $39/mo, or $69 for Team.
