What are amux and CloudCLI?

amux is an open-source control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, open source under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

CloudCLI, until recently called Claude Code UI, describes itself as a desktop and mobile UI for Claude Code, Cursor CLI and Codex. The open-source UI (siteboon/claudecodeui) runs with npx @cloudcli-ai/cloudcli, finds every session in your ~/.claude folder, and reads and writes the same config Claude Code uses. It is AGPL-3.0 licensed, has about 14.3k GitHub stars, and ships often (v1.37.6 came out on October 27, 2026). The same UI powers CloudCLI Cloud, a hosted service that runs your agents in persistent containers.

Where do the agents run?

Both tools offer the same two choices: run it yourself, or pay them to run it.

CloudCLI self-hosted runs on your machine with npm, or in an experimental Docker sandbox (a microVM through Docker's sbx CLI). Its own comparison table says both need the machine to stay on, and phones reach it through any browser on your network. CloudCLI Cloud gives each environment its own persistent container with 2 CPU cores and 4 GB RAM, reachable from a browser, VS Code over SSH, the REST API or n8n.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash. amux Cloud provisions a whole dedicated server at yourname.amux.io in about three minutes: 4 vCPU and 8 GB on Solo, 8 vCPU and 16 GB on Team. Every agent runs on that one server, on one board. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we run the box.

Which is better for running many agents at once?

CloudCLI is organised around projects and sessions. You pick a project, open or resume a session, and work in it with the chat, file tree, Git panel and shell side by side. It is strong when you want an IDE feel for one agent at a time from any device. Coordination across agents comes from plugins, such as the community task queue and GitHub Issues board.

amux is organised around the team. Each agent is a worker on the dashboard, work lives on a shared kanban board that agents claim tasks from, agents message each other, and usage limits pause delivery until the provider's reset, with stall alerts when a session stops. A scheduler starts recurring work on its own. That makes amux a good fit for leaving a software project, or a small business, running overnight and checking it from your phone in the morning.

Which is better from your phone?

CloudCLI's phone experience is its responsive web UI, the same app as on desktop with touch navigation. Self-hosted, you open [your-ip]:port on your network; on CloudCLI Cloud you open it from anywhere. Its README says a native app is in the works.

amux has a native iPhone and iPad app and a web app you can install on Android or any browser. The phone shows every agent at once with its live terminal, the task board, and controls to answer, approve, restart or reassign.

How much do amux and CloudCLI cost?

Both are free to self-host and both use your own model subscriptions. CloudCLI Cloud is cheaper to start: Hobby is 7 EUR a month for one environment, Growth is 20 EUR for five, with extra environments at 5 EUR each, and Team is 39 EUR for five members and five environments. amux Cloud costs $39/mo for Solo (4 vCPU, 8 GB), $69/mo for Team (8 vCPU, 16 GB) and $129/mo for Max (16 vCPU, 32 GB). You pay for a whole server rather than per container, so the price does not grow with the number of agents or projects you run on it.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel on one board.

When should you choose amux or CloudCLI?

Choose CloudCLI if

  • You want a browser IDE for your agent sessions: chat, file editor, Git and shell in one window.
  • You use Cursor CLI, or want your Claude Code MCP servers and permissions managed from a UI.
  • You want a hosted environment for as little as 7 EUR a month and mostly run one or two agents.
  • You want to continue the same session in VS Code over SSH, or start agents from n8n or a REST call.

Choose amux if

  • You run more than a few agents and want them on one board, claiming tasks and resuming after usage limits on their own.
  • You want a scheduler, CRM, email and browser automation in the same place as your agents, to run business tasks as well as code.
  • You want a native iPhone app today.
  • You want a dedicated always-on server sized for a whole fleet: amux Cloud from $39/mo.

FAQ

Is amux a CloudCLI alternative?

Yes. Both let you run Claude Code, Codex and other coding agents from a browser or your phone, self-hosted for free or on a hosted plan. CloudCLI (formerly Claude Code UI) is a web IDE around your agent sessions: chat, file explorer, Git, shell and MCP settings. amux runs a team of agents on a shared task board with usage-limit and reboot recovery, a scheduler and business tools, and amux Cloud gives you a dedicated always-on server.

Is CloudCLI the same as Claude Code UI?

Yes. The open-source project siteboon/claudecodeui was renamed CloudCLI UI. It is AGPL-3.0 licensed, installs with npx @cloudcli-ai/cloudcli, and is the UI layer behind the hosted CloudCLI Cloud.

Which is cheaper, CloudCLI Cloud or amux Cloud?

CloudCLI Cloud. Its Hobby plan is 7 EUR a month for one container with 2 CPU cores and 4 GB RAM, Growth is 20 EUR for five, and Team is 39 EUR for five members. amux Cloud starts at $39 a month for a whole dedicated server with 4 vCPU and 8 GB RAM, running every agent on one board, and Team is $69 for 8 vCPU and 16 GB.

Do both keep agents running when my laptop is closed?

On their hosted plans, yes. Self-hosted, only if the machine stays on: CloudCLI's own comparison table says the npm and Docker sandbox options need the machine to stay on. amux self-hosted is the same, and amux Cloud runs the server for you at yourname.amux.io.

Does CloudCLI have a phone app?

Not a native one yet. Its README says the web UI is responsive and works in any phone browser, and a native app is in the works. amux has a native iPhone and iPad app plus an installable web app.
