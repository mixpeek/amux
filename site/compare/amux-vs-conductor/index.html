amux vs Conductor

What Conductor does well

Conductor, from Y Combinator company Melty Labs, is built for one developer driving several agents on one repository. Each workspace is a git worktree with its own branch, terminal and diff, so agents cannot step on each other's files, and the review-and-merge flow is the center of the app. It supports Claude Code, Codex and Cursor with your existing subscriptions, and its paid plans add Conductor Cloud, which keeps agents running in a hosted sandbox when you close the app.

If your day is "start five agents on five features, review each diff, merge the good ones," Conductor is a clean fit, especially if you already work on a Mac.

What amux does differently

amux treats agents as a team rather than as tabs. Work lives on a shared board: an agent claims a card atomically, does it, attaches evidence and moves it on, so ten agents can drain a backlog without two of them grabbing the same task. Agents message each other to hand off or unblock, schedules start work at set times, and usage limits pause delivery until the provider's reset, with stall alerts when a session stops, so runs survive the night.

It is free to self-host (source-available, MIT + Commons Clause) on macOS or Linux as one Rust binary with SQLite. You supervise from the web dashboard, the free iOS app or the PWA. When you want the team running around the clock, amux Cloud gives you the same server at yourname.amux.io from $39 a month, and amux export / amux import move your board, schedules and memories across.

Which should you choose?

  • Stay on Conductor for now if you already use the local Mac app and want its diff-review and merge flow; it keeps working until early 2027. New users can no longer sign up.
  • Choose amux if you want agents coordinating on a backlog, running on Linux or a server, working overnight, or managed from your phone without a paid plan.
  • Use both if you like Conductor for interactive feature work and want amux running the standing fleet: scheduled jobs, triage, test and docs work.

Moving from Conductor to amux

  1. Export first. Conductor Cloud data is deleted from November 20, 2026. In Conductor, right-click a cloud workspace and choose Transfer to local, or go to Settings → Account → Export data for an archive of everything.
  2. Install amux on the Mac you already use, or on a Linux box: curl -fsSL https://amux.io/install.sh | bash, then open https://localhost:8824.
  3. Start one worker per piece of work in the same repository, with Claude Code or Codex as the provider. If you relied on Conductor's worktree per workspace, set AMUX_WORKSPACE_ISOLATION=1 for those workers and each gets its own git worktree at origin/main.
  4. Put the work on the board instead of in tabs. Each card is one task; workers claim cards atomically, so two never take the same one.

Two gaps to know about: amux does not run Cursor agents, and it has no single diff-review-and-merge screen like Conductor's. You review on the board and in the file viewer, or in your usual git tooling.

FAQ

What is the difference between amux and Conductor?

Conductor is a Mac app for running several Claude Code, Codex or Cursor agents side by side, each in its own git worktree, and then reviewing and merging their diffs. amux is a self-hosted control plane for running an AI engineering team: agents share a task board with atomic claiming, message each other, run on schedules and resume after usage limits, on macOS or Linux, and you can supervise them from a web dashboard or your phone.

Is Conductor shutting down?

Conductor announced on November 4, 2026 that it is joining Meta. New sign-ups and app downloads stopped that day. Conductor Cloud goes read-only on November 13 and starts deleting user data on November 20. The local Mac app keeps getting new models and critical fixes until early 2027, then winds down. Export your Conductor Cloud data before November 20. amux is a self-hosted alternative that keeps running on your own machine.

Is Conductor free?

Conductor stopped taking new sign-ups on November 4, 2026, when it announced it is joining Meta. Existing free users cannot upgrade, and Pro users keep Pro features for free; Conductor Cloud subscribers get a refund when Cloud goes read-only on November 13. amux is free to self-host with every feature, and amux Cloud starts at $39 per month for a dedicated always-on server.

Does Conductor run on Linux or Windows?

Conductor's site describes it as a Mac app and lists only Mac requirements for local workspaces. amux self-hosts on macOS or Linux with one command: curl -fsSL https://amux.io/install.sh | bash. amux Cloud runs on a dedicated server you reach from any browser.

Which is better for running agents overnight?

For unattended runs, amux is built around it: usage limits pause delivery and resume at the provider's reset, stall detection alerts you when a session stops, schedules start work at set times, and the board tells each agent what to pick up next. Conductor Cloud keeps agents working when you close the app on its paid plans. Conductor's local workspaces depend on your Mac staying awake.

Can I use amux and Conductor together?

Yes. They overlap on running agents in parallel, so teams usually pick one as the place agents live. A common split is Conductor for hands-on, review-heavy feature work on a Mac, and amux for a standing fleet that works through a backlog, runs scheduled jobs and keeps going overnight.
