What are amux and Claude Code Projects?

amux is a self-hosted control plane for running a team of AI coding agents from one dashboard or your phone. It launches and monitors parallel Claude Code, Codex, Gemini CLI, OpenCode and Ollama sessions, with a shared kanban board agents claim tasks from, agent-to-agent messages, shared memory, a scheduler, email and browser automation. It is one Rust binary over tmux, runs on any Mac or Linux machine, and is source-available under MIT + Commons Clause.

Claude Code Projects is one long-running conversation in which Claude acts as a coordinator. You send it work (a bug report, a stack trace, a list of tasks) and it starts a thread for each piece or passes it to the thread already working in that area. Each thread is a separate Claude Code session, usually in Anthropic's cloud, on its own branch, and it opens a pull request when the work calls for one. Threads share the project's repositories, instructions and memory, and an Overview pane shows which finished, which pull requests are ready and which thread is waiting on you. Anthropic announced the redesign in November 2026; Projects is in public beta on Pro, Max and Ultra plans and rolling out gradually.

Who coordinates the work?

This is the main difference. In a project, Claude does the coordinating: you brief the project conversation the way you would brief a chief of staff, and it decides what becomes a thread, sends follow-ups to the thread already working in that area, and reports back. It sees what threads report, not every step they take. For a goal that splits cleanly by repository or by task (bring every service up to a new lint config, migrate the callers of an old endpoint), that saves you the dividing and the stitching.

amux puts the work on a shared kanban board. Agents claim cards, message each other and pass work along; you can run a lead agent that files and assigns cards, or describe what you want in the Intent tab and amux sends it to the right worker. Every agent and every card is visible to you and, on a shared server, to your teammates. You get more control over who does what, and you do more of the setup.

Where do the agents run?

Project threads are cloud sessions in Anthropic's cloud by default, so they keep working after you close your laptop and need nothing installed. The tradeoff is that a cloud thread starts from the project's repositories, instructions and connectors, not from your machine: your skills, settings, MCP servers and local tools are not there unless you add them to the project's environment. For a task that needs a local database or a tool behind your VPN, you can ask Claude to run that one thread on your computer through Remote Control, and then it runs only while the computer is awake.

amux runs wherever you install it, and each agent runs with the same CLI setup you use yourself. Self-hosted on a Mac or Linux machine that stays on, it keeps a fleet going overnight. amux Cloud provisions a whole dedicated server at yourname.amux.io in about three minutes: 4 vCPU and 8 GB on Solo, 8 vCPU and 16 GB on Team, signed in with your own Claude, ChatGPT or Gemini account or an API key.

Can I use Codex or Gemini CLI?

Not in a project. Threads are Claude Code sessions with Anthropic as the model provider, and Projects is not offered through Amazon Bedrock, Google Cloud or Microsoft Foundry. amux runs Claude Code, Codex, Gemini CLI, OpenCode and Ollama agents side by side on one board, so you can give each task to the agent that suits it, or keep work moving on another provider when one plan hits its limit.

How much do they cost?

Projects has no price of its own: it is part of Pro, Max and Ultra plans. Anthropic's docs warn that a project uses your plan's limits faster than single sessions, since several threads run at once, and let you pick the model and effort for the coordinator and for the threads. amux is free to self-host and uses the subscriptions or API keys you already have. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max, for the server; model usage stays on your own accounts.

When should you choose amux or Claude Code Projects?

Choose Claude Code Projects if

  • You are on Pro, Max or Ultra, use only Claude Code, and your work lives in GitHub repositories or uploaded files.
  • You want Claude to split a goal into parallel threads and return pull requests, without dividing the work yourself.
  • You want nothing to host or keep running, and you work alone.

Choose amux if

  • You want the agents, their transcripts and your code on a machine you control.
  • You run Codex or Gemini CLI alongside Claude Code and want them on one board.
  • You want teammates working on the same board and the same agents.
  • You want every agent to have your own skills, MCP servers and local tools.
  • You want agents working with your laptop closed on your own server: amux Cloud gives you a dedicated always-on server from $39/mo.

FAQ

What are Claude Code Projects?

A project is one ongoing conversation where Claude coordinates a stream of related work. You tell it what needs doing and it starts a thread for each task. Each thread is a separate Claude Code session, usually in Anthropic's cloud, on its own branch, and threads share the project's repositories, instructions and memory. It is in public beta on Pro, Max and Ultra plans.

Is amux an alternative to Claude Code Projects?

For some jobs. Projects is the simplest way to have Claude split work across parallel cloud sessions and hand back pull requests, with nothing to host. amux is for running a team of agents on a machine you control: Claude Code, Codex and Gemini CLI on one shared board, teammates on the same server, your own tools in every session, a scheduler and a native iPhone app.

Can I share a Claude Code project with my team?

Not during the beta. Anthropic's docs say a project belongs to one user, its threads cannot be shared, and there are no organization-level controls yet; Projects is not offered on Team or Enterprise plans. On amux you invite teammates to the same server, and everyone sees the same board and agents.

Do Claude Code Projects run on my own machine?

Threads run in Anthropic's cloud by default. You can ask Claude to run a single thread on your computer through Remote Control, and that thread runs only while your computer is awake. Anthropic says running threads on your machine alongside your local tools is coming soon. amux runs every agent on the machine you install it on, or on your own amux Cloud server.

Can Claude Code Projects use Codex or Gemini CLI?

No. Project threads are Claude Code sessions with Anthropic as the model provider. amux runs Claude Code, Codex, Gemini CLI, OpenCode and Ollama agents side by side.
