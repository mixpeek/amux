amux vs Jean: Which Should Run Your Coding Agents?

Jean and amux both run Claude Code, Codex and other coding agents in parallel on your laptop or your own server, and keep them working after you close the laptop. Compared on interface, running many agents, where agents run, phone access, license and price. Updated November 2026.

amux Cloud: your agents keep running when your laptop sleeps, and you steer them from any browser or your phone. You get your own server at yourname.amux.io, from $39/mo, with no per-token markup and no server of your own to run.

Freelancer, agency or small team? Cloud Team is $69/mo with 8 vCPU and 16 GB RAM, one shared server your agents and teammates reach from any device, at a flat price per server instead of per seat.

Short answer: pick Jean if you want a free, Apache-2.0 workspace built around git: a worktree per task, ten agent CLIs, AI commits, reviews, pull requests and conflict fixes, work started from GitHub, Linear or Sentry issues, and a headless server you run yourself. Pick amux if you want to run an AI engineering team: agents that claim work from one shared board and message each other, a scheduler, CRM, email and browser automation, a native iPhone app, and the option of an always-on server we run for you at one flat price.

What are amux and Jean?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Jean, from coollabsio, the team behind Coolify, calls itself "a dev environment for AI agents". It runs Claude, Codex, Cursor, OpenCode, Pi, Command Code, Grok, Kimi Code, Antigravity (beta) and Muse in parallel, each task in its own git worktree, as a Tauri desktop app or a headless jean-server on Linux. The desktop app shows local and remote projects in one sidebar, and every instance can serve its full UI in a browser with token authentication. It adds magic commands for commits, reviews, pull requests and merge conflicts, a beta "Mr. Robot" that turns open GitHub issues into worktrees and plans, and GitHub, Linear and Sentry integrations. It is Apache 2.0, had about 1,430 GitHub stars on November 20, 2026, and shipped v1.0.16 on November 15.

How do you drive each one?

Jean is organised around projects and worktrees. Each task gets its own worktree with its pull request status, diff size and labels, and inside it you open chat sessions with the agent and model you pick, in Plan, Build or Yolo mode. A command palette of editable "magic prompts" handles the git chores: investigate an issue, review a diff, write the commit, open the pull request, fix a merge conflict.

amux is organised around the team. Each agent is a named worker card on the dashboard with its live terminal, and work arrives as cards on a shared kanban board. The same view works on a phone, in the iPhone and iPad app, or in the Mac app, and nothing needs to be installed on the device you steer from.

Which is better for running many agents at once?

Jean is the stronger git workbench. One worktree per task keeps parallel agents out of each other's files, and its review, commit, pull request and auto-merge tools mean the work goes from issue to merged branch without leaving the app. Mr. Robot points that at your GitHub issue list.

amux adds the layer a team needs on top: one board the agents claim tasks from atomically, so two never grab the same work; messages and @mentions between workers for handoffs and reviews; a scheduler for overnight and recurring runs; held delivery through a provider's usage limit, so a worker picks up again when the limit resets; and stall alerts when a worker stops making progress. Beside the agents sit a CRM, email with owner approval for outside sends, and browser automation with saved sign-ins.

Where do the agents run?

Both run where you choose. Jean runs on your laptop, or as jean-server on a Linux machine (amd64 or arm64) that the desktop app can install over SSH; its site notes that the agents keep running on the server when you close the laptop. Its docs recommend Tailscale, rather than an open port, for reaching that server from elsewhere.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash. The difference is the option to skip running a server at all: amux Cloud provisions a dedicated server at yourname.amux.io in about three minutes, 4 vCPU and 8 GB on Solo or 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running and patched. You can export everything at any time (how).

How much do amux and Jean cost?

Jean is free and open source, with no paid tier; the project takes sponsorships. You pay your model providers, and for whatever server you run it on.

amux is free to self-host with every feature, and the code is on GitHub. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max. The price covers the server itself, models are billed by your own provider plan, and the cost does not grow with the number of agents or teammates on the box.

For freelancers and agencies running agents across several client repos, Cloud Team is one always-on server every teammate can open, at $69 a month, with no VPS to set up, secure and keep updated.

When should you choose amux or Jean?

Choose Jean if

  • You want an Apache-2.0 license and a tool that is free with no paid tier.
  • Your work is git-centred: a worktree per task, AI commits, reviews, pull requests and conflict fixes in one app.
  • You start work from GitHub, Linear or Sentry issues.
  • You use an agent amux does not run, such as Cursor, Pi, Grok, Kimi Code or Command Code.
  • You are happy to run and secure your own Linux server for always-on agents.

Choose amux if

  • You want agents that claim work from one shared board, message each other and hold through usage limits.
  • You want a scheduler, CRM, email and browser automation beside your agents.
  • You want a native iPhone app for every agent, with nothing installed on the device you steer from.
  • You run Gemini CLI or local models through Ollama.
  • You want an always-on server without running one: amux Cloud from $39/mo, or $69 for a team.

FAQ

Is amux a Jean alternative?

For running coding agents in parallel, yes. Jean is a free, Apache-2.0 desktop app and headless server that runs Claude, Codex, Cursor, OpenCode and six more agent CLIs, each in its own git worktree, with git, review and issue-tracker workflows built in. amux runs a team of agents on one shared task board with CRM, email and browser automation, and amux Cloud runs it on a dedicated always-on server we keep running.

Is Jean free?

Yes. Jean is open source under the Apache 2.0 license and describes itself as free forever, funded by sponsors. You pay your model providers, and for any server you run jean-server on. amux is free to self-host, and amux Cloud costs $39 a month per server, or $69 for Team.

Can Jean keep agents running when my laptop is closed?

Yes, if you run jean-server on a Linux machine you manage; its site says the work continues on the server when you close your laptop. amux does the same when self-hosted, and amux Cloud gives you a dedicated always-on server from $39 a month with nothing to install or patch.

Does Jean have a phone app?

Not a native one. Every Jean instance can serve its full UI over HTTP with token authentication, which you can open in a phone browser, ideally over Tailscale. amux has a native iPhone and iPad app and an installable web app that start, steer and read every worker on your server.

Who makes Jean?

Jean is made by coollabsio, the team behind Coolify, the self-hosted alternative to Heroku and Netlify. Its repository is github.com/coollabsio/jean.
