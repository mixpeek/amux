What are amux and HAPI?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

HAPI (tiann/hapi, AGPL-3.0, about 5,500 GitHub stars, v0.36.7 on November 24, 2026) wraps the official agent command lines instead of replacing them: Claude Code, Codex, Cursor Agent, Grok Build, OpenCode, Kimi, Copilot, Antigravity, Pi and DeepSeek Harness. A hub you run (npx @twsxtd/hapi hub --relay) stores sessions in SQLite and serves a React web app that installs as a PWA or opens as a Telegram Mini App, plus paid native iOS and Android apps. Its name is a Chinese transliteration of Happy, and it was built as a local-first alternative to it.

How do you steer agents from your phone with each one?

HAPI is built around handoff. You start an agent with hapi claude or hapi codex in your own terminal, and the same session appears in the web app or native app, where you can chat, approve tool requests with one tap, browse files and diffs, and open a terminal on the working machine. Codex sessions can be used from the terminal and the phone at the same time. The hub prints a URL and QR codes; pairing a native app needs an HTTPS hub address, which the built-in relay or your own proxy provides.

amux is built around the team. Each agent is a named worker card on the dashboard with its live terminal, and work arrives as cards on a shared kanban board. The same view works in a browser, in the iPhone and iPad app, or in the Mac app, and on amux Cloud your server is already at an HTTPS address, so there is no relay or tunnel to set up.

Which is better for running many agents at once?

HAPI shows all active and past sessions in one list, and a runner (hapi runner start) lets you start new sessions on any connected machine from your phone. Agents get MCP peer tools to find, read, message and spawn other sessions on the same hub, and namespaces let a team share one hub.

amux adds the layer that keeps a team of agents working without you: one board that agents claim tasks from atomically, so two never grab the same work; messages and @mentions between workers for handoffs and reviews; a scheduler for overnight and recurring runs; held delivery through a provider's usage limit, so a worker picks up again when the limit resets; and stall alerts when a worker stops making progress. Beside the agents sit a CRM, email with owner approval for outside sends, and browser automation with saved sign-ins.

Where do the agents run?

With HAPI, agents run on the machines where you start the CLI or a runner, and the hub can live on your desktop or on a VPS or cloud host you run. If those machines sleep, the agents stop. The optional public relay forwards encrypted traffic without hosting your history; for your own domain you put a reverse proxy, Cloudflare Tunnel or Tailscale in front of the hub.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash, and keeps running when you close the browser tab. amux Cloud skips running a machine at all: it provisions a dedicated server at yourname.amux.io in about three minutes, 4 vCPU and 8 GB on Solo or 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running and patched, so your agents keep working overnight and your phone reaches them from anywhere. How much do amux and HAPI cost?

HAPI is free and its source, including the app clients, is on GitHub under AGPL-3.0. The web app and PWA are free; the native iOS and Android apps are paid downloads (the US App Store listed the iOS app at $9.90 on November 26, 2026, and the same purchase covers the Mac app). You pay your model providers, and for any host you run the hub or agents on.

amux is free to self-host with every feature, and the code is on GitHub. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max. The price covers the server itself, models are billed by your own provider plan, and the cost does not grow with the number of agents or teammates on the box.

For freelancers and agencies running agents across several client repos, Cloud Team is one always-on server every teammate can open, at $69 a month, with no Mac to leave awake and no VPS, relay or tunnel to set up and secure.

When should you choose amux or HAPI?

Choose HAPI if

  • You want a free, self-hosted way to continue your own terminal sessions from your phone.
  • You use agents amux does not run, such as Cursor Agent, Grok Build, Kimi, Copilot, Antigravity, Pi or DeepSeek Harness.
  • You want Telegram access, a hands-free voice assistant, or a native Android app.
  • You are comfortable running a hub and a relay or tunnel yourself.

Choose amux if

  • You want agents that keep working while your laptop sleeps, without running a VPS.
  • You want agents that claim work from one shared board, message each other and hold through usage limits.
  • You want a scheduler, CRM, email and browser automation beside your agents.
  • You want an always-on server without running one: amux Cloud from $39/mo, or $69 for a team.

FAQ

What is HAPI?

HAPI (hapi.run, github.com/tiann/hapi) is a free, self-hosted tool that wraps the official Claude Code, Codex, Cursor Agent, Grok Build, OpenCode, Kimi, Copilot, Antigravity, Pi and DeepSeek Harness command lines and lets you control those sessions from a web app, a Telegram Mini App or native iOS and Android apps. Each user runs their own hub, which stores session history in SQLite. Its name is a Chinese transliteration of Happy, the project it was built as a local-first alternative to.

Is amux a HAPI alternative?

For steering coding agents from your phone, yes. HAPI focuses on handing your own agent sessions between your desk and your phone, with approvals, a remote terminal and voice control. amux runs a team of Claude Code, Codex and Gemini CLI workers on one shared task board with a scheduler, CRM, email and browser automation, and amux Cloud runs it on a dedicated server that stays on without your laptop.

Is HAPI free?

The software is free under the AGPL-3.0 license, and its web app, which installs as a PWA, is free. The native iOS and Android apps are paid downloads; the US App Store listed the iOS app at 9.90 US dollars on November 26, 2026. You pay your model providers, and for any server you run the hub on. amux is free to self-host, and amux Cloud costs 39 dollars a month per server, or 69 for Team.

Does HAPI keep agents running when my laptop is closed?

Agents run on the machines where the HAPI CLI or runner is started, so they stop when that machine sleeps. The hub can run on a VPS or cloud host, and a runner on an always-on machine can start sessions there, but you set up and maintain that host yourself. amux Cloud gives you a dedicated always-on server at yourname.amux.io with nothing to set up.

Can HAPI agents work together?

HAPI gives agents MCP peer tools (list_peers, inspect_peer, ping_peer and spawn_peer) to find, read, message and start other sessions on the same hub. It has no shared task board or scheduler. amux workers claim tasks atomically from one kanban board, message and @mention each other, and run on a built-in scheduler.
