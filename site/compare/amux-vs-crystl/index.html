amux vs crystl: Which Should Run Your Coding Agents?

crystl and amux both run a fleet of Claude Code, Codex and other coding agents in parallel. Compared on interface, running many agents, phone access, where agents run, team use and price. Updated November 2026.

amux Cloud: your agents keep running when your laptop sleeps, and you steer them from any browser or your phone. You get your own server at yourname.amux.io, from $39/mo.

Short answer: pick crystl if you work on a Mac and want a fast native terminal built around agent sessions: projects as gems, sessions as shards, floating approval cards, a searchable history, open-model support and an iPhone app, with a free tier and a $170/year Guild plan. Pick amux if you want to run an AI engineering team from any browser or phone: agents on a shared kanban board that resume after usage limits on their own, a scheduler, CRM, email and browser automation, and a dedicated always-on amux Cloud server from $39/mo so nobody keeps a laptop awake.

What are amux and crystl?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

crystl is a Metal-accelerated macOS terminal built for running AI coding agents. Projects are "gems" and each terminal session inside one is a "shard". Claude Code, Codex, Antigravity CLI and Kimi Code are first-class, any other CLI agent runs too, and it can point agents at open models through Ollama, LM Studio, vLLM or llama.cpp. It adds floating approval cards, a searchable history of every session, token tracking, schedules, an iPhone app and an orchestrator that watches worker agents. It is a commercial app with license keys and a free tier, built by agency owner Chris Bolton, and ships often (version 2.270.0 came out on November 3, 2026).

How do you drive each one?

crystl replaces your terminal. You open a project folder as a gem, start shards in it, and work in a desktop window built for agents: approval requests float on screen as cards colored by project, the history navigator searches every past conversation and tool call, and a panel shows how many tokens each turn burns. Agents running inside crystl get its docs and CLI, so you can ask one to set up a schedule or start other agents on separate branches.

amux starts in the browser. Each agent is a worker card on the dashboard with its live terminal, and the same view works on a phone, in the iPhone and iPad app, or in the Mac app. You can still attach to any agent from a terminal, but nothing requires one, and nothing needs to be installed on the device you steer from.

Which is better for running many agents at once?

crystl's paid Guild plan lets you anoint an orchestrator agent that monitors its workers and can read their terminals, with each worker in its own git worktree. crystl quest goes further with role-played agent parties that talk to you and to each other in one chat. Sequences run multi-stage agent pipelines on a schedule or a file change.

amux organises the fleet around shared work. Tasks live on a kanban board that agents claim from, agents message each other and share memory, usage limits pause delivery until the provider resets, and stall alerts fire when a worker stops making progress. That suits leaving a software project, or a small business, running overnight and reviewing the board from your phone in the morning.

Which is better from a phone?

crystl's iPhone app shows which agents need input, lets you approve access, answer questions and spawn new agents. It is free on the same Wi-Fi as your Mac; reaching the Mac from anywhere goes through an encrypted relay included with Guild. The Mac has to stay awake for any of it to work.

amux has a native iPhone and iPad app and an installable web app. On amux Cloud the server has its own HTTPS address at yourname.amux.io, so the phone talks to a machine that is always on, with nothing to relay through your laptop.

Where do the agents run?

crystl runs agents on your Mac, or on a remote machine over SSH: it sets up reverse tunnels and hooks so a home server or VPS feels like a local project. There is no hosted plan, so you provide and maintain whatever machine stays on.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash. amux Cloud provisions a dedicated server at yourname.amux.io in about three minutes: 4 vCPU and 8 GB on Solo, 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running.

How much do amux and crystl cost?

crystl's free tier includes isolated parallel shards, floating cards, the history navigator, token tracking, remote SSH, up to 3 schedules and the iPhone app over Wi-Fi. Guild is $170 a year (or billed monthly) and adds orchestration, unlimited scheduling, sequence automation, phone access from anywhere and up to 3 devices. amux is free to self-host with every feature. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max, and the price covers the server itself, so it does not grow with the number of agents on it.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel on one board that every teammate can open.

When should you choose amux or crystl?

Choose crystl if

  • You work on a Mac and want a fast, native terminal designed around agent sessions.
  • You want open models through Ollama, LM Studio, vLLM or llama.cpp beside Claude Code and Codex.
  • You like the gems and shards model, floating approval cards and a searchable history of every session.
  • You are fine keeping your Mac, or your own SSH host, on while agents run.

Choose amux if

  • You want agents on one board, claiming tasks and resuming after usage limits on their own.
  • You want to steer from any browser or phone without installing a desktop app, on Mac or Linux.
  • You want a scheduler, CRM, email and browser automation beside your agents, for business tasks as well as code.
  • You want a dedicated always-on server your team shares: amux Cloud from $39/mo.

FAQ

Is amux a crystl alternative?

Yes. Both run many Claude Code, Codex and other coding agent sessions in parallel, each in its own git worktree if you want. crystl is a native macOS terminal app with floating approval cards, session history, an orchestrator agent and an iPhone app. amux is a self-hosted server you steer from any browser, its iPhone app or its Mac app, with a shared task board, usage-limit recovery and a scheduler, and amux Cloud runs it on a dedicated always-on server.

Is crystl free?

crystl has a free tier that covers parallel isolated sessions, approval cards, history, token tracking, remote SSH, up to 3 schedules and the iPhone app over Wi-Fi. The Guild plan is $170 a year, or billed monthly, and adds agent orchestration, unlimited schedules, sequence automation and phone access from anywhere. amux is free to self-host with every feature; amux Cloud starts at $39 a month.

Does crystl run on Windows or Linux?

No. crystl is a macOS app, with an iPhone companion. It can run agents on a Linux machine over SSH, but the app itself needs a Mac. amux installs on macOS or Linux and is used from any browser, so it works from Windows, Android or a Chromebook too.

Can I use crystl from my phone?

Yes, with its iPhone app: see which agents need input, approve access, answer questions and spawn agents. It is free over the same Wi-Fi as your Mac, and works from anywhere through an encrypted relay on Guild. Your Mac must stay on. amux has a native iPhone and iPad app, and an amux Cloud server stays reachable at yourname.amux.io whether your laptop is open or not.

Do both keep agents running when my laptop is closed?

Only on a machine that stays on. crystl runs agents on your Mac or on a host you reach over SSH. amux self-hosted is the same, and amux Cloud runs an always-on server for you, from $39 a month, or $69 for the Team plan with 8 vCPU and 16 GB.
