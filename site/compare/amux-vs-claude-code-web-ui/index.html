amux vs Claude Code Web UIs

Updated October 2026

Run your entire AI engineering team from one dashboard — not just a browser window around one terminal. View amux on GitHub

Several projects add a web interface to Claude Code: CloudCLI, claude-code-web, Remote Code, and others. They solve one problem well: getting a browser window around a Claude Code terminal. amux is a different kind of tool.

amux is an open-source control plane for running an AI engineering team from your browser or phone. It launches, monitors, and self-heals dozens of parallel Claude Code, Codex, or Gemini CLI agents, with built-in kanban, vault secrets, email, browser automation, and a scheduler. You manage the team; the agents handle the code.

What basic Claude Code web UIs do

  • Proxy a Claude Code terminal to a browser tab
  • List active sessions and switch between them
  • Some offer multi-session or multi-window views
  • Useful for remote access when SSH is inconvenient

What amux adds

These capabilities have no equivalent in basic web UI projects:

When to use a basic web UI

A basic Claude Code web UI is the right choice if you need to view a single Claude Code terminal from a browser and nothing else — for example, remote access to a session from a machine where you cannot install amux.

When to use amux

amux is the right choice when you want to run more than one agent, leave agents running overnight, coordinate work across a team of agents, or manage your engineering queue from your phone. It treats Claude Code, Codex, and Gemini CLI as workers in a fleet, not as individual terminals to observe.

What amux shipped in October 2026

  • Scratchpad tab — a global markdown scratch area at ~/.amux/scratchpad/, accessible from the dashboard without leaving your session
  • Companion chat inherits worker model — the companion conversation now uses the same model as the worker it is monitoring
  • Create modal for all providers — branch, worktree, and template options now appear for Codex, Gemini CLI, and Ollama workers, not just Claude Code
  • Tab search filter — filter across all open dashboard tabs by keyword
  • Workspace isolation per-agent — each agent gets its own git worktree and TMPDIR with a single env flag
  • Pinned notes — persistent markdown injected into agent context at startup, scoped to worker, group, or global
  • Goal keeper — set a goal, walk away, wake up to a finished task

Getting started

brew install mixpeek/amux/amux
amux register myproject --dir ~/Dev/myproject
amux start myproject
amux serve  # opens at https://localhost:8824

Or download the iOS app to manage your fleet from your phone.

Frequently asked questions

What is the difference between amux and a Claude Code web UI?

A Claude Code web UI proxies one terminal to a browser. amux runs many agents in parallel, self-heals crashes, coordinates work via a shared kanban board, and lets you monitor and redirect agents from your phone. It also includes built-in CRM, email, browser automation, a scheduler, and vault secrets.

Can I manage Claude Code agents from my phone?

Yes. amux has a native iOS app and a mobile-optimized PWA. You can check agent status, approve pending actions, send messages, and redirect work from your phone. Basic web UIs are not mobile-optimized and have no push notifications.

What happens if a Claude Code agent crashes overnight?

amux's self-healing watchdog detects the crash, restarts the session, and replays the last message. Context exhaustion triggers automatic compaction before the session fails. Basic web UIs have no watchdog; a crashed session stays dead.

Does amux work with Codex and Gemini CLI?

Yes. amux supports Claude Code, OpenAI Codex CLI, and Google Gemini CLI in the same fleet. Assign different models to different tasks and see all activity in one dashboard.

How many agents can amux run at once?

amux has been tested with 50+ agents simultaneously. Each agent gets its own tmux session and optionally its own git worktree via AMUX_WORKSPACE_ISOLATION=1.

Is amux open source?

Yes. amux is MIT+Commons Clause licensed at github.com/mixpeek/amux. A paid cloud tier adds tunnel URLs, cloud hosting, and managed onboarding.
