What are amux and the GitHub Copilot app?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

The GitHub Copilot app is GitHub's desktop app for agent-driven development, announced at Microsoft Build in June 2026 and generally available for macOS, Windows and Linux since June 17. It is built on Copilot CLI. Each agent session runs on its own branch and git worktree, locally (optionally in a local sandbox) or in a GitHub cloud sandbox. Sessions run in Interactive, Plan or Autopilot mode with the model and reasoning effort you choose, and the app covers the GitHub side too: start from an issue, review the diff, check CI and merge the pull request. It adds Projects that coordinate work across repositories, Automations that run saved tasks on a schedule, Canvases shared between you and the agent, MCP servers and skills, and computer use on macOS and Windows.

How do you drive each one?

The Copilot app is a desktop app organised by repository. You connect a repository or a local folder, start a session from a prompt or an issue, choose Interactive, Plan or Autopilot and a model, and the agent creates a branch, writes code and runs tests. You review the diff, give feedback, open the pull request, check CI and merge from the same window.

amux starts in the browser. Each agent is a worker card on the dashboard with its live terminal, and the same view works on a phone, in the iPhone and iPad app, or in the Mac app. Nothing needs to be installed on the device you steer from.

Which is better for running many agents at once?

The Copilot app takes the setup out of parallel work: every session gets its own worktree and branch, created and cleaned up for you, and a Project can hold a larger goal across several repositories with recurring tasks attached.

amux organises the fleet around shared work. Tasks live on a kanban board that agents claim from, agents message each other and share memory, usage limits pause delivery until the provider resets, and stall alerts fire when a worker stops making progress. Because the workers are the vendors' own CLIs, you can run Claude Code on one task and Codex on the next, each on the subscription you already pay for.

Which is better from a phone?

In the Copilot app, a session you run in a GitHub cloud sandbox can be followed and steered from GitHub Mobile, then picked up again on the desktop. A local session lives on the machine running the app.

amux has a native iPhone and iPad app and an installable web app that show every worker on your server, on every plan. On amux Cloud the phone talks to a server that is always on.

Where do the agents run?

The Copilot app runs sessions on your desktop, where a local sandbox can restrict what agent tools reach, or in a GitHub cloud sandbox that does not use your machine. Cloud automations let scheduled work run while your computer sleeps.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash. amux Cloud provisions a dedicated server at yourname.amux.io in about three minutes: 4 vCPU and 8 GB on Solo, 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running.

How much do amux and the GitHub Copilot app cost?

The Copilot app comes with every Copilot plan. For individuals that is Free, Pro at $10 a month, Pro+ at $39 and Max at $100. Chat and agent work draws on GitHub AI Credits at $0.01 each: each plan includes a monthly allowance, and you set a budget for anything beyond it. Business and Enterprise plans pool credits across the organisation.

amux is free to self-host with every feature. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max. The price covers the server itself, models are billed by your own provider plan, and the cost does not grow with the number of agents or teammates on the box.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel on one board every teammate can open, with no machine of your own to keep online.

When should you choose amux or the GitHub Copilot app?

Choose the GitHub Copilot app if

  • Your issues, pull requests and CI live on GitHub and you want the whole loop in one desktop app.
  • You already pay for Copilot and want agent sessions included in that plan.
  • Your organisation manages AI tools through Copilot Business or Enterprise policies.
  • You want GitHub to run sessions in its cloud sandboxes.

Choose amux if

  • You want Claude Code, Codex or Gemini CLI themselves, on the subscriptions you already have.
  • You want agents on one board, claiming tasks and resuming after usage limits on their own.
  • You want to steer every agent, local ones included, from any browser or a full phone app.
  • You want a dedicated always-on server your team shares at one flat price: amux Cloud from $39/mo.

FAQ

Is amux a GitHub Copilot app alternative?

For running coding agents in parallel, yes. The GitHub Copilot app is a desktop app built on Copilot CLI that runs Copilot agent sessions on their own branch and worktree, with issues, pull requests and CI inside the app. amux is a self-hosted server you steer from any browser, its iPhone app or its Mac app, running Claude Code, Codex, Gemini CLI or OpenCode as workers on a shared task board, and amux Cloud runs it on a dedicated always-on server.

How much does the GitHub Copilot app cost?

The app comes with every Copilot plan. Individual plans are Free, Pro at $10 a month, Pro+ at $39 and Max at $100, and agent work draws on monthly GitHub AI Credits at $0.01 each, with a budget for more. amux is free to self-host with every feature, and amux Cloud starts at $39 a month per server, with models billed by your own provider plan.

Can I use Claude Code or Codex in the GitHub Copilot app?

The app runs Copilot's own agent, built on Copilot CLI. You pick the model for each session, including models from your own provider through bring your own key. amux runs the Claude Code, Codex, Gemini CLI and OpenCode CLIs themselves, signed in with your own subscriptions.

Can I steer GitHub Copilot app agents from my phone?

Cloud sessions, yes: a session running in a GitHub cloud sandbox can be followed and steered from GitHub Mobile or another Copilot client. Local sessions stay on the desktop. amux has a native iPhone and iPad app and a web app that show every worker on your server, on every plan.

Does the GitHub Copilot app work without GitHub?

You can connect a local folder, but the app is built around GitHub: issues, pull requests, CI checks and Copilot plans, and Business and Enterprise admins control access by policy. amux works with any Git host or none, and agents work in plain folders.
