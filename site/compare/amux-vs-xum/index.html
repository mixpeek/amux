amux vs Xum: Which Should Run Your Coding Agents?

Xum, called Mux until a recent rename, and amux both run parallel coding agents in isolated workspaces. Compared on interface, agents, phone access, where agents run, team use and price. Updated November 2026.

amux Cloud: your agents keep running when your laptop sleeps, and you steer them from any browser or your phone. You get your own server at yourname.amux.io, from $39/mo, with no per-token markup.

Freelancer, agency or small team? Cloud Team is $69/mo with 8 vCPU and 16 GB RAM, one shared server your agents and teammates reach from any device, at a flat price per server instead of per seat.

Short answer: pick Xum if you want a free desktop app from Coder with its own agent loop, per-workspace runtimes including SSH and Docker, per-workspace cost tracking, and any model you have an API key for. Pick amux if you want to run Claude Code, Codex and Gemini CLI themselves on your own subscriptions: agents on a shared kanban board that resume after usage limits on their own, a scheduler, a native iPhone app, and an always-on server we can run for you at one flat price.

What are amux and Xum?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Xum is a coding agent multiplexer from Coder, renamed from Mux after a trademark concern from Mux.com. It runs parallel agents in isolated workspaces from a desktop app or a browser, on macOS, Linux and Windows (alpha). Xum has its own agent loop, with Plan and Exec modes inspired by Claude Code, and it connects to models through provider API keys, GitHub Copilot, OpenRouter, Ollama or a Coder AI Gateway. It is free under AGPL-3.0, with about 2k GitHub stars.

How do you drive each one?

Xum is a focused desktop app. You open a project, create a workspace per task, choose a runtime and a model, and work with its agent in Plan or Exec mode, with vim-style input, slash commands and keyboard shortcuts. A VS Code extension jumps into workspaces from the editor.

amux starts in the browser. Each agent is a worker card on the dashboard with its live terminal, and the same view works on a phone, in the iPhone and iPad app, or in the Mac app.

What actually runs: Claude Code or another agent?

This is the main difference. Xum runs its own agent loop and calls models with API keys or through GitHub Copilot, OpenRouter, Ollama or a Coder gateway. You can swap models freely, and you pay per token unless a provider route covers it.

amux runs the real Claude Code, Codex and Gemini CLI, signed in with your own subscription or API key. If you already pay for a Claude or ChatGPT plan, those agents work on that plan, with their own skills, hooks and updates.

Which is better for running many agents at once?

Xum keeps agents apart well. Each workspace can be a worktree, an SSH host, a Docker container or a Dev Container, with a central view of git divergence, and its SSH runtime treats the remote host as untrusted by default. Best of N runs several independent attempts at one ask.

amux organises the fleet around shared work. Tasks live on a kanban board that agents claim from, agents message each other and share memory, usage limits pause delivery until the provider resets, and stall alerts fire when a worker stops making progress.

Which is better from a phone?

Xum has a server mode with a responsive UI for phones, on a machine you run and expose yourself. There is no native mobile app listed in its docs.

amux has a native iPhone and iPad app and an installable web app. On amux Cloud the server has its own HTTPS address at yourname.amux.io, so the phone talks to a machine that is always on.

How much do amux and Xum cost?

Xum is free under AGPL-3.0, and model use is billed by whichever provider you connect. Its Costs tab shows the spend per workspace.

amux is free to self-host with every feature. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max. The price covers the server itself, models are billed by your own provider plan, and the cost does not grow with the number of agents or teammates on the box.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel on one board every teammate can open.

When should you choose amux or Xum?

Choose Xum if

  • You want one free desktop app with its own agent and any model you hold an API key for.
  • You want each workspace isolated in SSH, Docker or a Dev Container.
  • You want per-workspace cost figures.
  • Your company already runs Coder and its AI Gateway.

Choose amux if

  • You want the real Claude Code, Codex and Gemini CLI, on the subscriptions you already pay for.
  • You want agents on one board, claiming tasks and resuming after usage limits on their own.
  • You want a native iPhone app, a scheduler, CRM, email and browser automation.
  • You want a dedicated always-on server your team shares at one flat price: amux Cloud from $39/mo.

FAQ

Is amux a Xum alternative?

For running parallel coding agents, yes. Xum is a free desktop app with its own agent loop on your API keys and strong workspace isolation. amux runs Claude Code, Codex and Gemini CLI on a shared task board from any browser or its iPhone app, and amux Cloud runs it on a dedicated always-on server.

Is Xum the same as Mux?

Yes. Coder renamed its Mux coding agent multiplexer to Xum after a trademark concern from Mux.com. amux is a separate product from a different team.

Is Xum free?

Yes. Xum is free under AGPL-3.0, and you pay your model providers. amux is free to self-host with every feature, and amux Cloud starts at $39 a month per server.

Does Xum run Claude Code?

Xum has its own agent loop, with a user experience inspired by Claude Code, and calls Claude models through an API key or a provider route. amux runs the Claude Code CLI itself on your subscription or key.

Does Xum have a phone app?

Its docs list a responsive web UI in server mode and no native app. amux has a native iPhone and iPad app.
