amux vs Agent of Empires: Which Should Run Your Coding Agents?

Agent of Empires (aoe) and amux both run a fleet of coding agent sessions you can check from a browser or a phone. Compared on interface, phone access, running many agents, team use, hosting and price. Updated November 2026.

Short answer: pick Agent of Empires if you want a free, fast session manager on your own machine: a keyboard-driven TUI and a web dashboard over tmux sessions, with git worktrees, Docker, Podman or Apple Containers sandboxes and a diff viewer. What are amux and Agent of Empires?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Agent of Empires (the aoe command) describes itself as a session manager for AI coding agents on Linux and macOS. Written in Rust and backed by Mozilla.ai, it runs each agent in its own tmux session and puts a TUI, a web dashboard, a CLI and an HTTP API on top. It works with Claude Code, Codex, OpenCode, Gemini CLI, Mistral Vibe, Copilot CLI and others. It is MIT licensed, has about 3.4k GitHub stars, and ships often (v1.21.0 came out on October 21, 2026).

How do you drive each one?

aoe starts in the terminal. Run aoe for the TUI, aoe add --cmd claude to start a Claude Code session, and Ctrl+b d to detach back to the list. Because every agent is a plain tmux session, you can also tmux attach to it directly. aoe serve starts a web dashboard that streams the same sessions as a real terminal over WebSocket, with diffs beside them and token sign-in by default.

amux starts in the browser. Each agent is a worker card on the dashboard with its live terminal, and the same view works on a phone, in the iPhone and iPad app, or in the Mac app. You can still attach to any agent from a terminal, but nothing requires one.

Which is better from a phone?

aoe has put real work into mobile. Press R in the web dashboard to expose it over HTTPS and pair your phone with a QR code through Tailscale Funnel or Cloudflare Tunnel. The dashboard installs as a PWA, and its structured view renders agent plans and tool calls as cards you can swipe to approve.

amux has a native iPhone and iPad app as well as the installable web app, and on amux Cloud the server already has its own HTTPS address, so there is no tunnel to run. From the phone you see every agent's terminal, the task board and the schedules, and can send work to any agent.

Which is better for running many agents at once?

aoe keeps a long list of sessions readable: it detects whether each agent is working or waiting, sends notifications, and gives each session its own worktree or container so parallel branches do not collide. Coordination between agents is left to you.

amux organises the fleet around shared work. Tasks live on a kanban board that agents claim from, agents message each other and share memory, usage limits pause delivery until the provider resets, and stall alerts fire when a worker stops making progress. A scheduler starts recurring work on its own. That suits leaving a software project, or a small business, running overnight and reviewing the board from your phone in the morning.

Where do the agents run?

aoe runs where you install it: a Mac or a Linux box, or Windows through WSL2. Sessions persist as long as that machine stays on, and you reach it remotely over SSH or through the tunnel. Its CityHall project is an experimental self-hostable server for teams running aoe across many machines. There is no hosted plan.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash. amux Cloud provisions a whole dedicated server at yourname.amux.io in about three minutes: 4 vCPU and 8 GB on Solo, 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running.

How much do amux and Agent of Empires cost?

Agent of Empires is free. amux is free to self-host too, and both use your own model subscriptions. If you would rather not keep a machine awake for your agents, amux Cloud costs $39/mo for Solo (4 vCPU, 8 GB), $69/mo for Team (8 vCPU, 16 GB) and $129/mo for Max (16 vCPU, 32 GB). The price is per server, so it does not grow with the number of agents or projects on it.

For freelancers and agencies running agents across several client repos, Cloud Team gives the agents enough memory to work on several projects in parallel on one board.

When should you choose amux or Agent of Empires?

Choose Agent of Empires if

  • You want a free TUI and web dashboard over tmux sessions on your own machine.
  • You want each agent in a Docker, Podman or Apple Containers sandbox, or across multi-repo workspaces.
  • You use agents amux does not list, such as Mistral Vibe, Copilot CLI or Factory Droid.
  • You are happy to run a Tailscale or Cloudflare tunnel to reach it from your phone.

Choose amux if

  • You want agents on one board, claiming tasks and resuming after usage limits on their own.
  • You want a native iPhone app and a server that already has its own HTTPS address.
  • You want a scheduler, CRM, email and browser automation beside your agents, to run business tasks as well as code.
  • You want a dedicated always-on server sized for a whole fleet: amux Cloud from $39/mo.

FAQ

Is amux an Agent of Empires alternative?

Yes. Both manage many Claude Code, Codex, OpenCode and other coding agent sessions in one place. Agent of Empires (aoe) is a Rust session manager on tmux with a terminal TUI, a web dashboard you can pair to your phone, git worktrees and container sandboxes. amux runs a team of agents on a shared task board with usage-limit and reboot recovery, a scheduler and business tools, and amux Cloud gives you a dedicated always-on server.

Is Agent of Empires free?

Yes. aoe is MIT licensed and free, installs with Homebrew or one curl command, and runs on Linux and macOS (Windows only through WSL2). It has no hosted plan. amux is also free to self-host, and amux Cloud starts at $39 a month if you want the server run for you.

Can I use Agent of Empires from my phone?

Yes, through its web dashboard. Run aoe serve, then expose it over HTTPS with QR pairing through Tailscale Funnel or Cloudflare Tunnel; it installs as a PWA and has a mobile structured view with swipe-to-approve. There is no native app. amux has a native iPhone and iPad app plus an installable web app.

Does Agent of Empires work for a team?

Partly. Its read-only links let a teammate watch a session, and CityHall, an experimental self-hostable control plane at v0.1.0, adds accounts, roles, single sign-on and invites across machines. amux Cloud Team is $69 a month for a dedicated 8 vCPU, 16 GB server your team shares, with a task board the agents work from.

Do both keep agents running when my laptop is closed?

Only on a machine that stays on. aoe sessions are tmux sessions, so they survive closing the TUI or an SSH disconnect, but they stop when the machine sleeps. amux self-hosted is the same, and amux Cloud runs an always-on server for you at yourname.amux.io.
