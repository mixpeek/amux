What are amux and CC Pocket?

amux is a self-hosted control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, source-available under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

CC Pocket (K9i-0/ccpocket, MIT, about 1,100 GitHub stars, first published February 2026, with releases as recent as November 27) is a chat app made for the phone. It has two parts: the app, on iPhone, iPad, Android and Apple silicon Macs with experimental Linux and Windows builds, and a Bridge Server (npx @ccpocket/bridge@latest, Node.js 22.19 or newer) that runs on the machine with your projects and drives the Codex, Claude or Antigravity command line over a WebSocket.

How do you steer agents from your phone with each one?

CC Pocket is built around the chat. Each session is a room for prompts, replies, approvals and questions, with Markdown, voice input and image attachments. Sessions started in the CLI can be resumed in the app and continued on a tablet or Mac, where chat, files and git changes sit side by side. Messages you send while offline wait and resend when you reconnect. You pair the app with the Bridge by scanning the QR code it prints, by a saved host, or by a Tailscale address.

amux is built around the team. Each agent is a named worker card on the dashboard with its live terminal, and work arrives as cards on a shared kanban board. The same view works in a browser, in the iPhone and iPad app, or in the Mac app, and on amux Cloud your server is already at an HTTPS address, so there is no bridge or tunnel to set up.

Which is better for running many agents at once?

CC Pocket lets you run several sessions and keep parallel tasks apart with git worktrees, and you review and commit each one's changes from the app. Each session is yours to start and steer; there is no shared queue of work, and agents do not hand tasks to each other.

amux adds the layer that keeps a team of agents working without you: one board that agents claim tasks from atomically, so two never grab the same work; messages and @mentions between workers for handoffs and reviews; a scheduler for overnight and recurring runs; held delivery through a provider's usage limit, so a worker picks up again when the limit resets; and stall alerts when a worker stops making progress. Beside the agents sit a CRM, email with owner approval for outside sends, and browser automation with saved sign-ins.

Where do the agents run?

With CC Pocket, agents run on the machine with the Bridge Server, and your code stays there. The Bridge can be registered as a launchd or systemd service on an always-on host (npx @ccpocket/bridge@1 setup), but its README notes that on macOS the Bridge goes offline while the Mac sleeps, and a closed MacBook lid sleeps it unless it runs in closed-display mode. Away from home, the recommended setup is Tailscale on both the host and the phone.

amux self-hosted installs on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash, and keeps running when you close the browser tab. amux Cloud skips running a machine at all: it provisions a dedicated server at yourname.amux.io in about three minutes, 4 vCPU and 8 GB on Solo or 8 vCPU and 16 GB on Team. You sign in with your own Claude, ChatGPT or Gemini account or an API key, and we keep the box running and patched, so your agents keep working overnight and your phone reaches them from anywhere. You can export everything at any time (how).

How much do amux and CC Pocket cost?

CC Pocket is free to use, and its source, including the apps, is on GitHub under MIT. Optional Supporter purchases in the app help cover development; they restore within the same Apple ID or Google account. Claude sessions use an Anthropic API key by default, and using a Claude subscription needs an explicit opt-in on the Bridge. You pay your model providers, and for the machine the Bridge runs on.

amux is free to self-host with every feature, and the code is on GitHub. amux Cloud costs $39/mo for Solo, $69/mo for Team and $129/mo for Max. The price covers the server itself, models are billed by your own provider plan, and the cost does not grow with the number of agents or teammates on the box.

For freelancers and agencies running agents across several client repos, Cloud Team is one always-on server every teammate can open, at $69 a month, with no Mac to leave awake and no bridge or tunnel to set up and secure.

FAQ

What is CC Pocket?

CC Pocket (github.com/K9i-0/ccpocket) is a free, MIT-licensed chat app for iPhone, iPad, Android and Mac, with experimental Linux and Windows builds, that controls Codex, Claude Code and Antigravity sessions. The agents run on your own Mac, Linux or Windows machine through the CC Pocket Bridge Server, which you start with npx @ccpocket/bridge@latest and pair with the app by QR code.

Is amux a CC Pocket alternative?

For steering coding agents from your phone, yes. CC Pocket is a phone-first chat client for your own agent sessions, with approvals, voice input, file browsing and git review. amux runs a team of Claude Code, Codex and Gemini CLI workers on one shared task board with a scheduler, CRM, email and browser automation, and amux Cloud runs it on a dedicated server that stays on without your laptop.

Is CC Pocket free?

Yes. The apps are free to download and use, and optional Supporter purchases in the app fund development. You pay your model providers, and for the machine the Bridge Server runs on. amux is free to self-host, and amux Cloud costs 39 dollars a month per server, or 69 for Team.

Does CC Pocket keep agents running when my laptop is closed?

No. Agents run on the machine with the Bridge Server, and its README notes that on macOS the Bridge goes offline while the Mac sleeps, so closing a MacBook lid stops it unless the Mac runs in closed-display mode. You can register the Bridge as a launchd or systemd service on an always-on machine you maintain. amux Cloud gives you a dedicated always-on server at yourname.amux.io with nothing to set up.

Can I use my Claude subscription with CC Pocket?

Claude sessions use ANTHROPIC_API_KEY by default. Signing in with a Claude subscription needs an explicit Bridge opt-in (BRIDGE_ALLOW_CLAUDE_OAUTH=1), because the project considers Anthropic's guidance for this setup unclear. On amux you sign in with your own Claude, ChatGPT or Gemini account or an API key.
