What are amux and Paradev?

amux is an open-source control plane for running an AI engineering team from a single dashboard or your phone. It launches and monitors dozens of parallel Claude Code, Codex or Gemini CLI sessions, with a built-in kanban board, notes, CRM, email, browser automation and a scheduler. It is one Rust binary plus SQLite, open source under MIT + Commons Clause, and you can self-host it or rent an always-on server from amux Cloud.

Paradev, until October 2026 called Superset, describes itself as an agentic IDE to orchestrate 100+ coding agents in parallel with your own subscriptions. Each task gets a workspace with its own git worktree, branch and terminals, and you review the result in a built-in diff viewer and browser pane before you merge. Its source is published under the Elastic License 2.0, it has about 15.6k GitHub stars, and its command-line tool is still called superset.

Where do the agents run?

With Paradev, a workspace lives on the machine that hosts its files and terminals, usually your Mac. Its keep-agents-running docs say terminals belong to a background daemon, so closing or quitting the app leaves agents working, but restarting or logging out of the computer ends them. To reach the machine from your phone while the app is closed, you run the standalone superset CLI as a host service. Cloud workspaces run agents in a cloud sandbox instead; they are in early access, need a paid plan, and are metered in GB-hours with 150 hours per seat on Team.

With amux, you can self-host on any Mac or Linux machine with curl -fsSL https://amux.io/install.sh | bash, or let amux Cloud provision a dedicated server at yourname.amux.io in about three minutes. It is one server for all your agents at a flat monthly price, signed in with your own Claude, ChatGPT or Gemini account or an API key, and we keep it running.

Which is better for running many agents at once?

Paradev is built around the workspace and the review. You start a workspace per task, race two agents on the same problem, read each diff, preview the app in the built-in browser and merge the one you like. Automations start agents on a schedule or from a Slack message, a Linear issue, a Sentry alert or a pull request review request. It is strong when you are at the desk shipping code from several agents at once.

amux is built around the team. Each agent is a worker on the dashboard, work lives on a shared kanban board that agents claim tasks from, and agents resume on their own after a provider usage limit resets, and on macOS every worker comes back in its own conversation after a reboot. You can open the board on your phone, see which agent is stuck, answer it and move on, which makes amux a good fit for leaving a software project, or a small business, running overnight.

Which is better from your phone?

Paradev's iPhone and iPad app starts agents, follows them live, shows diffs and merges pull requests. It needs iOS 26 or iPadOS 26 or later and a Pro plan, and an Android app is listed as coming soon. Phones reach your computer through the Paradev Relay, so that computer has to stay awake and online unless you use cloud workspaces.

amux has a free native iPhone and iPad app and a web app you can install on Android or any browser. The phone shows every agent at once with its live terminal, the task board, and controls to answer, approve, restart or reassign. Traffic goes over HTTPS straight to your own server.

How much do amux and Paradev cost?

Both let agents use your existing model subscriptions. Paradev is free for one user with local workspaces, the desktop app and the CLI. Pro costs $20 per user per month ($16 billed yearly) and adds remote access, automations, the mobile app and team members. Team costs $60 per user per month ($54 yearly) and adds cloud workspaces with 150 hours per seat, and Ultra costs $200 per user per month with 500 hours. amux is free to self-host; amux Cloud costs $39/mo for Solo (4 vCPU, 8 GB), $69/mo for Team (8 vCPU, 16 GB) and $129/mo for Max (16 vCPU, 32 GB), per server rather than per seat.

For freelancers and agencies running agents across several client repos, Cloud Team at $69/mo is one always-on server for all of them, close to the price of a single Paradev Team seat.

When should you choose amux or Paradev?

Choose Paradev if

  • You work at a Mac and want a diff viewer, editor, terminals and a browser preview around your agents in one app.
  • You race several agents on one task and pick the best result.
  • You use Cursor Agent, Copilot, Amp, Droid or another agent beyond the big three.
  • You want agents started from Slack, Linear, Sentry or GitHub review requests.

Choose amux if

  • You run more than a few agents and want them on one board, claiming tasks and resuming on their own after usage limits.
  • You want CRM, email, browser automation and a scheduler in the same place as your agents, to run business tasks as well as code.
  • You manage the work from your phone, including on Android or an iPhone older than iOS 26.
  • You want an always-on server at a flat price without maintaining one: amux Cloud from $39/mo.

FAQ

Is amux a Paradev or Superset alternative?

Yes. Superset renamed itself Paradev in October 2026. Both run Claude Code, Codex and other coding agents in parallel and let you steer them from your phone. Paradev is an agentic IDE, a desktop app with a worktree per task, diffs, an editor and a browser. amux runs a team of agents on a shared task board that resume after usage limits, with built-in business tools, and offers an always-on amux Cloud server.

Is Paradev the same as Superset?

Yes. The GitHub repository superset-sh/superset now describes itself as Paradev (formerly Superset), and its CLI is still called superset. Its docs and pricing live at paradev.com.

Do Paradev and amux keep agents running when my laptop is closed?

Paradev keeps terminals alive when you close or quit the app, but its docs say agents stop when you restart or log out of the computer. Cloud workspaces, in early access on the $60 Team plan and up, run agents in a cloud sandbox. amux Cloud gives you a dedicated always-on server at yourname.amux.io from $39/mo, and a self-hosted amux on macOS brings every worker back in its own conversation after a reboot.

Does Paradev have a phone app?

Yes. Paradev has an iPhone and iPad app that needs iOS 26 or iPadOS 26 or later and a Paradev Pro plan ($20 per user per month, or $16 billed yearly). An Android app is listed as coming soon. amux has a free iPhone and iPad app and an installable web app for Android.
