OpenCode: the most-starred open-source coding agent

OpenCode is a terminal coding agent with a desktop app in beta. Its docs list dozens of model providers, from Anthropic and OpenAI to local models through Ollama, LM Studio and llama.cpp. With about 222k stars it is the largest open-source project in the category.

Strength: provider choice, very active development. github.com/anomalyco/opencode

Codex CLI: OpenAI's open-source terminal agent

Codex CLI is OpenAI's coding agent for the terminal, written in Rust and licensed Apache 2.0. It signs in with a ChatGPT plan or an API key. amux runs Codex sessions next to Claude Code and Gemini CLI on one board.

Strength: native Rust binary, works on a ChatGPT plan you already pay for. amux vs Codex →

Gemini CLI

Google's open-source terminal agent (Apache 2.0). On June 18, 2026 Google moved free individual access and Google AI Pro and Ultra accounts to Antigravity CLI (agy), which is not open source. Gemini CLI keeps working with a Gemini API key or Google Cloud.

Strength: large context, Google Cloud integration. github.com/google-gemini/gemini-cli · amux vs agy →

OpenHands

The most autonomous open-source coding agent here. It works in a Docker sandbox with its own shell, browser and filesystem, and can finish end-to-end tasks including web research. MIT licensed.

Strength: sandboxed autonomy, strong research community. amux vs OpenHands →

Cline

Cline started as a VS Code extension and now also ships as a CLI and an SDK. It reads files, runs shell commands and drives a browser with approval checkpoints, and works with any model provider. Its best-known fork, Roo Code, was archived in May 2026.

Strength: deep editor integration, human-in-the-loop checkpoints. amux vs Cline →

Goose

An extensible agent for code and workflows, with a desktop app, a CLI and an API. Block created it; the repo now lives under aaif-goose on GitHub. Written in Rust and licensed Apache 2.0.

Strength: desktop app for macOS, Linux and Windows, plus a CLI and an API. amux vs Goose →

Aider

Aider pioneered the terminal pair-programming pattern. It works with almost any LLM, including local models through Ollama, and commits every change with a descriptive message. Development has slowed: its last push to GitHub was in May 2026.

Strength: model choice, git-first workflow. amux vs Aider →

Continue

Continue began as an open-source Copilot alternative for VS Code and JetBrains and now describes itself as an open-source coding agent. It supports many model providers, including local ones.

Strength: JetBrains support, provider choice. amux vs Continue →
