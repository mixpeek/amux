amux

Self-hosted control plane for running an AI engineering team from a single dashboard or your phone. amux is not a framework — you don't write agent code. You configure workers (Claude Code, Codex, Gemini CLI), queue tasks on the shared kanban board, and let the fleet run. Agents resume after usage limits overnight, and stall detection alerts you. Built-in scratchpad, pinned notes, vault secrets, goal keeper, companion chat, and workspace isolation (per-agent git worktrees). Web dashboard + native iOS app for monitoring. Single Rust binary, zero external dependencies. 525 GitHub stars.

New in October 2026: built-in scratchpad tab for shared fleet notes, companion chat inherits worker model, workspace isolation (per-agent git worktrees), pinned notes with token-efficient startup injection, and goal keeper for overnight task tracking. New in September 2026: board hygiene runtime job, mobile terminal streaming, session log rotation. Install: curl -fsSL https://amux.io/install.sh | bash. 525 GitHub stars.

Architecture: tmux or herdr sessions managed by a Rust binary (axum server). SQLite for state. REST API for inter-session coordination. Static SPA dashboard served from the same binary.

Best for: Developers shipping code who want 10–50× throughput with minimal setup. Not a framework — you don't program agents, you run them. amux vs LangGraph →

LangGraph

The most mature Python framework for building custom stateful agent graphs. 47k+ GitHub stars as of mid-2026. Nodes are functions or LLM calls; edges define control flow. Supports cycles (for retry loops), streaming, and persistence via LangGraph Cloud. Part of the LangChain ecosystem but usable standalone. LangGraph Platform offers hosted deployment for production workloads.

Architecture: Directed acyclic/cyclic graph, each node is a Python function. State is a typed dict threaded through the graph. Can persist state to any SQL-compatible store via LangGraph checkpointers.

Best for: Engineers building custom multi-agent pipelines from scratch — research workflows, approval pipelines, complex branching logic. High flexibility, higher implementation effort than orchestrators.

CrewAI

Role-based multi-agent framework. 31k+ GitHub stars. You define a "Crew" of "Agents" with distinct roles (researcher, writer, reviewer), assign them "Tasks", and CrewAI orchestrates the handoff. CrewAI Enterprise adds observability, deployment, and team management on top of the open-source core.

Architecture: Agent objects with role/goal/backstory, Task objects with description/expected output, Crew that sequences them. Supports both sequential and hierarchical process modes.

Best for: Structured document-production workflows (reports, analyses, content pipelines) where role separation and task handoff are natural. Less suited to open-ended coding tasks.

AutoGen (Microsoft)

Conversation-based multi-agent framework from Microsoft Research. 38k+ GitHub stars. Agents communicate by exchanging messages; you define which agents talk to which and what triggers termination. AutoGen 0.4 (released late 2025) introduced a new async actor-model architecture. Integrates with Azure OpenAI and the broader Microsoft AI ecosystem.

Architecture: Agent conversations with configurable termination conditions. Supports human-in-the-loop via HumanProxyAgent. AutoGen Studio provides a low-code UI for building agent workflows. amux vs AutoGen →

Best for: Microsoft/Azure shops, or researchers who want conversation-based agent coordination with rich observability and a growing community.

OpenAI Symphony

Open-sourced by OpenAI in early 2026. Ticket-driven Codex orchestrator — it reads GitHub issues, assigns them to Codex agents, and opens PRs. Tightly integrated with GitHub and OpenAI's Codex model. Uses Linear for project management integration.

Architecture: Event-driven pipeline: GitHub issue → task queue → Codex agent → PR. amux vs Symphony →

Best for: Teams already using GitHub Issues as their task tracker who want Codex-driven automation with minimal setup.

Claude Managed Agents (Anthropic)

Anthropic's cloud-managed agent service. Zero infrastructure — Anthropic runs the agents, handles scaling, and manages the runtime. Launched April 2026. Suited for teams that want agent benefits without ops overhead. amux vs Managed Agents →

Best for: Enterprises that want Anthropic-managed infrastructure and are willing to pay for the convenience and compliance guarantees. amux is the self-hosted, source-available alternative.

Hermes Agent (NousResearch)

Persistent AI daemon with cross-session memory, self-improvement loop, and 16+ messaging connectors. Single agent with deep memory rather than a fleet — a different philosophy from amux (depth vs breadth). amux vs Hermes →

OpenHands (formerly OpenDevin)

Autonomous coding agent with a browser sandbox. 42k+ GitHub stars. Can browse documentation, search the web, and execute code in an isolated environment. Strong for end-to-end tasks requiring web research. MIT licensed, active community. OpenHands runs one agent per task; amux runs many. amux vs OpenHands →
