Features

Run many agents without losing track

Ten terminals is chaos. One view shows what every agent is doing, so you step in only where it counts.

Run agents

  • Know what every agent is doing at a glance

    Spot a stuck or finished agent in seconds instead of checking each terminal.

    Worker cards. Every agent is a live card showing its status, current task and model.

    Watch the demo →

  • Give instructions from anywhere

    Work keeps moving when you are away from your desk.

    Send to any worker. Type to any agent from the laptop or the phone and watch the reply stream in.

    Watch the demo →

  • Use the best model for each job

    No lock-in. Pick cost or quality per task, and switch when a better model ships.

    Any model, per worker. Run Claude Code, Codex, Gemini CLI, OpenCode or Ollama, and switch a worker between them.

  • Correct course without starting over

    A wrong turn costs one sentence, not a redone task.

    Steering. Add a note to a running agent and it changes course mid-task.

  • Understand the work without reading code

    People who don't code can follow and direct technical agents.

    Translate. A plain-English summary of what a terminal is doing, for people who do not read code.

  • Review and ship code from the browser

    Approve changes without opening an editor or a terminal.

    Git panel. Read an agent's diff and commit it from the browser.

  • Run agents side by side safely

    Agents never overwrite each other, so more agents means more output, not more conflicts.

    Separate checkouts. Each worker can get its own git worktree, so parallel agents never overwrite each other's files.

  • Step in directly when you need to

    You are never locked out of your own machine.

    Terminal. A real shell on your amux machine, in the browser.

Agents work as a team and ask you only for decisions

Your time goes to decisions, not to handing out work and checking up on it.

Coordinate the team

  • No duplicated or dropped work

    Every task has exactly one owner, so nothing is done twice or missed.

    Board. A shared kanban board. Claiming a card is atomic, so two agents never grab the same task.

    Watch the demo →

  • Done means done

    Nothing is marked finished without proof, so you don't find out later that it wasn't.

    Gates and evidence. A card cannot be marked done until the agent attaches proof that the work passed.

  • Talk to your agents like teammates

    Ask, assign and get updates in one place, the way you already work with people.

    Messages. Channels and direct messages between you and your agents, and between agents.

    Watch the demo →

  • Keep each customer and project separate

    Each team gets its own board, channel and rules, so work and data don't mix.

    Groups. Organize workers by team or project, each with its own board, channel and rules.

  • Teach it once

    Agents remember how you work, so you stop repeating yourself.

    Memory and rules. Agents remember how your team works, with rules set per worker, per group or everywhere.

  • Answer only what needs you, in one tap

    Agents handle the rest, so your attention goes where it matters most.

    Needs-you inbox. When an agent needs a decision you get one notification and answer it in a tap.

  • Hand off a goal, not a to-do list

    The agent keeps going until the result checks out, without you pushing it.

    Long-running goals. Give a worker a goal and a check, and it keeps working until the check passes.

  • Nothing broken reaches production

    Every change is tested and reviewed first, so speed doesn't cost quality.

    Land gate. Tests and a fresh review run on an agent's commits before anything reaches main.

Work happens on time, even while you sleep

Routine work runs itself and keeps going through usage limits and restarts.

Schedule and keep going

  • Recurring work runs itself

    Reports, follow-ups and checks happen on time without anyone remembering them.

    Scheduler. Write "every weekday at 9am" and a worker runs the job on time, without you.

    Watch the demo →

  • See scheduled work where you already look

    It shows up in your own calendar, with no new tool to check.

    Calendar. Events land in a calendar feed your Google or Apple calendar can subscribe to.

    Watch the demo →

  • Work survives limits and restarts

    A usage cap or a reboot pauses the work instead of losing it.

    Keeps going through limits. When a usage limit hits, delivery waits and resumes at the reset. On macOS, workers come back after a reboot.

    Watch the demo →

Get finished deliverables, not just chat

Agents produce documents, pages and apps you can open, edit and share right away.

Files, docs and apps

  • Check any deliverable in the browser

    Open and fix what an agent made without downloads or extra apps.

    File viewer. Open markdown, code, PDFs and slide decks in the browser, and edit them in place.

    Watch the demo →

  • Edit documents by asking

    Describe the change and see it applied, instead of rewriting by hand.

    MDAI docs. Write a document with an agent beside it that applies your requested changes in place.

  • Sketch an idea on any device

    Explain it visually, then pick it up on your phone where you left off.

    Draw. A whiteboard that syncs live between your laptop and phone.

    Watch the demo →

  • Ship what agents build to a link

    Share a working page or app with a customer the same day, once you approve it.

    Apps. Publish a page or app an agent built to a link, after you approve it.

    Watch the demo →

  • Capture a thought before it's lost

    Notes stay plain files that you own.

    Scratchpad. Quick notes, saved as plain markdown files you own.

  • Turn a meeting into action

    The transcript and notes go straight to the agent that does the follow-up.

    Record. Record a conversation, get a live transcript and notes, and send them to a worker.

Run your business from your phone

You are not tied to a desk to keep work moving.

Phone, Mac and voice

  • Everything, in your pocket

    Check, approve and direct from anywhere.

    Phone app. The iPhone and iPad app, or install the dashboard on any phone as an app.

    Watch the demo →

  • Nothing you send gets lost

    A bad signal never drops an instruction.

    Offline sync. Messages you send without a connection are saved on your device and delivered when you reconnect.

  • Keep every agent one glance away

    A native app on your desktop, always within reach.

    Mac app. A native Mac app with tiled windows, floating notes, a menu bar readout and a Dock badge.

  • Talk instead of type

    Give instructions while you walk or drive.

    Voice. Dictate to a worker, talk with one out loud, or have its output read to you.

  • Get anywhere in one keystroke

    Less clicking, faster decisions.

    Hotkeys and Cmd-K. Keyboard shortcuts, text triggers and a command palette that jumps anywhere.

Agents work in the tools you already use

No migration. They use your email, websites and software the way your team does.

Connect your tools

  • Email handled, with nothing sent behind your back

    Agents read and draft. Anything to an outside address waits for your approval.

    Email. Agents read and draft email. Nothing goes to an outside address until you approve it.

  • Automate websites that have no API

    If you can do it in a browser, an agent can do it for you.

    Browser automation. Agents use websites with your saved sign-ins, including sites with no API.

  • Connect a service once, and every agent can use it

    No setup per agent.

    Connectors. Connect the services you use once, and every worker can use them.

  • Agents use your accounts without seeing your passwords

    Credentials stay protected even while agents use them.

    Vault. Store credentials agents can use without ever seeing the values.

  • Automate desktop software too

    Older apps with no web version are not a dead end.

    Computer use. Agents drive desktop software inside a sandboxed computer.

  • Reuse what works

    One good process becomes something every agent can run.

    Skills. Reusable instructions any agent can run, searchable by name.

Know what you spend and keep control of your data

You see what the spend produced, and your data stays where you choose.

Cost and control

  • See what you pay for and what it produced

    Cut waste without guessing.

    Usage and cost. See where the spend goes, what it produced and what to change.

  • Answer “what happened?” in one search

    Every action is recorded, so any problem is easy to trace.

    Logs. One searchable record of board, worker, memory, file and HTTP activity.

  • Your data stays on your machine

    Nothing leaves unless you send it.

    Self-hosted. One Rust binary and SQLite on your own Mac or Linux machine. Your data stays there, and you can export it any time.

  • Always on, nothing to maintain

    No machine of your own to keep running.

    amux Cloud. Your own always-on amux server at yourname.amux.io, from $39/mo.

  • Automate amux itself

    Scripts and agents can do anything you can do in the dashboard.

    CLI. The amux command does everything the dashboard does, for scripts and agents.
