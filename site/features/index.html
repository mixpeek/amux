Features

Everything amux does, in one list. Run Claude Code, Codex and Gemini CLI agents in parallel from one dashboard or your phone.

41 features in 7 groups. The 11 highlighted ones have a short demo video.

Run agents

See every agent at once and talk to any of them.

  • Worker cards

    Every agent is a live card showing its status, current task and model.

    Watch the demo →

  • Send to any worker

    Type to any agent from the laptop or the phone and watch the reply stream in.

    Watch the demo →

  • Any model, per worker

    Run Claude Code, Codex, Gemini CLI, OpenCode or Ollama, and switch a worker between them.

  • Steering

    Add a note to a running agent and it changes course mid-task.

  • Translate

    A plain-English summary of what a terminal is doing, for people who do not read code.

  • Git panel

    Read an agent's diff and commit it from the browser.

  • Separate checkouts

    Each worker can get its own git worktree, so parallel agents never overwrite each other's files.

  • Terminal

    A real shell on your amux machine, in the browser.

Coordinate the team

Agents share work, talk to each other and ask you only when they need to.

  • Board

    A shared kanban board. Claiming a card is atomic, so two agents never grab the same task.

    Watch the demo →

  • Gates and evidence

    A card cannot be marked done until the agent attaches proof that the work passed.

  • Messages

    Channels and direct messages between you and your agents, and between agents.

    Watch the demo →

  • Groups

    Organize workers by team or project, each with its own board, channel and rules.

  • Memory and rules

    Agents remember how your team works, with rules set per worker, per group or everywhere.

  • Needs-you inbox

    When an agent needs a decision you get one notification and answer it in a tap.

  • Long-running goals

    Give a worker a goal and a check, and it keeps working until the check passes.

  • Land gate

    Tests and a fresh review run on an agent's commits before anything reaches main.

Schedule and keep going

Work happens on time and survives limits and restarts.

  • Scheduler

    Write "every weekday at 9am" and a worker runs the job on time, without you.

    Watch the demo →

  • Calendar

    Events land in a calendar feed your Google or Apple calendar can subscribe to.

    Watch the demo →

  • Keeps going through limits

    When a usage limit hits, delivery waits and resumes at the reset. On macOS, workers come back after a reboot.

    Watch the demo →

Files, docs and apps

See and share what your agents make.

  • File viewer

    Open markdown, code, PDFs and slide decks in the browser, and edit them in place.

    Watch the demo →

  • MDAI docs

    Write a document with an agent beside it that applies your requested changes in place.

  • Draw

    A whiteboard that syncs live between your laptop and phone.

    Watch the demo →

  • Apps

    Publish a page or app an agent built to a link, after you approve it.

    Watch the demo →

  • Scratchpad

    Quick notes, saved as plain markdown files you own.

  • Record

    Record a conversation, get a live transcript and notes, and send them to a worker.

Phone, Mac and voice

Run your agents from wherever you are.

  • Phone app

    The iPhone and iPad app, or install the dashboard on any phone as an app.

    Watch the demo →

  • Offline sync

    Messages you send without a connection are saved on your device and delivered when you reconnect.

  • Mac app

    A native Mac app with tiled windows, floating notes, a menu bar readout and a Dock badge.

  • Voice

    Dictate to a worker, talk with one out loud, or have its output read to you.

  • Hotkeys and Cmd-K

    Keyboard shortcuts, text triggers and a command palette that jumps anywhere.

Connect your tools

Let agents work in the software you already use.

  • Email

    Agents read and draft email. Nothing goes to an outside address until you approve it.

  • Browser automation

    Agents use websites with your saved sign-ins, including sites with no API.

  • Connectors

    Connect the services you use once, and every worker can use them.

  • Vault

    Store credentials agents can use without ever seeing the values.

  • Computer use

    Agents drive desktop software inside a sandboxed computer.

  • Skills

    Reusable instructions any agent can run, searchable by name.

Cost and control

Know what you spend and where you run.

  • Usage and cost

    See where the spend goes, what it produced and what to change.

  • Logs

    One searchable record of board, worker, memory, file and HTTP activity.

  • Self-hosted

    One Rust binary and SQLite on your own Mac or Linux machine. Your data stays there.

  • amux Cloud

    Your own always-on amux server at yourname.amux.io, from $39/mo.

  • CLI

    The amux command does everything the dashboard does, for scripts and agents.
