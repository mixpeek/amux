amux tunnel has been retired

This page described amux tunnel, which was removed from amux on October 25, 2026.

The command now exits with a message and does nothing. amux has one supported way to share a local app, the Apps tab. For anything else, a dedicated tunnel tool is the better fit.

What to use instead

  • Share a local app or file from amux: open the Apps tab, or run amux publish PORT (anyone with the link) or amux publish --internal PORT (only you, inside amux). Anything an agent adds stays pending until you approve it, and you can revoke a link at any time.
  • Reach your amux dashboard from anywhere: use Tailscale to reach your own machine, or run amux Cloud, your own always-on server at yourname.amux.io that you sign in to from a browser or the iOS app.
  • A public URL for any local port, webhooks or TCP: use ngrok or Cloudflare's cloudflared.
