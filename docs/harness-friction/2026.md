# Harness friction, 2026

A weekly sweep (SCHED-1669, Mondays 9:30) reads the owner's messages to every
worker, each worker's session history and tasks, new frustrations.md entries,
the error report and failing invariants, then files each place the amux harness
made someone struggle as a GitHub issue labelled `harness-friction`. One block
per run.
