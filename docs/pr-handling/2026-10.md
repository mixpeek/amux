  `stop_worker`) writes exactly `WorkerState::Stopped` and leaves
  `lifecycle` as it was. `WorkerState::Stopped` carries no reason, so a
  deliberate stop and a lost process look the same to the sweep.

  next tick. amux's CLAUDE.md requires recovery to keep "isolation, owner
  stops and authorization gates intact".

  `lifecycle = deleted` (read-only query on `~/.amux/amux.db`). It would hit
  any install that runs durable workers, which is the contributor's setup.

The PR already reports the stopped case (`todo_owner_unavailable` with
`owner_stopped`). That covers the 20-minute silent wait it describes without
the restart.
