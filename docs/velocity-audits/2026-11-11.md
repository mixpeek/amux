  `AMUX_AUTOFIX_SESSION=amux` in `~/.amux/server.env`, or turn this lane's

  card never lands on nobody. 26b's other half is part of this: the card

  that lane is isolated.

  so the PR handler can name the producer. A plan that opens stacked PRs

  rather than adding parts nobody can merge.

  pressure level is raised. Owner tier.
