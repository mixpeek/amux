## Bottlenecks, ranked by cost

### B1. `amux requests --open` takes 36 to 41 seconds for one worker (top)

Every worker is told to run it before ending a turn. Timed: amux 36.4s,
amux-app 35.4s. A profile of origin/main's script put 19.1s of 41.5s in the
stranded pass, which reads every branch and worktree HEAD in the repository
and computes patch ids for each, so one worker pays for the fleet's
worktrees on every run. AF-1401: the pass is now cached by the refs it reads
(origin/main, every branch tip, the worktree list). Same request, same
machine, alternating runs: 21.3s and 12.5s before, 5.9s and 5.1s after,
with identical output apart from `age_h`.
