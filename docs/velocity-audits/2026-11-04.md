## Proposals

- **19b, extended (B1). A CI-red alert per failing step, sent to the lane
  that broke it.** Open since the 11-03 audit ("name a spec that reddens main
  twice and its last author"). New evidence above. main-ci-watch should key
  its card on the failing STEP (or spec), not the workflow, so a new step
  going red under an already-red main raises its own alert, and address it to
  the lane in the first failing commit's `Amux-Session` trailer. amux land
  should also stop treating a step that went red within the last day as
  "inherited".
- **20a (B2). An owner's relay instruction carries the owner's reach.** When
  a worker sends to a worker outside its groups because the owner asked it
  to, the send names the owner message (`--for MSG-<id>`); the server checks
  that the message is the owner's, was delivered to the sender in the last
  hour and names the target, then delivers it stamped "relayed for the owner,
  MSG-<id>". The boundary stays closed to worker-initiated sends. The
  boundary code is owner tier (api/boundaries.rs), so this is yours to
  approve.
- **20b (B3). Ask answers from its best match.** When the top match clears
  a score threshold, the answer leads with it ("Yes: MSG-103447, to backend,
  11-02 07:11") and the prose explains after; keep the hiking question as a
  regression fixture that must return MSG-103447 first. amux owns this thread
  (MSG-104095 open).
- **20c (B4). A closed route reopens itself once.** The route request that
  finds its browser closed reopens it with the same profile (the logins
  survive, as the error says), logs `route_reopened`, and retries the verb.
  If it cannot, and the same caller has hit the closed route N times in an
  hour, log `route_closed_loop` naming the worker so a sweep catches it.
- **AF-1166 (B5).** Now that the cause is IndexedDB transactions on a small
  origin, fix the outbox's reads in app.js the way 368a7d69f did for
  dictation: bounded transactions, a reset after one hang, and the outbox
  served from memory until storage answers again.

Still open from earlier audits: 19a second half (chunk the long writer jobs),
19c (tell you when a goal clears unmet), 18c (WhatsApp sender, your choice).
