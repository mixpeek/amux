## Proposals

- **1f. Refuse a migration version that origin/main already holds, at
  commit time.** `versions_are_dense_and_match_their_filenames` runs only
  in CI, nine hours after the push. The pre-commit hook can compare each
  new `crates/amux-server/migrations/NNNN_*.sql` against
  `git ls-tree origin/main` and refuse a number that is taken, printing the
  next free one. This is cheap and targets the exact failure. The deeper
  cause is commits from the 1250-behind shared checkout. A hook that warns
  when a commit's base is more than N commits behind origin/main covers the
  route and catalog misses too.
- **2b (new evidence).** B2 above.
- **3b (new evidence).** B4 above.
- **5a (new evidence).** B5 above.
- **8a. The owner's acceptance test is recorded once, on the worker.** When
  Ethan states "it's not done until X" or "your test should be X", store X
  in that worker's memory under a fixed heading. `amux requests` would show
  the stored criterion beside each open request, and the done line would
  name the evidence that meets it. This reuses the memory and request
  primitives and adds no new one. It ranks below 1f because it needs a
  capture rule, and that rule is a judgment call.
- **9a. Test scripts never default to the live server or a live worker.**
  `tests/e2e-offline-sync.mjs` refuses to run unless `AMUX_E2E_URL` is set
  explicitly or `AMUX_E2E_LIVE=1`. Its send target is a session the script
  creates and removes, never a named worker.
