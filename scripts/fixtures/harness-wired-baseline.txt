# Harnesses that exist and are invoked by no workflow and no git-hook.
#
# Recorded, not blessed. scripts/test-harness-wired.sh fails on any UNWIRED
# harness that is not listed here, so this file is the ratchet's memory: the set
# may shrink, never grow silently. One reason per line, after the filename.
#
# Seeded 2026-09-09 from a measurement of 80 harnesses, 48 wired, 32 not.
# AF-677 (2026-09-10) is the decision this file asked for: each of the 31 named
# here at the time was run standalone and given a real verdict rather than
# left as "owner to confirm or wire" (ethos rule 8 — the decision was made,
# not skipped). 28 were CI-safe and are now wired into checks.yml. The 3 that
# remain here each have a checked, specific reason, not a placeholder.
test-target-clause.sh                  AF-346's own harness. Every cell compiles for real, so wiring it into the required `checks` gate adds minutes to every lane's push. Its cheap half is scripts/test-selector-clauses.sh, which IS wired.
test-lineage-render.sh                 AF-677: needs a LIVE server carrying real, aged board history to prove its renderer against `/api/why/task/<id>`'s ACTUAL payload rather than a synthetic fixture -- the script's own header calls this deliberate ("a synthetic fixture would not prove the renderer matches what the endpoint actually emits"). It self-reports SKIP (exit 2) when unreachable, and a GitHub-hosted runner has nothing at localhost:8824 by construction, so wiring it would either always skip or need CI to stand up production-shaped historical data neither this repo nor any runner has. Stays a local dev-box tool; re-run it by hand against a real box before trusting a Lineage-tab change.
test-unstamped-ledger.sh               AF-677: same shape as test-lineage-render.sh, against a live `/api/history` instead of `/api/why/task`. Same self-reported SKIP-when-unreachable contract, same reason it cannot run where nothing is listening on :8824.
test-ios-board.mjs                    AF-741/AF-745: native local acceptance requires a booted Xcode iOS Simulator, the supervised Appium/XCTest driver, and an isolated amux API; the script refuses production. Run node scripts/test-ios-board.mjs on the Mac after mobile board changes. Six native journeys were exercised in scratch/ios-simulator-review/mobile-board-final; Linux checks has none of these device prerequisites.
test-ios-browser.mjs                  AF-732/AF-745: exercises native Safari taps, software keyboard and real receipt recovery against a booted local Simulator plus isolated API and configured driver. Run node scripts/test-ios-browser.mjs on the Mac after browser/receipt changes; this is device acceptance, not a Linux-hosted CI test.
test-tailnet-owner.py                 AF-734/AF-745: deliberately uses the real owner Tailscale daemon and its bound interface with an isolated token-protected server. Run AMUX_AUTH_TEST_PORT=<isolated-port> python3 scripts/test-tailnet-owner.py locally; hosted CI has no owner tailnet identity and must not receive its credentials.
