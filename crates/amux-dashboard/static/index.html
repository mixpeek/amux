Workers may message across groups
Workers may message only workers in a shared group. Owner input remains permitted.
Refill To Do from Backlog, all workers
The fleet-wide default for each worker’s “Refill To Do from Backlog” switch: when To Do is empty, the oldest Backlog card the worker can do moves into To Do. It only takes effect on workers whose “Board steers this worker” and “Start To Do cards when idle” are on. Human-owned, triggered, epic, watch and tripwire cards are never moved.
Auto-answer resume dialog
Pick "Resume from summary" automatically when the old-worker dialog appears
Auto-file every command as a task
Every command you send becomes a board issue, so the board is the source of truth without you filing anything. Control words ("continue", "yes") are skipped.
Autofix: file a card when something breaks
Watches server errors, latency, dead routes, stalled subsystems, invariants and the build — files one board card per distinct fault, with the evidence, and lets the board hand it to a worker. It never fixes anything itself. Off still detects and records; only the card is skipped (see /api/debug/autofix).

            Typing here switches the schedule to Custom. Accepted: every Nm/Nh/Nd, daily at HH:MM, every weekday at HH:MM, weekly on monday at HH:MM, monthly on 1-28 at HH:MM, every morning/evening, or 5-field cron (minute hour day month weekday).
          
        
          
          
        Timeouts, environment variables and notifications are not settings this scheduler has, so they are not offered here. A shell command reports a failure to its owner worker on a non-zero exit. To re-run a schedule until its work is done, turn on Pass/fail under Basic.
